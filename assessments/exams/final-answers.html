简答题评分要点 ​

Q11（RLHF = RL + 人类偏好；reward hacking） ​

满分（5 分）：

  • 解释 RLHF = 用 RL 训练策略，reward 来自人类偏好训练的 reward model
  • reward hacking：模型学会"骗 reward model 高分"而非真的对齐人类意图
  • 引用具体例子（如重复 / 谄媚 / 长篇但内容空洞）
  • 常见错误：把 RLHF 说成"用人工标注微调"——这是 SFT，不是 RLHF

Q12（推理 vs Agent 对比表） ​

满分（5 分）：

维度推理模型（L20）Agent（L26）
执行环境模型内部，纯文本外部世界，含工具调用
反馈来源模型自评 + 可验证奖励（数学题对错）工具返回 + 环境状态变化
失败模式推理链错（reasoning chain hallucination）tool call 错 / 无限循环 / 奖励欺骗
  • 常见错误：把两者混为一谈（"推理模型就是简单 Agent"）—— 错，推理模型不调外部工具

Q13（百万 token 不能取代 RAG） ​

满分（5 分） —— 至少 2 条理由：

  • 成本：百万 token 推理成本高（attention 是 O(n2)），RAG 只送相关 chunk
  • 数据更新：知识库每天更新，把全库塞 context 不现实；RAG 能动态检索最新内容
  • 可解释：RAG 提供 citation，便于 fact-check
  • 常见错误：只说"长 context 注意力会衰减"——这只是论据 1 而不是 2 条独立理由

Q14（FC / Skill / Protocol 三层） ​

满分（5 分）：

  • Function Calling（L25）：单次 LLM ↔ 工具的调用机制（语法层）
  • Skill（L27）：可复用的能力包，包含 prompt + tool + memory + workflow（能力层）
  • Protocol（L28）：跨模型 / 跨 Agent / 跨厂商的标准化通信约定（生态层）
  • 常见错误：把 Skill 等同于 prompt template

Q15（多模态 vs 具身） ​

满分（5 分）：

  • 多模态：扩展感知通道（文 / 图 / 音 / 视频），但仍在虚拟世界
  • 具身：感知扩展到物理传感器（IMU / 力反馈 / 触觉），且输出是物理动作
  • 具身更难的核心：① 物理世界不可逆 ② sim-to-real gap ③ 数据采集成本数量级更高
  • 常见错误：把具身仅说成"加机器人"——忽略了"决策即物理动作"的不可逆性

Q16（L34 + L35 耦合） ​

满分（5 分）：

  • L34 给出"技术能不能可控"的诊断（SAE / 红队 / 对齐税）
  • L35 第 6 个预测给出"社会能不能跟上"的判断（许可制度全球落地）
  • 两者互为前提：技术不可控 → 社会层面无法立法（不知道立什么）；社会不立法 → 技术风险无法被强制约束（市场失灵）
  • 常见错误：把它们说成两个独立话题

评分维度4 分7 分10 分
极窄场景识别泛泛给出 1 个场景给出 ≥ 2 个 + 各自的"安全前提"（验证基础设施）
社会基础设施不涉及提到 1 个涉及法规 / 保险 / 审计 / 责任界定中至少 2 个
命题反驳能力全盘接受提到 L30 论点同时引用 L30 + L34 并提出新论点（如"自主性是技术能做到，但人类制度选择不允许"）

终极整合题评分（Q19 · 25 分） ​

评分细则 ​

子题 1：命题验证（8 分） ​

  • 每命题至少 1 个具体案例 → 3 分
  • 每命题来自不同幕的案例 → 5 分
  • 每命题有支持 + 反驳两面案例 → 8 分
  • 典型扣分：命题 A 只用 L01 / L11；命题 B 只用 L12；命题 C 只用 L24

子题 2：矛盾识别（8 分） ​

  • 识别 ≥ 1 处张力 → 3 分
  • 识别 ≥ 2 处张力 → 5 分
  • 识别张力 + 给出"如何共存"的解释 → 8 分
  • 示例满分张力：
    • 命题 B 说"规模占上风" + 命题 C 说"构造是护城河" → 共存方式：规模决定基线模型能力（商品化），但产品价值由 RAG / Agent / Skill / Eval（构造）决定
    • 命题 A 说"压缩"是核心 + 命题 B 说"规模"占优 → 张力：规模化模型还在压缩吗？或只是"记忆"？
    • 命题 A 说"预测" + L20 推理模型说"测试时计算" → 张力：纯预测 vs 推理时计算分别在何时占优

子题 3：个人立场（5 分） ​

  • 单纯陈述偏好 → 1 分
  • 给出理由 → 3 分
  • 给出可被证伪的判断 → 5 分

子题 4：2030 哪条先倒（4 分） ​

  • 任意回答 → 1 分
  • 给出技术理由 → 2 分
  • 给出技术 + 社会理由 → 3 分
  • 给出可观测的"先倒指标" → 4 分

整体加分项 / 减分项 ​

  • 加分（最多 +3）：用 L34/L35 的"四元组"框架来检验自己的命题
  • 加分（最多 +2）：引用课程之外的最新论文（2025–2026 年）
  • 减分（最多 −5）：抄袭课程原文超过 30% / 立场前后矛盾 / 字数 < 600
