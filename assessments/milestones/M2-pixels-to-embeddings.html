M2 · 从像素到 Embedding ​

对应：幕二（L06–L11） · 建议工作量：5–8 小时 核心命题：归纳偏置 vs 规模；向量空间是通用语言。

项目目标 ​

让学习者亲身体验「像素 → 手工特征 → CNN 自学特征 → 嵌入空间」这条 70 年压缩史。

在 CIFAR-10（小图像 10 分类）上：

  1. 手工特征 baseline：HOG / 颜色直方图 + 逻辑回归
  2. 小型 CNN：从零训 3 层 CNN（< 100k 参数）
  3. 预训练 Embedding：用 OpenCLIP / DINOv2 抽特征 + 线性分类器
  4. 输出对比表 + 嵌入可视化（t-SNE 或 UMAP）

必做项 ​

  • [ ] HOG + LogReg baseline（accuracy ≥ 0.40）
  • [ ] 小型 CNN 训练 ≥ 5 epoch（accuracy ≥ 0.65）
  • [ ] CLIP/DINOv2 特征 + 线性分类器（accuracy ≥ 0.85）
  • [ ] 三种方法各画 1 张 t-SNE 嵌入图，对比"类簇分离度"
  • [ ] 写 200 字反思：归纳偏置 vs 规模在每一阶段如何体现

反思题 ​

  1. HOG → CNN → CLIP 三阶段 accuracy 提升中，哪一跃最大？为什么？
  2. 嵌入空间的 t-SNE 图里，三种方法的"类簇分离度"差异说明什么？
  3. CLIP 的成功是不是反驳了"归纳偏置"路线？为什么 CNN 在某些场景仍胜出（提示：参考 L08）？
  4. 如果数据规模缩到 100 张图，三种方法的胜负关系会逆转吗？

参考实现要点（给评分人 / 卡壳学员） ​

⚠️ 不要直接拷贝。这是要点，完整代码请自行写。

  • HOG：用 skimage.feature.hog 抽特征 + 逻辑回归，10 类 CIFAR-10 通常 acc ≈ 0.45
  • CNN：可用 torchvision.models.resnet18(weights=IMAGENET1K_V1) 抽 fc 前一层做特征
  • CLIP：用 open_clip 或 transformers.CLIPModel，做 zero-shot 文本对比
  • t-SNE：sklearn.manifold.TSNE(perplexity=30, init="pca")，注意只在 2000–5000 样本上跑（>1 万会非常慢）
  • 典型陷阱：CLIP zero-shot 用错了 prompt template（如 "a photo of {label}." 是关键）
