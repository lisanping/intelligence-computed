第 35 讲 · 反派视角 + 六个预测 — 对一门技术最深的理解是能同时复述两面 ​

我们花了 34 讲构建了从统计直觉到 Transformer 到 Agent 到安全的完整理解。但最聪明的反对者们说：这一切可能建立在错误的范式上。本讲不回避批评——把四位怀疑论者的核心论点最强钢人化（Steelman）地复述，然后用**六个可被日后验证的具体预测（五个技术维度 + 一个社会维度）**收束全课。最后，回到序章的 50 行代码——同样的代码，你现在看到的已经完全不同了。

前置知识核心产出建议用时
全部 34 讲——本讲是全课终章① 能钢人化复述四位怀疑论者的核心批判 ② 理解每个批判对应的技术缺陷 ③ 掌握六个带时间节点的可验证预测 ④ 回到 50 行代码完成课程闭环 ⑤ 形成自己对 AI 未来的独立判断阅读约 55 分钟

从上一讲到这一讲 ​

第 34 讲问：这一切可能都建立在错误的范式上？四位怀疑论者说你们高兴得太早了。

34 讲下来，你建立了一套完整的世界观：统计学习是基础，归纳偏置带来效率，Transformer 用规模碎压了手工设计，Scaling Law 指引方向，对齐让模型听话，Agent 让模型行动，安全确保可控。

这套叙事很圆满。太圆满了。

科学进步的历史告诉我们，当一个范式（Paradigm）看起来"什么都能解释"的时候，恰恰是它最脆弱的时候。地心说也曾完美解释所有天体运行——通过不断添加本轮和均轮。当前的大语言模型范式会不会也是如此？

让我们严肃地听听四位最聪明的批评者怎么说。

⚠️ 阅读前的层级提示：与 L20 的诚实对话

本讲即将听到 Marcus 等人说："AI 的 System 2 是假的"。这听起来像是直接打脸 L20 ——L20 不是刚说"o1/R1 让 AI 有了 System 2"吗？

两讲不矛盾——它们在不同层级回答不同问题：

  • L20 是工程层论断：在可验证任务（数学、代码、形式化证明）上，CoT + RLVR + Test-Time Compute 让模型生成的推理链确实提升了正确率。这是可复现的、可被基准测试证伪的工程事实。
  • L35 是认知 / 哲学层论断：可被验证的进步能否泛化到不可验证的开放推理？模型生成的推理链是否对应模型内部的真实计算路径？还是只是更精巧的事后合理化？

Marcus / Chollet / LeCun 的批判不否认 L20 的工程事实，他们追问的是"这套机制的结构是否够格叫'真正的推理'"。本讲不强求答案，而把工程层与认知层的界线显式画清——让你自己判断"我接受这是 System 2 到何种程度"。

1. Gary Marcus：符号推理不可能从模式匹配中涌现 ​

1.1 核心论点 ​

Gary Marcus（纽约大学教授，认知科学家）是当前 AI 范式最激烈、最持久的批评者[1]。他的核心论点：

核心概念

Marcus 的核心批判：当前的深度学习（包括 LLM）本质上是高级模式匹配（Pattern Matching），而非真正的推理。符号推理能力——逻辑演绎、因果推断、组合性泛化——不可能从统计关联中"涌现"出来。你需要在架构中显式地构建它。

Marcus 的证据：

  • LLM 无法可靠地做多位数乘法——这是纯规则操作，不应该依赖训练数据中见过多少乘法例子
  • LLM 在"不在训练分布中"的推理问题上大幅退化——如果真的"学会了推理"，为什么推理能力和问题的形式高度相关？
  • LLM 的"推理链"可能只是模仿训练数据中推理链的模式，而非实际在推理

1.2 钢人化 ​

Marcus 最强的论点不是"LLM 不好用"（它显然好用），而是：

钢人化要点

"LLM 在 80% 的任务上表现出色，不能证明它掌握了这些任务背后的能力。 一个在 1000 万道数学题上训练的模型可能在第 1000 万零一道题上失败——因为它学到的是模式，不是规则。如果你的飞行控制系统 95% 的时间工作正常——那 5% 就是坠机。我们需要的是 100% 可靠的推理，而模式匹配天然无法提供这种可靠性。"

1.3 反驳与开放问题 ​

反驳：GPT-4 + CoT 在很多推理任务上已经逼近人类水平；o1/o3 等推理模型通过搜索 + 验证大幅提升了可靠性。

开放问题："涌现"是真正的能力习得，还是更精密的模式匹配？ 如果是后者，那么 Scaling 到 10 万亿参数也无法解决 Marcus 指出的问题——它只是让"模式库"更大，但本质没变。

[!abstract] 呼应线 🔗 System 1/2 线（终极呼应）：L01 埋线——人类有 System 1（快速直觉）和 System 2（慢速推理）。L20 呼应——o1 / R1 / Claude Extended Thinking 通过推理时计算让 AI 在可验证任务上生成了"System 2"似的推理链。本讲终极呼应：Marcus 的核心批判恰恰在说"AI 的 System 2 是假的"——它看起来在推理，实际上只是更精致的模式匹配（System 1 伪装成 System 2）。 这条线的张力在终章达到最高点。

2. Yann LeCun：自回归 LLM 是死胡同 ​

2.1 核心论点 ​

Yann LeCun（图灵奖得主，Meta 首席 AI 科学家）不是 AI 的怀疑论者——他是"当前路线"的怀疑论者[2]。他的核心论点：

核心概念

LeCun 的核心批判：自回归语言模型（Autoregressive LLM）是通向 AGI 的死胡同。原因：(1) 语言是思维的压缩表达，不是思维本身——在 token 空间中推理效率极低；(2) 自回归生成一旦犯错就不可回退——错误会指数级放大；(3) 真正的智能需要"世界模型"——一种在高维向量空间中规划和推理的能力，而非在离散 token 中逐个采样。

LeCun 提出的替代方案：JEPA（Joint Embedding Predictive Architecture） ——模型不预测下一个 token，而是在表示空间中预测未来状态。

自回归 LLM:   token₁ → token₂ → token₃ → ...  (离散, 单向, 不可回退)
JEPA/世界模型: state₁ → predict state₂ → 在表示空间中规划 → 选择最优动作

2.2 钢人化 ​

LeCun 最强的论点：

钢人化要点

"一个婴儿在出生后几个月内学会的物理直觉——物体永恒性、重力、因果——需要的数据量比 GPT-4 的全部训练数据少几十亿倍。 这证明当前 LLM 的学习效率极低。LLM 用了整个互联网的文本才学会的'推理'，婴儿只用了几千小时的感官体验就掌握了。我们缺少的不是更多数据或更大模型，而是一个根本不同的学习架构——一个能在向量空间中构建世界模型的架构。"

[!abstract] 呼应线 🔗 归纳偏置 vs 规模（终极呼应，Part 1）：LeCun 的世界模型本质上是在说——纯规模路线的尽头是一堵墙，你需要重新引入正确的归纳偏置（世界模型架构、向量空间推理、物理先验）才能突破。从 L12 CNN 的局部性偏置、到 L18 Transformer 去掉偏置靠规模、再到 L33 物理世界的偏置反击——这条张力线在 LeCun 的批判中达到终极对峙。

2.3 反驳与开放问题 ​

反驳：LLM 已经展示出某种程度的"世界模型"能力（Othello-GPT 内部形成了棋盘表示）；多模态 LLM 正在整合视觉、音频等非语言信息。

开放问题：JEPA 目前还没有比 LLM 更成功的实证——它是对的理论但缺乏工程证明，还是根本走不通？

3. François Chollet：ARC 基准证明 LLM 无法泛化 ​

3.1 核心论点 ​

François Chollet（Keras 作者，Google 研究员）创建了 ARC（Abstraction and Reasoning Corpus，抽象与推理语料库） 基准[3]，专门用来检验 AI 是否具备真正的泛化能力。

核心概念

Chollet 的核心批判：智能 ≠ 技能。LLM 展示的是"技能"（在大量训练数据上做模式匹配的能力），而非"智能"（面对全新问题时的推理泛化能力）。ARC 每道题都是全新的、从未在训练集中出现过的——它测试的是"你能否在极少的例子中发现规则并推广"，而非"你是否见过类似的题目"。

ARC 题目示例：

输入:  ■□□    输出:  □□■
       □■□           □■□
       □□□           □□□

输入:  □□■    输出:  ■□□
       □□□           □□□
       □■□           □■□

问题:  ■□□    输出:  ???
       □□□
       □□■

人类看几个例子就能发现规则（左右翻转），但 LLM 在 ARC 上的表现远低于普通人——即使是 GPT-4o。

3.2 钢人化 ​

钢人化要点

"如果你在 100 万道数学题上训练一个模型，它在第 100 万零一道同类型题上表现好——这只证明了它记住了这类题的模式。真正的泛化是：给你三个例子，你就能推导出规则并应用到全新情境中。人类儿童天然具备这种能力。当前最大的 LLM 在这个能力上不如五岁小孩。如果你把'在训练分布内表现好'叫做智能，那搜索引擎也是智能的。"

3.3 反驳与开放问题 ​

反驳：ARC 的任务设计本身可能有偏向（偏向视觉空间推理，而非所有类型的推理）；2024 年 ARC Prize 竞赛中，结合程序合成与 LLM 的方案已经达到 ~55% 的正确率。

[!abstract] 呼应线 🔗 归纳偏置 vs 规模（终极呼应，Part 2）：Chollet 的 ARC 是这条张力线的终极试金石——如果规模路线是对的，那么足够大的模型应该能解决 ARC；如果规模不够，就需要新的归纳偏置（如程序合成、符号推理模块）。截至 2025 年，纯 LLM 方案在 ARC 上仍然挣扎——但混合方案正在缩小差距。裁决尚未做出。

4. 具身派：没有身体就没有理解 ​

4.1 核心论点 ​

以 Rodney Brooks（iRobot 创始人、MIT 教授）和 Karl Friston（自由能原理提出者）为代表的具身智能（Embodied Intelligence）阵营认为：

核心概念

具身派的核心批判：真正的理解需要与物理世界的交互——感知、行动、感受后果。一个只处理文本符号的系统，无论多大多强，都不可能真正"理解"什么是"重"、什么是"热"、什么是"痛"。它处理的只是这些概念的符号标签（Symbolic Label），而非概念本身。

这与 L33 讨论的 Moravec 悖论直接呼应：高级推理容易，低级感觉运动难——而具身派认为低级感觉运动才是智能的根基。

4.2 钢人化 ​

钢人化要点

"LLM 可以完美地描述如何骑自行车——力的平衡、重心调节、转向的反直觉原理——但它永远不会'骑'自行车。描述和理解之间的鸿沟，就是语言和身体之间的鸿沟。人类智能诞生于数亿年与物理世界的交互进化中——你不能指望跳过这数亿年的'物理经验'，只从文本中就获得等价的理解。"

4.3 反驳与开放问题 ​

反驳：盲人和聋人同样具有高级智能，证明并非所有感官模态都是智能的必要条件；多模态模型正在整合视觉、音频、触觉信号。

开放问题："理解"到底需不需要"身体"？ 这是一个古老的哲学问题（具身认知 vs 功能主义），AI 的发展可能最终给出实证答案。

5. 六个可验证的预测（2026-2030） ​

图：六个预测的综合记分卡（前五个为技术维度，第六个为社会维度），每个预测带明确时间节点和可验证指标。

核心概念

对一门技术最诚实的展望，不是"我觉得 AI 会很厉害"或"AI 要完蛋了"这种不可证伪的空话，而是给出带明确时间节点、可被日后验证的具体预测。 以下六个预测——前五个在技术维度（AI 能做到什么），第六个在社会维度（人类制度能跟上吗）—2030 年我们回来对答案。

每条预测均附四元组（数据集版本 | 评估指标 | 判定阈值 | 判定主体）——预防 2030 年验证时退化为"定义之争"。这个设计原则在哲学上是 Karl Popper 可证伪性（falsifiability）——"AI 会很厉害" 不可证伪 → 不是科学陈述；"到 2028 年 ARC > 80%" 可证伪 → 是科学陈述。

预测一：推理能力 ​

到 2028 年底，单一模型（不含外部搜索或工具调用）将在 ARC-AGI 公开测试集上达到 >80% 正确率。

四元组赋值
数据集版本ARC-AGI-2 公开集（2025 发布；如后续出现 ARC-AGI-3 则以预测作出时的最新公开版为准）
评估指标pass@1（每题允许 1 次提交），不使用 self-consistency / 多采样
判定阈值公开集整体准确率 ≥ 80%（600+ 题 × 0.8 = 480 题以上）
判定主体ARC Prize Foundation 官方 leaderboard（https://arcprize.org）

如果成真 → Chollet 低估了规模+架构创新的组合力量。 如果落空 → 模式匹配有天花板，需要新范式。

预测二：世界模型 ​

到 2029 年底，至少一个"世界模型"（在向量空间而非 token 空间中做规划）将在标准机器人操作基准上超过纯自回归方案。

四元组赋值
数据集版本LIBERO 或 RoboCasa（2024 发布）以及 2026–2028 间社区广泛采纳的后续版本（以预测验证时 SOTA 论文库使用最多的版本为准）
评估指标全评测集平均任务成功率（task success rate, 同一硬件 + 同一训练预算 ± 20%）
判定阈值世界模型方案 ≥ 纯自回归方案 + 5 个百分点（统计显著 p<0.05）
判定主体CoRL / RSS / NeurIPS 同行评审论文（非厂商官方博客）

如果成真 → LeCun 的方向论是对的，JEPA 类架构有实际价值。 如果落空 → 自回归范式的生命力比 LeCun 预计的更强。

预测三：具身智能 ​

到 2030 年底，至少一款通用家庭机器人（能在预定的 20 项日常家务上达成成功率 >90%）将以 <$20,000 的售价商业化。

四元组赋值
20 项任务清单叠衣物、装卸洗碗机、扫一个房间、插拔充电器、烤面包、取快递、打包垃圾、调节空调、清理台面、折叠床单、按口语指令找物、水果切块、遛狗、送快递下楼、照顾植物、换灯泡、敷茶冲咖啡、打开包装、收干净衣服、为客人拿饮料（完整清单见 demo/figures/prediction_3_tasks.md，以预测作出时版本为准）
评估指标20 项任务在 100 个不同家庭环境中的平均成功率 ≥ 90%（任务路线 5 分钟内完成为成功，用户零介入）
判定阈值商业售价（含税、不含代补贴） < $20,000，中美两地都需达到
判定主体Consumer Reports / Wirecutter 等独立评测机构的实测报告（非厂商自报）

如果成真 → Sim-to-Real gap 被工程力量解决，具身智能从实验室走向家庭。 如果落空 → 物理世界的复杂性超出了当前技术路线的能力。

预测四：安全与可解释性 ​

到 2028 年底，主流 LLM 将提供模型层面的"置信度"指标——对于每个输出，模型给出一个经过校准（Calibrated）的"我有多确定"分数。

四元组赋值
数据集版本MMLU + TriviaQA + HellaSwag 三者合集（面向事实型问答），及代表性生成型任务集
评估指标Expected Calibration Error (ECE) 使用 15-bin reliability diagram 计算
判定阈值主流 LLM（OpenAI / Anthropic / Google / Meta / DeepSeek / Qwen 中至少 3 家）的官方 API 返回的 confidence 字段在以上集上 ECE < 0.05
判定主体HELM (Stanford CRFM) 或同类独立评测平台公布的评测报告

如果成真 → 幻觉问题虽未消除但被有效标注，用户可以知道什么时候该信模型。 如果落空 → 模型的"不知道自己不知道"是架构性缺陷，非工程可解。

预测五：范式转换 ​

到 2030 年底，自回归 Transformer 仍将是 AI 工业的主要架构——尽管可能有重要的补充模块（检索、符号推理、世界模型），但核心不会被替代。

四元组赋值
指标全球 Top-20 商业 LLM API（按调用量 / 营收加权）中使用起点为「decoder-only Transformer + (可选) Mixture-of-Experts」架构的比例
判定阈值上述比例 ≥ 70%（SSM/Mamba/JEPA/纯符号 等非 Transformer 架构合计不超过 30%）
数据源State of AI Report 2030 年度商业架构统计或同类独立报告
判定主体外部分析师（State of AI Report / a16z / Stratechery 等）公开报告

如果成真 → Marcus 和 LeCun 的批判是正确的诊断但开错了药方——补丁比重建更实际。 如果落空 → 2020 年代的 Transformer 确实像 2000 年代的翻盖手机——功能完备但即将被颠覆。

预测六：人类社会的适应（非技术维度） ​

前五个预测都在问"AI 能做到什么"，第六个预测问"人类制度能跟上吗"——到 2030 年底，全球至少 5 个主要经济体（中、美、欧盟、英、印度、日本中至少 5 个）将通过强制性的"AI 高风险用途许可制度"，覆盖至少 3 类用途（医疗诊断、教育评测、信用评分中至少 3 类）。

四元组赋值
指标强制性许可制度数量 = 上述 6 个经济体中，已通过立法且 2030-12-31 之前正式生效的"AI 高风险许可"法律的国家数
判定阈值≥ 5 个经济体 + 每个经济体覆盖的高风险类别 ≥ 3 类
数据源OECD AI Policy Observatory + Stanford AI Index Report 2031（覆盖前一年的法规快照）
判定主体OECD / Stanford HAI / Brookings 等独立政策研究机构的年度报告

如果成真 → "技术创新跑得过制度建设"的悲观叙事被证伪——人类社会有能力建立起与 AI 能力相匹配的治理框架。EU AI Act (L34 §5.1.1) 不是孤例，而是范本。 如果落空 → 治理与能力的差距进一步拉大，AI 应用的合规复杂度会成为下一个十年最大的工程瓶颈（远超技术挑战）。

为什么把它列成预测六

前五个预测都在 AI 系统内部——能不能推理、有没有世界模型、能不能造身体、安不安全、用什么架构。第六个预测在 AI 系统外部——人类制度怎么应对。

如果你的工作是开发 AI 应用：第六个预测决定了你 2028-2030 年要面对的合规成本。EU AI Act 已经把高风险应用合规变成了显性的工程约束（参见 L34），如果还有 5 个经济体跟进 → 全球部署一个高风险 AI 应用 = 处理 5 套独立的合规框架 + 5 套独立的评估报告 + 5 套独立的责任界定。

如果你的工作不直接接触 AI：这条预测决定了 AI 是被以"互联网式扩散"（监管落后于扩散）还是"航空式扩散"（监管和扩散同步）的方式融入社会。两条路径对就业、教育、医疗、司法的影响完全不同。

预测的价值

这些预测可能全错。但给出预测本身就有价值——它迫使你把模糊的直觉转化为具体的判断，而具体的判断可以被检验。这里加上了四元组（数据集版本 | 指标 | 阈值 | 判定主体）的原因是防止 2030 年验证时退化为"定义之争"——预测的价值不在于判断是否成真，而在于预先明确"怎么算成真"。

六个预测的覆盖结构：

  • 预测一-二：AI 能力边界（推理、世界模型）
  • 预测三：AI 物理形态（具身）
  • 预测四：AI 可控性（校准）
  • 预测五：AI 架构选择（Transformer 续命）
  • 预测六：人类社会的适应能力

这六个维度是 2030 年回头评判"我们走到哪一步了"的最少必要拼图。如果只看技术指标（前五个），可能 5/5 全对，但社会层面（第六个）仍然失败 —— 那就回到 L01 埋下的"两次 AI 寒冬"逻辑：技术能力的进步不能自动兑现为社会价值。

终章之问

"它理解莎士比亚吗？" 这是第 1 讲留下的问题。34 讲后，你的回答不应该是"是"或"否"——而应该是"'理解'这个词在这个语境下意味着什么？按照什么定义？用什么标准衡量？" 这门课教给你的不是一个答案，而是问出正确问题的能力。

失败模式 / 反例 ​

本节列出本讲核心结论不适用或易被误用的常见情境。教学的目的不是制造「已学会」的错觉，而是认清边界。

  • 预测的「事后偏差」：所有「AI 预测史」回顾文章只引用对的预测；KurzWeil 等「预测大师」实际命中率 ~50%（与抛硬币持平）——选择性引用是教学陷阱。
  • 「指数曲线必然延续」迷思：Moore 定律放缓、Kaplan 被 Chinchilla 推翻、Sora 一年未根本进步——「AI 加速」叙事需要保持怀疑。
  • 短期高估、长期低估（Amara 定律）：本课程最稳的预测就是这一条——具体技术常被高估时间表，但底层影响常被低估。
  • 自我应验 vs 自我证伪：广为流传的预测会改变行为（投资涌入、人才流动），从而改变它的概率——这让「客观预测」在 AI 领域接近不可能。

本讲小结 ​

  1. Gary Marcus 指出了模式匹配的天花板——符号推理不可能从统计关联中涌现，LLM 的"推理"可能只是更精致的模式匹配。System 1 在伪装 System 2。
  2. Yann LeCun 认为自回归是死胡同——真正的智能需要在向量空间中构建世界模型做规划，而非在 token 空间中逐个采样。数据效率是当前范式的致命弱点。
  3. François Chollet 用 ARC 证明 LLM 无法真正泛化——智能 ≠ 技能，面对全新问题时的推理泛化能力才是智能的本质。
  4. 具身派认为没有身体就没有理解——处理符号标签不等于理解概念，数亿年的物理交互经验不可能被文本替代。
  5. 六个预测把模糊直觉转化为可验证判断——五个技术维度（推理能力 ARC > 80%? / 世界模型 / 家庭机器人 / 校准置信度 / 范式持续性）+ 一个社会维度（高风险许可制度的全球落地）。2030 年对答案。
