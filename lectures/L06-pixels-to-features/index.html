第 6 讲 · 像素到特征 — 手工特征的天花板 ​

特征决定上限，模型只是逼近上限。

这是 ImageNet 之前 30 年计算机视觉的核心信念。一代代研究者把毕生精力投入设计"更好的特征"——SIFT 让 David Lowe 写了 6 年，HOG 让 Dalal & Triggs 一篇论文获引用 50,000+ 次。人类先验知识是捷径，也是天花板。

这个信念会在 L07（CNN）被部分推翻、在 L12（Transformer）被彻底颠覆。但理解它为什么曾经是对的、又为什么最终输给了规模——是理解整个深度学习革命的关键。

前置知识核心产出建议用时
L03（统一优化框架）、L04（经典 ML）① 理解"特征"概念及其对模型能力的约束 ② 掌握 SIFT / HOG / Bag-of-Visual-Words 的设计哲学与数学 ③ 看清手工特征的三面天花板 ④ 体验 ImageNet 之前的 CV 工作流（手工特征 + SVM） ⑤ 理解为什么 2012 AlexNet 让一切崩塌 ⑥ 拿到 L07（CNN）/ L12（Transformer）的伏笔阅读 ~50 分钟 + 动手 ~25 分钟

从上一讲到这一讲 ​

L03 给了统一框架：所有 ML 都是 θ∗=arg⁡minθL(fθ(x),y)。

L04 / L05 给了经典 ML 的算法武器和应用场景。但有一个根本前提没有触碰：所有这些算法都假设输入 x 是"漂亮的特征向量"。

逻辑回归需要 x∈Rd；XGBoost 需要"特征 + 阈值"；K-means 需要"距离有意义的向量"。

但真实世界的图像不是这样：

  • 一张 224×224 RGB 照片是 150,528 维向量
  • 直接喂给 KNN：维度灾难（L05 §5）
  • 直接喂给 SVM：核函数算不动
  • 直接喂给 XGBoost：每个像素当一个特征，没有任何"形状"信息

要做图像识别，必须先有"特征"——但谁来选？

这一讲讲清楚 ImageNet 之前的回答：人类来选——SIFT、HOG、SURF、BRIEF……以及为什么这条路最终走到了尽头。

核心概念

本讲同时标志着从第一幕（"智能何以可计算"）进入第二幕（"归纳偏置路线"）——从抽象的统一框架，走进具体的模型/特征设计实践。第二幕的核心问题是：如何把人类先验编码进系统？

1. 计算机看到的世界 ​

先建立一个基础认识：一张图片在计算机里到底是什么？

一只猫蜷缩在毛毯里，只露出半只耳朵和一小片毛。人类不到一秒就能说出"这是只猫"——半只耳朵、毛的纹理、蜷缩的轮廓，大脑瞬间完成识别。

但计算机看到的是几十万个数字。

1.1 RGB 三通道分解 ​

每张彩色照片在计算机里是三个数字矩阵——红（R）、绿（G）、蓝（B）三个通道。每个通道是一个二维网格，每个格子里是一个 0–255 的整数。

一张 224×224 的照片（很多经典模型的输入尺寸）包含：

224×224×3=150,528 个数字

十五万个数字。我们的模型要从这十五万个数字里学出"这是只猫"。

图 6.1：一张照片被分解为 R/G/B 三通道——每个通道是一个 0-255 的整数矩阵。来源：demo/feature_comparison.py 生成。

1.2 像素 vs 特征 ​

但想想我们自己是怎么认猫的——不是逐像素扫描的。我们看的是轮廓、纹理、形状、比例——这些叫特征（Feature）。

特征是对原始数据的有意义的概括——从 15 万个数字中提取出几十个、几百个真正有用的描述。

核心概念

在深度学习出现之前，谁来决定什么是"有意义的"？答案是：人类来决定。

SIFT、HOG、Bag-of-Visual-Words——每一个都是某位（或某几位）研究者花数年时间，把自己对"什么样的图像结构是重要的"这件事的理解，编码成数学算法。

2. 经典 CV 的标准管线 ​

2010 年代之前，几乎所有 CV 任务都遵循同一套管线。

原始图像
    ↓ 特征提取（手工设计）
    ↓ SIFT / HOG / SURF / BRIEF
特征向量
    ↓ 编码 / 量化（可选）
    ↓ Bag-of-Visual-Words / Fisher Vector / VLAD
固定维度向量
    ↓ 分类器
    ↓ SVM / Random Forest / Logistic Regression
分类结果

每一阶段都是独立设计的——研究者发论文时通常只改一个阶段。这种两段式架构（特征提取 + 分类器）统治了 CV 整整 20 年。

[!quote] 历史 2010-2011 年的 ImageNet 挑战赛，前几名几乎都是 SIFT / HOG + Fisher Vector + SVM 的不同组合。每年的提升靠更好的特征、更精的编码——而不是更好的分类器。

当时的共识：分类器选择已经是 solved problem，差距在特征。这个共识在 2012 年崩塌。

3. SIFT：尺度不变特征变换 ​

3.1 设计哲学 ​

[!quote] 历史 2004 年，加拿大 UBC 的 David Lowe 发表 Distinctive Image Features from Scale-Invariant Keypoints[1]。他从 1999 年开始研究这个问题——写了整整 6 年。

SIFT 论文累计被引用 80,000+ 次——计算机视觉史上最高引用论文之一。

设计目标：找到那些"不管图像怎么变都长得一样"的关键点——

  • 旋转 30°：关键点位置和描述符不变
  • 缩小一半：关键点位置和描述符不变
  • 改变亮度：关键点位置和描述符基本不变
  • 视角小幅变化：关键点位置和描述符基本不变

3.2 SIFT 算法四步 ​

3.2.1 尺度空间极值检测 ​

构建图像的高斯金字塔——同一图像的多个模糊版本。在不同尺度间找Difference of Gaussian (DoG) 极值点：

D(x,y,σ)=(G(x,y,kσ)−G(x,y,σ))∗I(x,y)

DoG 是 Laplacian of Gaussian 的快速近似——找出"在某个尺度上特别突出"的点。

3.2.2 关键点定位 ​

对每个候选极值点：

  1. 拟合 3D 二次函数精确定位（亚像素精度）
  2. 过滤低对比度点——抛弃噪声引起的假关键点
  3. 过滤边缘响应——边缘上的点不稳定（沿边缘方向定位不准）

3.2.3 方向赋值 ​

在关键点周围 16×16 邻域内：

  1. 计算每个像素的梯度幅值和方向
  2. 用 36-bin 直方图统计方向分布
  3. 取最大 bin 作为关键点主方向

之后所有计算都相对于这个主方向——这就是旋转不变性的来源。

3.2.4 描述符生成 ​

在关键点周围 16×16 区域：

  1. 划分为 4×4 = 16 个子区域
  2. 每个子区域计算 8 方向梯度直方图
  3. 拼接成 128 维向量：16×8=128

最后归一化以增强光照不变性。

图 6.2：SIFT 在猫脸上检测出的关键点。每个箭头表示关键点的位置、尺度（圆圈大小）和主方向（箭头方向）。来源：本课程 demo。

3.3 用 L03 框架解读 ​

要素SIFT 中的形式
Model手工设计的特征提取函数——无参数
Loss无（不是学习算法，是确定性算法）
Optimizer无
归纳偏置"局部梯度结构是稳定的视觉信号"——人类先验

核心概念

SIFT 没有训练——它是一个确定性算法，完全由人类设计。这是它最大的优点（不需要数据）也是最大的缺点（无法适应特殊场景）。

4. HOG：方向梯度直方图 ​

4.1 设计哲学 ​

[!quote] 历史 2005 年，Navneet Dalal & Bill Triggs 发表 Histograms of Oriented Gradients for Human Detection[2]。论文专门为行人检测设计——这是当时自动驾驶和监控的关键问题。

论文被引用 50,000+ 次。HOG + 线性 SVM 在 2005-2012 年是行人检测的事实标准——OpenCV 至今仍带 cv2.HOGDescriptor()。

设计目标：用梯度方向分布描述物体形状——而不是关键点。

4.2 HOG 算法五步 ​

  1. 梯度计算：对图像每个像素计算 Gx,Gy，得到梯度幅值 |G| 和方向 θ。
  2. 划分 cell：把图像划成 8×8 像素的 cell。
  3. 方向直方图：每个 cell 内统计 9-bin 方向直方图（0-180°，每 20° 一 bin）。
  4. block 归一化：把 2×2 = 4 个 cell 合并为 block，做 L2 归一化（增强光照不变性）。
  5. 拼接：所有 block 的归一化直方图拼成一个长向量——典型 64×128 的图像得到 3,780 维 HOG 特征。

图 6.3：HOG 特征可视化——每个 cell 的方向直方图被画成放射线，方向越亮幅值越大。可以"看到"行人的轮廓。来源：本课程 demo。

4.3 HOG vs SIFT ​

维度SIFTHOG
单位关键点（局部，稀疏）滑动窗口（全局，密集）
输出一组 128 维描述符一个高维向量
用途匹配（图像配准、SLAM）分类（行人、人脸）
旋转不变✅❌（只对小旋转鲁棒）
计算量中低（线性扫描）

5. Bag-of-Visual-Words：特征到向量的桥梁 ​

SIFT 给一张图返回一组关键点（数量不固定），但 SVM 需要固定维度输入。怎么办？

Bag-of-Visual-Words (BoVW) 把 NLP 的 BoW 思想搬到 CV。

5.1 算法 ​

  1. 在大量训练图上提取所有 SIFT 关键点
  2. 用 K-means 聚类这些 128 维描述符——得到 K 个视觉单词（visual words），K 通常 1000-5000
  3. 对每张图：把它的所有关键点分配到最近的视觉单词，统计直方图——得到 K 维向量
  4. 这个 K 维向量就是图像的最终特征——喂给 SVM

5.2 与 NLP 的同构 ​

NLPCV (BoVW)
文档 = 一段文本图像 = 一组 SIFT 关键点
词典 = 词汇表视觉词典 = 聚类中心
词频向量视觉词频直方图
TF-IDF 加权TF-IDF 加权（也用）
文档分类图像分类

[!quote] 历史 2003 年 Sivic & Zisserman 把 BoW 引入视频检索[3]——Video Google。Csurka et al. 2004[4] 推广到通用图像分类。BoVW + SIFT + SVM 是 2005-2012 年所有视觉分类比赛的标配。

5.3 进阶：Fisher Vector / VLAD ​

BoVW 太粗糙——只用计数。Fisher Vector[5] 和 VLAD[6] 把每个视觉单词的"残差"也编码进去，性能大幅提升。

2010-2012 年 ImageNet 挑战赛冠军方案——SIFT + Fisher Vector + linear SVM。

6. 渐进退化实验：手工特征有多脆弱？ ​

让我们逐步"摧毁"一张猫的照片，看人类和机器分别在哪里崩溃。

退化方式人类SIFT/HOG
模糊（轻 → 重 → 极度）重度模糊仍能判断"是个动物"中度模糊即崩溃——SIFT 依赖梯度锐度
旋转（0° → 45° → 180°）任何角度都能认出SIFT 理论旋转不变；HOG 整体分类时下降
遮挡（10% → 50% → 90%）70% 遮挡只要露出一只耳朵仍能认30% 以上关键点大量丢失
缩小（224 → 56 → 7 像素）28×28 仍能认出大致形状56×56 以下几乎找不到关键点
光照变化几乎无影响部分鲁棒（直方图归一化）
视角变化（小幅）完全鲁棒部分鲁棒
视角变化（大幅）仍能识别完全失败
遮挡 + 模糊 + 光照仍能识别完全失败

图 6.4：从原图到极度模糊/遮挡的渐进序列。来源：本课程 demo。

规律：人类识别极度鲁棒，手工特征极度脆弱。

为什么？因为人类大脑在做一件手工特征做不了的事——用过去的经验"脑补"缺失的信息。SIFT 和 HOG 没有"经验"，它们只是数学公式。

7. 特征决定上限：天花板的来源 ​

核心概念

模型能力≤f(特征质量)

特征决定了上限，模型只是逼近上限。用最先进的 SVM、最精心调参的 Random Forest，都突破不了特征给你划的天花板。

这就是为什么在深度学习之前，机器学习领域有一句名言：

"Feature engineering is the key to machine learning."

数据科学家 80% 的时间花在特征工程上——不是训练模型，不是调参数，是想到底用什么特征。

7.1 手工特征的三面天花板 ​

天花板问题例子
领域依赖不存在"通用手工特征"，每换一个领域就得重新设计SIFT 做不了语音识别，HOG 做不了肿瘤检测
劳动密集需要深厚的领域知识 + 大量实验迭代SIFT 论文 Lowe 写了 6 年
脆弱依赖的数学假设在真实世界经常不成立模糊、遮挡、光照变化导致崩溃

三面天花板叠加 → 手工特征是一条有尽头的路。面对 ImageNet 的 1000 类、128 万训练图——人类手动设计特征的速度永远跟不上问题复杂度的增长。

7.2 ImageNet 之前的 CV 进展曲线 ​

[!quote] 历史 ImageNet 比赛 (ILSVRC) 2010-2012 年的 top-5 错误率：

年份冠军方法Top-5 Error
2010SIFT + Fisher Vector + SVM28.2%
2011同左 + 改进25.8%
2012AlexNet (CNN)[7]15.3%
2013ZFNet (CNN 变种)11.7%
2014VGGNet, GoogLeNet7.3%, 6.7%
2015ResNet3.6%
2017ResNeXt + 各种集成2.3%
人类(估算)~5%

2012 年 AlexNet 一夜降低 10 个百分点——而前两年总共才降了 2.4。这是 CV 历史上最戏剧性的转折。

[!abstract] 呼应线 🔗 归纳偏置 vs 规模（L06 建立 → L07 → L12 → L35）：手工特征是最极端的归纳偏置——人类把全部领域知识硬编码进特征提取器。L07（CNN）会展示一种更优雅的做法：把人类先验编码进模型结构（局部性 + 平移不变 + 层次抽象），让模型自己学特征。L12（Transformer）走向另一个极端——几乎不编码先验，用规模暴力让模型从零学起。

8. 手工特征的"优雅遗产" ​

不要以为手工特征都"过时了"——很多场景它们仍是最佳选择。

8.1 仍在生产系统中的手工特征 ​

场景为什么仍用
嵌入式设备 / 边缘计算CNN 推理太重，HOG+SVM 在树莓派上能实时跑
SLAM / 视觉里程计ORB / SIFT 至今是 ORB-SLAM2/3 的核心 (2024 仍 SOTA)
图像配准 / 拼接SIFT + RANSAC 至今是 OpenCV stitching 默认
实时跟踪 (KCF/TLD)手工特征 + 在线学习——延迟可控
低光照 / 恶劣条件CNN 在分布外场景退化严重，手工特征更稳定
工业缺陷检测数据少，手工特征 + SVM 仍打败小数据 CNN

8.2 CNN 学到了什么？惊人的发现 ​

[!quote] 历史 2014 年 Zeiler & Fergus[8] 用 deconvolution 可视化 AlexNet 的 conv1 滤波器——它们和 Gabor wavelet 几乎一样。

一年后，Krizhevsky 公开承认[9]："我们没有教 AlexNet 任何视觉知识——但它自己学出了和人类视觉皮层 V1 区几乎相同的滤波器。"

手工特征不是被否定，而是被自动化了。人类几十年总结出的"什么样的滤波器有用"，CNN 用反向传播一周训练就学出来了——而且更优。

9. 失败模式 / 反例 / 边界 ​

9.1 「HOG/SIFT 已死」误解 ​

如 §8.1 所述。在嵌入式、SLAM、低光照等场景仍是首选。

9.2 「人工特征 = 落后」叙事陷阱 ​

CNN 学出的早期 filter 与 Gabor wavelet 高度相似——人工特征不是被否定，是被自动化了。

9.3 像素 → 特征的失败案例：shortcut learning ​

医疗影像（X 光）上 CNN 经常学到的是**"医院水印"或"扫描仪型号"，而不是病灶——典型的 shortcut learning[10]。这是 §8.2 "CNN 自己学特征"的阴暗面——它也会自己学到错误特征**，且更难发现。L06-L08 / L34 都会回到这件事。

9.4 通道数迷思 ​

从 3 通道 RGB 升到 256 通道不一定提升性能——很多通道学到的是冗余/相关特征。剪枝（pruning）研究表明 ~50% 通道可去除而性能不降。

9.5 「BoVW 一统天下」误解 ​

BoVW 在文本/图像上有效，但忽略了空间关系。"猫在草地上"和"草地在猫身上"的视觉单词分布几乎一样。Spatial Pyramid Matching[11] 部分缓解了这个问题，但根本解还是 CNN/Transformer。

9.6 「手工特征不需要训练数据」误解 ​

虽然 SIFT/HOG 本身不需要训练，但 BoVW 的视觉词典需要在大量图上聚类，SVM 也需要标注数据训练。整个管线仍然需要监督。

9.7 从手工到自动的过渡不是单向 ​

LayoutLM、Donut[12] 等文档理解模型——把手工设计的"位置 + OCR 文本"特征显式喂给 Transformer，而不是让模型从纯像素学。这是"手工 + 自动"混合的现代典范。

11. 本讲小结 ​

  1. 计算机看到数字，不是意义——15 万个像素值里不直接包含"猫"，需要特征来桥接。
  2. SIFT 和 HOG 是手工特征的巅峰——把人类对"什么重要"的理解编码成算法，统治 CV 20 年。
  3. BoVW 把变长关键点变成定长向量——是 SIFT/HOG 与 SVM 之间的桥梁。
  4. 特征决定上限——模型能力≤f(特征质量)，再强的分类器也突破不了特征的天花板。
  5. 手工特征三面天花板——领域依赖、劳动密集、脆弱。面对 ImageNet 复杂度走到尽头。
  6. 人类极度鲁棒，手工特征极度脆弱——差距在于人类有"经验"，手工特征只有公式。
  7. 2012 AlexNet 一夜让一切崩塌——top-5 错误率从 25.8% 降到 15.3%。
  8. CNN 自己学出了 Gabor wavelet——人类几十年的视觉先验被自动化。
  9. 手工特征仍在生产——SLAM、嵌入式、低光照等场景至今首选。
  10. shortcut learning 是自动学习的阴暗面——CNN 也会学到"水印"等错误特征。

下一讲预告 ​

敌意问题：如果特征决定上限，那谁来选特征？继续靠人类？还是让机器自己学？如果让机器学——怎么学？

答案是：让机器自己学特征。2012 年，一个叫 AlexNet 的模型用两块 GPU 证明了一件事——卷积神经网络（CNN）可以从原始像素出发，自动学出比人类手工设计更好的特征。

第 7 讲——「卷积神经网络」——这场革命是怎么发生的，为什么是 CNN 而不是 MLP，以及"局部性 + 平移不变 + 层级抽象"这三条视觉先验为什么是对的。
