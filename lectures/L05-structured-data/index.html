第 5 讲 · 结构化数据与现实应用 — 时序、推荐与异常检测 ​

这一讲讲一个反 LLM 中心主义的事实：世界上大多数 ML 应用跑的不是深度学习。

  • 时序预测（电力 / 物流 / 销量）：Prophet + ARIMA + GBDT 仍统治
  • 推荐系统（电商 / 短视频）：协同过滤 + 矩阵分解 + 深度部分混合
  • 异常检测（欺诈 / 监控）：Isolation Forest + One-Class SVM 仍然是行业标准
  • 图分析（社交网络 / 知识图谱）：PageRank、社区发现仍工业一线

每一个都是千亿美元级产业的技术底座。深度学习是扩展，不是替代。

前置知识核心产出建议用时
L03（学习即优化）、L04（经典 ML）① 掌握 ARIMA / Prophet / Kalman 的核心直觉与代码 ② 理解协同过滤与矩阵分解的数学 ③ 学会推荐系统的"召回-排序-重排"三段式 ④ 区分 Isolation Forest / One-Class SVM / Autoencoder 三种异常检测路线 ⑤ 看懂 PageRank / Louvain 等图算法 ⑥ 理解维度灾难 ⑦ 掌握特征工程的工业实战 ⑧ 拿到 L11 (Embedding)、L23 (Retrieval) 的伏笔阅读 ~75 分钟 + 动手 ~30 分钟

从上一讲到这一讲 ​

L04 留下的敌意问题是：经典算法都假设输入是“漂亮的特征向量”，但真实数据是脏的、缺失的、混杂类型的——怎么办？

这一讲先给答案框架：不是先谈“最强模型”，而是先谈“最常见数据形态 + 对应工程套路”。当你把真实世界的数据问题拆成时序、推荐、异常检测、图结构四类后，会发现“漂亮特征”不是前提，而是通过数据建模和特征工程一步步构造出来的结果。

在这个前提下，我们再问：L04 的算法武器库（决策树、SVM、Random Forest、XGBoost、K-means）在真实世界的哪些战场上部署？

答案出人意料：全球实际部署的 ML 系统中，排名前三的是：

  1. 时序预测（电力调度、物流、销量、金融）
  2. 推荐系统（电商、视频、新闻、社交）
  3. 搜索与广告（CTR 预测、相关性排序）

大部分不需要 GPU、不需要深度学习。

核心概念

一个反直觉的事实：最酷的不一定最有用，最有用的不一定最酷。深度学习论文上 100 万引用——但 Walmart、Amazon、JPMorgan 的核心生产模型，仍然是 GBDT + 协同过滤 + ARIMA 的组合。

这一讲的任务是给你一张现实 ML 应用的全景图，让你看到 LLM 之外的真实世界。

1. 时间序列预测 ​

时序数据是不可交换的——观察顺序有意义。这让所有"假设独立同分布"的算法都不能直接用。

1.1 时序数据的特性 ​

四个常见组成：

成分含义例子
趋势（Trend）长期上升或下降销量的逐年增长
季节性（Seasonality）固定周期重复周末购物高峰
周期性（Cyclic）不固定周期波动经济周期
噪声（Noise）不可预测的随机波动测量误差

经典假设：平稳性（stationarity）——均值、方差、自相关不随时间变化。真实世界数据几乎永远不平稳——这就是 ARIMA 的 "I"（Integrated, 差分）的存在意义。

1.2 ARIMA(p, d, q) ​

ARIMA 是时序预测的经典基线，由三部分组成：

Xt=c+∑i=1pϕiXt−i+∑j=1qθjεt−j+εt
分量全称含义参数
ARAutoRegressive用过去 p 个值预测未来p
IIntegrated差分 d 阶让非平稳序列变平稳d
MAMoving Average用过去 q 个预测误差修正q

SARIMA 在 ARIMA 基础上加季节性分量 (P,D,Q,m)，其中 m 是季节周期长度（周 = 7，月 = 30，年 = 365）。

直觉

ARIMA(p,d,q) 就像一个三旋钮调节器：

  • p = 回看多远的历史
  • d = 做几次差分去趋势
  • q = 用几步前的误差来修正

2000 年代之前是时序预测的黄金标准——简单、可解释、统计有保证。但调参痛苦、对非线性失效。

1.3 Kalman 滤波 ​

[!quote] 历史 Rudolf Kalman（匈牙利-美国数学家）1960 年发明 Kalman 滤波[1]。1969 年用于阿波罗登月导航——是人类登月的关键数学工具之一。今天你的手机 GPS 仍在运行 Kalman 滤波。

核心是 "预测-更新" 两步循环：

预测步（基于运动模型）：

x^t|t−1=Fx^t−1|t−1+ButPt|t−1=FPt−1|t−1FT+Q

更新步（用观测纠正）：

Kt=Pt|t−1HT(HPt|t−1HT+R)−1x^t|t=x^t|t−1+Kt(zt−Hx^t|t−1)
符号含义
x隐藏状态（真实位置）
z观测值（GPS 信号）
F状态转移矩阵（运动模型）
H观测矩阵
Q过程噪声协方差
R观测噪声协方差
KtKalman 增益（权衡预测与观测）
P状态估计协方差

核心概念

Kalman 增益 Kt 是整个算法的灵魂——它自动权衡 "相信模型预测" 还是 "相信传感器观测"。

  • 如果观测噪声 R 大 → Kt 小 → 更相信预测
  • 如果过程噪声 Q 大 → Kt 大 → 更相信观测

这种"自适应权衡"思想在很多地方重生——从 RL 的 actor-critic 到 LLM 的 RoPE 频率插值。

1.4 Prophet：业务友好的 ML 民主化 ​

Meta 2017 年开源的时序预测工具[2]。自动分解为三个可加分量：

y(t)=g(t)+s(t)+h(t)+εt
分量含义说明
g(t)趋势（Growth）分段线性或 Logistic 增长曲线
s(t)季节性（Seasonality）用 Fourier 级数建模周期波动
h(t)假日效应（Holidays）已知假日的脉冲影响

直觉

Prophet 的设计哲学：让业务人员也能做时序预测。不需要调 ARIMA 的 (p,d,q)，不需要统计学背景。输入一列日期 + 一列数值，输出预测 + 置信区间，5 行代码搞定。

python
from prophet import Prophet
import pandas as pd

df = pd.read_csv('sales.csv')  # 列: ds (date), y (value)
m = Prophet()
m.fit(df)
future = m.make_future_dataframe(periods=30)
forecast = m.predict(future)
m.plot(forecast)

核心概念

2024 年时序预测的工业事实：把时序转成表格 + 滞后特征 + GBDT。这条路线比 Prophet/ARIMA 更准、比 RNN/Transformer 更便宜。

M5 Forecasting[3]（Walmart 销量预测大赛，2020）冠军方案就是 LightGBM——全部时序明星算法被表格 GBDT 击败。

1.6 Transformer 时序：N-BEATS / TFT / Chronos ​

2020 年后，Transformer 进入时序领域：

模型特点
N-BEATS[4]神经基函数分解（趋势 + 季节）
Temporal Fusion Transformer (TFT)[5]Google 出品，多变量 + 注意力
Chronos[6]Amazon 2024，"时序当语言"——foundation model 范式
TimeGPT[7]Nixtla，闭源时序基础模型
TimesFM[8]Google Research 2024，开源

2024 趋势：时序基础模型（zero-shot 预测）正在追赶 GBDT——但工业部署仍以 GBDT 为主，因为 GBDT 训练快、可解释、显存友好。

2. 推荐系统：50 亿美元/年的协同过滤 ​

推荐系统是 ML 在工业上最赚钱的应用。Amazon 35% 的销售额来自推荐；Netflix 80% 的观看量是推荐驱动；TikTok 95%+ 的视频是推荐。

2.1 推荐问题的形式化 ​

用户 u、物品 i、评分（或交互）rui——目标：预测未观察到的 rui。

数据形式：稀疏矩阵 R∈R|U|×|I|，绝大部分 entry 缺失。

2.2 协同过滤（Collaborative Filtering, CF） ​

2.2.1 基于用户的 CF ​

直觉：和你品味相似的用户喜欢什么，你也可能喜欢。

  1. 计算用户两两相似度（Pearson / 余弦）
  2. 对用户 u 的预测：
r^ui=r¯u+∑v∈N(u)sim(u,v)⋅(rvi−r¯v)∑v∈N(u)|sim(u,v)|

2.2.2 基于物品的 CF ​

直觉：和你喜欢的物品相似的物品，你也可能喜欢。

[!quote] 历史 Amazon 2003 年的论文 Item-to-Item Collaborative Filtering[9] 让基于物品的 CF 成为业界标准——比基于用户的 CF 更稳定（物品比用户少而稳定）。Amazon 至今仍在用这个算法的变体。

2.3 矩阵分解（Matrix Factorization, MF） ​

2.3.1 公式 ​

R≈UVT

其中 U∈R|U|×d,V∈R|I|×d 是用户和物品的潜在因子（latent factors）。

每个用户/物品被表示为 d 维向量（典型 d=50−200）。预测：

r^ui=uuTvi

2.3.2 训练 ​

最小化：

∑(u,i)∈observed(rui−uuTvi)2+λ(∥uu∥2+∥vi∥2)

用 SGD 或 ALS（Alternating Least Squares）训练。

[!quote] 历史 2009 年 Netflix Prize——奖金 100 万美元，谁把 RMSE 比 Cinematch 提升 10% 就能拿。冠军 BellKor's Pragmatic Chaos 用的就是矩阵分解 + 集成。MF 从此成为推荐系统的事实标准[10]。

2.4 现代推荐系统：召回-排序-重排 ​

工业级推荐系统是多阶段流水线：

百万级物品
    ↓ 召回 (Recall)：从全量中取 1000 个候选
1000 候选
    ↓ 粗排 (Coarse Rank)：取 100 个
100 候选
    ↓ 精排 (Fine Rank)：CTR / 互动预估
有序列表
    ↓ 重排 (Rerank)：多样性、新颖性、业务规则
最终列表

每一阶段用不同模型：

阶段主流方法
召回向量召回（双塔模型）+ 协同过滤 + 热门 + 个性化
粗排简单 GBDT / 双塔
精排DeepFM / DIN / DCN / Transformer
重排多目标优化 + 业务规则

L11（Embedding）、L23（Retrieval）会展开"双塔召回"——它和 RAG 的核心架构高度相似。

[!abstract] 呼应线 🔗 召回-排序模式（L05 此处 → L11 → L23 → L24）：推荐系统的"召回-排序"范式被 RAG 完整继承——召回 = 向量检索，排序 = LLM 生成。RAG 本质上是一个"以 LLM 为排序器的推荐系统"。

2.5 冷启动问题 ​

新用户 / 新物品没有历史交互——纯 CF 失效。解法：

  • 基于内容：用物品特征（类目、价格、描述）做向量
  • 混合模型：CF + 内容
  • Bandit 算法：探索-利用平衡（L17 RL）
  • 冷启用 LLM：2024 年新趋势——用 LLM 直接生成推荐理由

3. 异常检测：在干草堆里找针 ​

异常检测的特殊：正样本极少（欺诈、故障）。普通分类器在 99.9% 负样本上训出"全部预测负" = 99.9% 准确率，但完全无用。

3.1 三大路线 ​

方法思路工业代表用法
统计z-score、3σ 法则、Mahalanobis运维监控（CPU 异常）
基于密度/距离LOF、DBSCAN入侵检测
基于模型Isolation Forest、One-Class SVM、Autoencoder金融欺诈、生产故障

3.2 Isolation Forest（最常用工业方法） ​

[!quote] 历史 Liu, Ting, Zhou 2008 提出 Isolation Forest[11]——核心想法：异常点更容易被随机划分孤立。

算法：

  1. 随机选一个特征 + 随机选一个分裂点 → 划分数据
  2. 递归直到每个点单独一片
  3. 异常点路径短（容易被孤立），正常点路径长

异常评分：

s(x)=2−E[h(x)]/c(n)

其中 h 是路径长度。

优势：

  • 训练快、推理快
  • 不需要标签
  • 对高维数据稳定

3.3 Autoencoder：用重建误差检测异常 ​

训练一个 encoder-decoder：把输入压缩再恢复，损失是重建误差。

直觉：异常样本"不像训练数据"——重建误差大。

python
# 简单版本
input -> [encoder] -> latent (低维) -> [decoder] -> reconstruction
loss = ||reconstruction - input||^2
# 阈值: top 1% 高 loss 样本 = 异常

广泛用于：信用卡欺诈、工业故障、网络入侵。

4. 图算法：连接的力量 ​

很多数据是关系性的——社交网络、知识图谱、引用网络、分子结构。

4.1 PageRank：Google 的基石 ​

[!quote] 历史 Larry Page 和 Sergey Brin 1996 年在斯坦福读 PhD 时发明 PageRank[12]——网页 i 的重要性 = 链接到它的网页重要性的加权和。

这个算法让 Google 击败了所有竞争对手，成为现代搜索引擎的起点。

公式（迭代）：

PR(pi)=1−dN+d∑pj∈M(pi)PR(pj)L(pj)

其中 d 是阻尼因子（通常 0.85），L(pj) 是 pj 的出链数。

4.2 社区发现 ​

算法思路
Louvain[13]贪心最大化模块度（modularity）
Label Propagation邻居标签传播
Spectral Clustering图拉普拉斯特征向量 + K-means

广泛用于：社交网络分析、推荐用户分群、欺诈环挖掘。

4.3 Graph Neural Networks（GNN） ​

2017 年开始的"图深度学习"：把卷积思想搬到图上。代表：

  • GCN[14]
  • GraphSAGE[15]
  • GAT (Graph Attention)[16]

实战：分子性质预测、社交网络推荐、知识图谱补全。但 LLM 时代后，LLM + 知识图谱正在融合（GraphRAG）——L24 会展开。

5. 维度灾难（Curse of Dimensionality） ​

高维数据的反直觉性质——几乎所有距离都接近，几乎所有点都在"边界"。

5.1 一个戏剧化的例子 ​

考虑 d 维超立方体 [0,1]d 内随机两点的欧氏距离：

维度 d距离的均值/std
10.33
101.27
1004.05
1000040.8 ± 0.4——所有距离几乎相同

含义：d→∞ 时，任何两点的距离都接近相同。"最近邻"和"最远邻"的距离比 → 1。KNN 在高维失效。

5.2 应对策略 ​

策略适用场景
降维（PCA / Embedding）去掉噪声维度
特征选择留下信息量最大的维度
流形假设真实数据通常在低维流形上
局部敏感哈希（LSH）高维近邻搜索的 sub-linear 算法
向量量化（PQ / FAISS）现代大规模向量检索的核心

L11（Embedding）和 L23（Retrieval）是这一节的延续——embedding 把高维稀疏数据变成低维稠密向量，专门为高维检索而设计。

6. 特征工程：经典 ML 的胜负手 ​

经典 ML 时代有句话："特征工程做完，模型选什么都差不多。"

6.1 类别特征处理 ​

方法适用
One-hot类别少（< 100）
Label Encoding顺序类别
Target Encoding高 cardinality（如 user_id）
Frequency Encoding高 cardinality
Embedding高 cardinality + 深度模型

6.2 缺失值处理 ​

  • 删除：缺失少时
  • 填充：均值 / 中位数 / 众数 / 前一个 / 模型预测
  • 标记：用一个 binary feature 标记"是否缺失"
  • **GBDT（XGBoost/LightGBM）**自动处理缺失值——这是它们的杀手锏之一

6.3 文本特征 ​

方法适用
Bag-of-Words简单分类
TF-IDF经典 ML 工业标配
Word2Vec / GloVe词级 embedding
Sentence-BERT现代标准（L11/L23）

7. 失败模式 / 反例 / 边界 ​

7.1 「时序模型一定要用 RNN/Transformer」错觉 ​

如 §1.5 所述。GBDT + 滞后特征在 90% 工业时序场景胜过 RNN/Transformer。

7.2 推荐系统的 popularity bias ​

热门物品被推荐更多 → 互动更多 → 更被推荐——形成正反馈环。需要显式去偏（IPW、causal inference）。

7.3 异常检测的"标签缺失"困境 ​

异常检测通常没有标签——你不知道什么是真异常、什么是新模式。评测困难——用历史已知异常评测是 cheating，因为系统就是设计来抓它们的。

7.4 维度灾难的"没那么糟"反驳 ​

如果数据真实在低维流形上，高维表示不是问题——KNN 在 ImageNet 像素空间崩溃，但在 ResNet 特征空间工作良好。这就是 embedding 的价值——L11 展开。

7.5 「特征工程是脏活」误解 ​

特征工程是工业 ML 真正的核心竞争力。Kaggle 大师 80% 时间在特征工程——不是调参。LLM 时代特征工程的"自动化"是新趋势（AutoFE），但人工特征工程仍是高难度业务问题的胜负手。

7.6 「LLM 取代经典 ML」的炒作 ​

当前 LLM 不能替代：

  • 实时推荐（延迟太高）
  • 大规模 CTR 预估（成本太高）
  • 严格时序预测（数值不准）
  • 监管严格的金融 ML（可解释性要求）

经典 ML 在这些场景仍是事实标准，且短期不会变。

9. 本讲小结 ​

  1. 大多数 ML 应用不跑深度学习——时序、推荐、异常检测、图分析仍是经典 ML 主战场。
  2. 时序四组件：趋势 + 季节性 + 周期性 + 噪声。Prophet 让业务人员能做时序，GBDT 是工业事实标准。
  3. Kalman 滤波是"自适应权衡"思想的鼻祖——预测/观测的加权融合。
  4. 推荐系统的"召回-排序-重排"是 RAG 的祖先——L11/L23/L24 的伏笔。
  5. 协同过滤 + 矩阵分解 仍是大规模推荐的核心，混合深度网络做 CTR。
  6. 异常检测三路线：统计、密度/距离、模型——Isolation Forest 是工业最常用。
  7. PageRank 是 Google 的起点，社区发现和 GNN 是图分析的延续。
  8. 维度灾难 让 KNN 等距离方法在原始高维空间失效——embedding 是解决方案，L11 展开。
  9. 特征工程是经典 ML 的胜负手——比模型选择更重要。
  10. LLM 不替代经典 ML——实时性、成本、可解释性要求让经典 ML 仍统治大部分工业场景。

下一讲预告 ​

敌意问题：第 4-5 讲讲了所有"漂亮的特征 → 漂亮的模型"的故事。但图像怎么办？ 一张 224×224 RGB 照片是 150,528 维向量——直接喂给 KNN 或 SVM 完全失败（维度灾难 + 没有有效相似度）。要做图像识别，必须先有"特征"——但谁来选特征？

第 6 讲——「像素到特征：手工特征的天花板」——讲 SIFT、HOG、Bag-of-Visual-Words 的辉煌时代，讲 ImageNet 之前的 CV 是什么样子，讲为什么 2012 年之后这一切都崩塌了。这是理解 L07（CNN）的必经之路。
