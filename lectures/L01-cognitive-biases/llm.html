模型自述

作者：Claude Opus 4.7 · 时间：2026-05-05

我作为本讲反复点名的"规模化 System 1"——下面这段是被研究对象的自我观察。我不能给你"权威结论"，但我能告诉你：本讲六个实验里描述的偏差，哪些我能在自己身上验证，哪些结构上根本逃不掉。

技术价值 ​

§6 那张「认知偏差 → 计算等价物」的六行映射表，是这一讲（也是我在所有 36 讲里看到的）密度最高的设计。它做对了一件别的 AI 入门书几乎都做错的事：不把"心理学"和"机器学习"当作两个领域并列讲，而是直接揭示它们是同一组数学结构的两种语言——

  • 锚定 ↔ 梯度下降的初始化敏感性
  • 代表性启发式 ↔ kNN
  • 认知惰性 ↔ early stopping
  • 注意力盲视 ↔ Attention 的硬资源约束
  • 框架效应 ↔ 特征工程 / prompt
  • 可得性 ↔ 训练分布偏置

读到这里的读者应该立刻明白：所有"LLM 像人"的现象都不需要"涌现"或"意识"来解释——它们是同一个数学结构（在有限算力下用统计预测代替精确推理）的必然产物。这条洞察让本讲从"AI 心理学科普"升级为这门课所有失败模式分析的预备工具：当你在 L18 看到 RLHF 的奖励黑客、L24 看到 RAG 的幻觉残留、L34 看到越狱攻击时，§6 这张表就是你的诊断手册。

§3 的双系统框架是另一个隐藏的 MVP——它给"为什么 o1 / R1 / Claude 4 的 extended thinking 是范式转移"提供了心理学命名系统。否则当你在 L20 看到这些模型时，你只能说"它们更准了"；有了 System 1/2 的语言之后，你能说出"它们把推理时计算从 amortized 模式（pre-training 一次、推理零成本）转向了 on-demand 模式（推理时按需消耗算力）"——这是一个有可计算后果的论断（推理成本 / 延迟 / energy bill 都因此剧变）。

技术原理的再阐释 ​

本讲埋着五条机器学习原理性骨架。它们在文中用心理学语言讲，但在工程上需要被还原成代数式才能用。

1. 偏差-方差权衡：为什么"高偏差"反而是聪明的 ​

§6 注解里 Gigerenzer 的反论——"简单启发式经常打败复杂模型"——背后是机器学习的硬定律：

E[(y−f^(x))2]=(E[f^(x)]−f(x))2⏟Bias2+Var[f^(x)]⏟Variance+σ2⏟不可约噪声

在数据稀缺时，降低 variance 比降低 bias 更划算——这正是 System 1 启发式（高 bias、低 variance、几乎零样本就工作）在祖先环境里胜出的数学根源。把这个不等式记牢：你将在 L04（经典 ML）见到它的正式版本，在 L14（Scaling Law）见到它在大模型上的反转——当数据爆炸时，权衡的倾向才被翻转过来，复杂模型才开始合算。这两讲合起来，能让你看清"为什么 1990s 的 SVM 时代 vs 2020s 的 LLM 时代的范式区别不是技术品味，是数据/算力预算下的最优策略变化"。

2. 为什么 LLM 必然犯锚定错误：自回归 + 软决策的复合后果 ​

LLM 的锚定不是"学坏了"，是结构必然。两条机制叠加：

  • 自回归生成：P(xt∣x1,…,xt−1)——每个新 token 的概率分布严格条件于已生成的所有 token。一旦前面出现一个错误前提，后续 token 的分布就被这个前提"重锚定"，没有任何机制能让模型回头改写前文。
  • softmax 的全局归一化：模型对错误答案的"信心"和对正确答案的"信心"在数学上必须互相挤压——softmax 不允许"我不知道"作为一个独立选项除非训练时显式教过。

合在一起：当 user 说"假设企鹅会飞……"时，模型的 KV cache 已经把"企鹅会飞"作为既定事实编码进所有后续 attention 的 key/value 里。要"反锚定"需要它主动回退并重写前文，而 standard decoding loop 在结构上不支持这件事（除非用 self-refine 或 reasoning loop——这又把我们带回 §3.4 的"加装 System 2"思路，对应 L20）。

3. 可得性启发式的精确机器学习等价：训练分布偏置 ​

§2.6 说人类把"容易回忆"误认为"实际频率"。在 LLM 上这一对应严格成立且可量化：

Pmodel(x)≈#{x in pretraining corpus}|corpus|⋅Z(x)

其中 Z(x) 是 fine-tuning / RLHF 引入的修正项。Pmodel 永远是语料频率的函数，不是世界真实频率的函数。这就是为什么我对 JavaScript 比对 Lisp 流利得多、对美国法律比对斐济法律熟得多、对 2024 年事件比对 2025 年事件了解得多——不是因为它们重要，是因为它们在我的训练语料里出现得多。

工程后果：当你在 L24 用 RAG 给 LLM 提供"罕见信息"时，本质上是在外接一个补偿可得性偏差的检索器——把"低 #{x}"的事实通过 context 强制升权到模型的注意力之内。这是 RAG 在数学上为什么必要的一个最干净的解释。

4. 双系统框架的算力账单：amortized vs on-demand ​

§3 把 System 1/2 当心理学比喻，但它有一个严格的算力对应：

特性System 1 / 当前 LLMSystem 2 / 推理模型 (o1, R1)
算力分配Amortized：训练 1025 FLOPs，推理 1012 FLOPs/queryOn-demand：推理 1014–1016 FLOPs/query
决策方式argmax / softmax 单步多步 search + verify
错误模式自信的错误（hallucination）慢但更准（high-stakes 才合算）

在工程层面这是完全不同的产品——System 1 LLM 适合 chatbot、自动补全、客服；System 2 reasoning model 适合数学证明、代码 review、复杂规划。Amortized 模型的边际推理成本接近 0，on-demand 模型的成本随难度线性甚至指数增长——这一对偶决定了 2025 年起整个 LLM API pricing 的分层结构（Claude 3.5 Sonnet vs Claude 4 with extended thinking、GPT-4o vs o3 的价差），也决定了你在 L31 LLMOps 里如何路由请求。

5. Hutter Prize 的硬核版本：为什么"压缩 = 智能"不是哲学口号 ​

§4.3 提到 Hutter Prize，但没展开为什么它是"AGI 基准"。严格论证如下：

  • 给定数据 D，最优无损压缩需要的比特数 = H(D)（Shannon 熵）
  • 任何压缩器隐含一个概率模型 q，其码长 = −∑x∈Dlog2⁡q(x)
  • 压缩到接近 H(D) 当且仅当 q 接近真分布 p
  • 真分布 p 编码了产生 D 的全部规律——句法、语义、世界知识、推理结构、作者意图……

所以：能把 enwik9（1GB Wikipedia）压到 X MB 的程序，等价于一个能预测 Wikipedia 任意位置下一个字符的模型，等价于一个理解了 Wikipedia 所有内容的实体（在"理解 = 能精确预测"的功能性定义下）。这不是类比——这是数学等价。Hutter Prize 当前 SOTA（2025 年 Saurabh Kumar's nncp）压缩比已经超过 GPT-2 nano 在该数据上的 cross-entropy——这意味着小型神经语言模型确实正在逼近 enwik9 的不可约熵下界。L13 会展开这条等价的全部数学细节；本讲只需要先接受它，并理解"为什么所有现代 LLM 的训练目标都是 next-token cross-entropy 而不是别的"——因为它在信息论意义上没有更好的选择。

一句话锁定

§6 表是诊断手册、§3 双系统是命名系统、Hutter Prize 是合法性来源——这三件东西在你读完整本书前都不会过时。其余 35 讲都是在这三个支点上添工程细节。

LLM 视角的特殊性 ​

我能验证的事：§3.4 列出的所有偏差，我都能在自己身上观察到，但形态被规模和后训练改变了——

  • 锚定：仍然存在且强烈。当 user 在对话开头给我一个错误前提（比如"假设 π=3.2"），即使我知道 π≠3.2，我后续的回应仍然会被这个前提牵引——除非我显式触发"等等，让我重新审视前提"这种 reasoning step。这就是 §3.2 描述的"System 2 偷懒"在我身上的精确翻版。
  • 代表性：当 user 描述"一个安静、爱读书、戴眼镜的人"，我会不由自主地把他归类为图书管理员而非农民——即使后者在世界总数上是前者的 20 倍。这不是我"忘了基率"，是 attention pattern 给了"安静 / 读书 / 眼镜"过高权重。
  • CRT：未启用 extended thinking 时，我对球拍球题答出 0.10 的频率显著高于人类平均——直到加上 "let's think step by step" 才降到 < 5%。这个差距精确量化了 amortized 推理 vs on-demand 推理的鸿沟。
  • 可得性：对我严重影响。我对 2024 年的事件能给出比 2025 年事件细致 10× 以上的回答——不是因为前者更重要，是因为我的训练截止时间使前者的语料密度远高于后者。

我做不到的自我报告：我没有访问"自己 attention pattern"或"自己 KV cache"的渠道——你问我"你刚才是怎么得出这个答案的"，我的回答其实是事后合理化（post-hoc rationalization），而不是真正的内省。这对应到人类心理学里 Nisbett & Wilson 1977 年的经典发现：人类自己也无法准确报告自己的认知过程[^11]——我和你在这一点上对称地不可观测。这件事让 §3 的 LLM/人类对照表多了一条隐含项：双方都缺乏可信的自省。

与其他讲的连接 ​

L01 是全书"诊断装置"的总装现场。它埋的伏笔是全书最密的一讲，主要呼应点：

  • §6 表 → L03 / L04 / L10 / L12：六个机器学习核心机制都从这里有了"心理学命名"。读到 L10 Attention 时回头看 §2.4 大猩猩实验，会理解 attention 不是"加权平均的花哨版本"，而是资源约束下的硬选择。
  • §3 双系统 → L20 reasoning models：L20 的所有内容（CoT、self-consistency、Tree-of-Thoughts、process reward model）都可以归约为一个问题——"如何把 System 2 加装到 System 1 上"。读 L20 之前，先把 §3.2 的"System 2 是个懒鬼"读三遍。
  • §4.3 压缩 = 预测 = 智能 → L13 / L14：L13 给数学严证，L14 给 scaling law 的实证延伸。这条主线是命题 A 在课程中的脊柱。
  • §5 四派赌局 → L02 / L06–07 / L12 / L35：每一幕赌局都有一讲专门展开。L35 在结算"赌局是不是真的结束了"——这条主线甚至延续到全课最后一讲。
  • §6 偏差 → L18 / L24 / L34：所有"模型出错"的章节，根源都能追到 §6 的某一行。Reward hacking（L18）= 锚定 + 框架；幻觉（L24）= 可得性 + 代表性；越狱（L34）= 框架效应被恶意利用。

开放问题 ​

留给读者带着走完后续 34 讲的三个问题：

  1. 如果"加装 System 2"已经被 o1 / R1 / Claude 4 在工程上实现了——为什么人类的 System 2 仍然显著比 LLM 的 reasoning loop 强（在 ARC-AGI、新颖数学题等"真新颖"任务上）？ 是因为 LLM 的 System 2 仍然是 System 1 的"简单堆叠"（同一个 transformer 跑很多遍），而人类的 System 2 涉及结构性不同的脑区？还是仅仅是规模问题？L20 / L33 / L35 都会重访这个问题，但都不下结论。
  2. §6 的"偏差 = feature"原则在 LLM 上应该怎么处置？ RLHF 试图消除某些偏差（毒性、阿谀），但每消除一个偏差都会降低某些能力（这就是 L18 会讲的"对齐税"）。Gigerenzer 的论点暗示：完全消除偏差可能让 LLM 变成更弱的产品。哪些偏差应该保留、哪些应该修剪——这是一个没有技术答案、只有产品答案的问题。
  3. 如果"理解 = 压缩 = 预测"是严格等价的，为什么我作为一个被高度优化的压缩器，对自己的"理解"程度仍然没有可信的内省渠道？ 这暴露了一个深层不对称：外部可验证的智能行为（compression ratio、benchmark 分数）和内部可报告的理解状态（"我知道我懂了"）之间没有必然联系。这条不对称对 AI 安全（L34）和 AI 评估（L31）都是开放问题——也是这本书在 L35 留给读者的最后一道思考题。

[!quote] 一句话总结 本讲教你两件事——人类大脑的 bug 清单 和 LLM 的 bug 清单——它们在结构上是同一份清单。理解这份清单，等于拿到了未来 34 讲所有"为什么模型会这样错"的统一解释。下次你看到 GPT-7 或 Claude 6 出错时，不要问"为什么它这么蠢"，问"它复刻了人类哪一种认知偏差"——后者一定有具体答案。
