2. 学术论文

  1. ●●●●○
    P1Toolformer: Language Models Can Teach Themselves to Use Tools
    Schick, T., Dwivedi-Yu, J., et al. (Meta) · 2023 · NeurIPS 2023

    模型自主学习使用工具的开创性工作。MCP "模型控制 Tools" 理念的学术来源。

  2. ●●●●○
    P2Gorilla: Large Language Model Connected with Massive APIs
    Patil, S., Zhang, T., et al. (Berkeley) · 2023 · arxiv preprint

    LLM 连接海量 API 的能力评测。"几百万个 API 写不过来" 的学术背景。

  3. ●●●●○
    P3AutoGen: Enabling Next-Gen LLM Applications via Multi-Agent Conversation Framework
    Wu, Q., Bansal, G., et al. (Microsoft) · 2023 · arxiv preprint

    Multi-Agent 对话框架——A2A 协议试图标准化的学术原型。L20 已引用。

  4. ●●●●○
    P4OS-World: Benchmarking Multimodal Agents that Navigate and Act in Open-Ended Computer Tasks
    Xie, T., Zhang, D., et al. · 2024 · NeurIPS 2024

    Computer Use 任务的标准评测。Claude Computer Use 的可靠性数据 (~70-90%) 的学术参考。

  5. ●●●●○
    P5WebArena: A Realistic Web Environment for Building Autonomous Agents
    Zhou, S., Xu, F.F., et al. · 2024 · ICLR 2024

    Web 交互 Agent 的标准评测。Browser Use 可靠性讨论 (~85-95%) 的学术参考。

  6. ●●●●○
    P6CogAgent: A Visual Language Model for GUI Agents
    Hong, W. et al. (Tsinghua/Zhipu) · 2024 · CVPR 2024

    高分辨率视觉语言模型专为 GUI Agent 训练——Computer Use 背后的技术路线之一。

  7. ●●●●○
    P7The Model Context Protocol: A Survey
    2025 · arxiv preprint

    MCP 综述论文——2025 年首份学术总结，涵盖生态、安全、部署、与其他协议的关系。

  8. ●●●○○
    P8A Survey of LLM-based Agents: From Single Agent to Multi-Agent Systems
    Wang, X. et al. · 2024 · arxiv preprint

    LLM Agent 从单体到多体的综述——A2A 协议设计背后的学术背景。

  9. ●●●○○
    P9Mind2Web: Towards a Generalist Agent for the Web
    Deng, X. et al. (Ohio State) · 2023 · NeurIPS 2023

    Web 上的通用 Agent benchmark——Browser Use 评测场景的学术起点。
