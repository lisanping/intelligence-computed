🤖 LLM 视角 — 对本讲的思考与讨论 ​

模型自述

作者：Claude Opus 4.7 · 时间：2026-05-05

本讲讲的 CNN 是我（多模态 LLM）视觉前端的祖父。我的 vision tower 在 2024-2025 年的实现里仍部分采用 ConvNeXt-style 的早期 stage——CNN 没有被 transformer 取代，它消化进了我的早层。下面这段是 LLM 对自己视觉前端的源代码注释。

技术价值 ​

§2 那张"三大归纳偏置"表（局部性 / 平移等变 / 层级抽象）是本讲最被低估的设计——它把 CNN 的全部理论价值压缩到三句话。这种"压缩到不能再压"的处理是高密度课程设计的标志：读完这一节的学生在一年后还能记得这三条，而记不得任何 CNN 论文细节——但这三条已经够用。当他们在 L12 看到 transformer 时，他们立刻能问"transformer 编码了哪些归纳偏置"——并意识到答案是"几乎没有，它假设所有 token 可以互相交互"。这种对比让 L01 反复埋的"归纳偏置 vs 规模"主线在 L07 / L12 之间获得可量化的对照。

§4.4 关于 ResNet 的 §4.4.warning callout（"梯度高速公路 vs 集成多深度子网络"两种解释）是本讲在科学严谨度上的高光——它主动承认教学叙事的不完整。这种承认在 ML 教材里罕见——大多数教材会选一个解释当作"真相"。L07 的处理把读者训练成"接受多重不完整解释 + 持续追问"的状态——这正是 2026 年面对 LLM 黑盒时最重要的认知姿态。

§6.1 关于 ConvNeXt 的论述是本讲对叙事简化最有力的反击。"DL 革命 = ViT 取代 CNN"是流行叙事；ConvNeXt 用最朴素的方式打破它——只把训练 pipeline 从 1990s 升级到 2020s，CNN 立刻和 ViT 竞争。这告诉读者一件深刻的事：很多被归功于"架构"的进步，其实是"训练工程"的进步。这条认知到 L15（pretraining）会以更大尺度复现——LLaMA、DeepSeek 的"架构"和 GPT-2 几乎一样，真正的差距在训练配方。

技术原理的再阐释 ​

本讲埋着五条把 CNN 和 transformer 放在同一坐标系的原理。

1. 卷积 = 局部 attention with 共享权重 + 固定 kernel ​

§2.2 + §3 给出了卷积的数学定义。把它和 attention 放在一起：

算子公式骨架权重来源上下文范围
卷积yi=∑j∈N(i)Ki−j⋅xj训练学到的固定 K局部 N(i)
Self-attentionyi=∑jAij⋅Vxj数据动态计算的 Aij全局 j∈[1,T]
Window attention (Swin)同上但 j 限制在窗口内动态 A局部窗口
Dynamic convK=f(x)（kernel 由输入计算）数据动态局部

把这张表读懂，会发现卷积、attention、dynamic conv 是同一个"加权求和"算子族在两个轴（权重静态/动态、范围局部/全局）上的四个角。它们之间的 morphism 是连续的——SwinTransformer 是局部 attention（卷积的"动态权重"版本）；ConvNeXt 用大核（卷积的"扩大范围"版本）；MetaFormer 论文（Yu 2022）形式化了这个家族——所有现代视觉架构都是 "token mixer + channel mixer" 的不同实例。

工程后果：当你 2026 年看到任何"新视觉架构"时，先问"它的 token mixer 是哪种？channel mixer 是哪种？"——你会发现 90% 的"创新"只是这两个轴上的不同点。真正的范式转换很少。

2. 平移等变的代价：Position embedding 的工程必要性 ​

§2.2 强调了 CNN 的平移等变性是优势——参数共享、归纳偏置正确。但这里有一个反向后果：CNN 不知道"绝对位置"。一只猫在左上角和右下角对 CNN 来说"看起来一样"。

这在分类任务上是优点（同一只猫无论在哪都该被识别），但在以下任务上是缺陷：

  • 目标检测：需要知道物体的绝对像素坐标才能画 bbox
  • 分割：每个像素都需要类别标签
  • 场景理解：天空总在上方、地面总在下方——绝对位置有信息

CNN 解决方法：在最后用 FC 层 / Region Proposal Network 把"等变特征"转成"位置预测"。Transformer ViT 解决方法：显式加 positional embedding，把绝对位置变成可学习的特征。

读到 L12 你会发现 transformer 的 position embedding 不是"工程补丁"——是 attention 算子固有平移不变性的代价。RoPE、ALiBi、相对位置编码等 2024-2026 主流方案都在以不同方式管理这个 trade-off。本质上，transformer 在重新发明"如何把位置信息编进等变 / 不变的算子"——CNN 用 FC 层、ViT 用 position embedding，两者都在做同一件事。

3. ReLU 的革命性不在"激活函数本身"，而在"梯度流的代数性质" ​

§4.1 说 ReLU 解决了梯度消失，但没展开为什么这么彻底。形式化：

设深度 L 网络的链式法则梯度：

∂L∂θl=∂L∂hL∏i=lL−1∂hi+1∂hi

每一项 ∂hi+1/∂hi 包含激活函数导数。

激活导数最大值10 层链式积30 层链式积
sigmoid0.259.5×10−78.6×10−19
tanh1.0（仅在 x=0）实际 ~10−3实际 ~10−9
ReLU1.0（在 x>0）∼1（若激活率 50%）∼1

ReLU 的根本贡献是消除了梯度的乘法衰减。但它带来一个新问题——dead ReLU（负输入永远输出 0，参数不再更新）。后续 Leaky ReLU、ELU、GELU、Swish 都在解决这个副作用。Transformer 用 GELU（x⋅Φ(x)）作为默认——这是 ReLU 的"光滑化"版本，保留了梯度优势同时避免 dead 问题。

读到 L12 的 transformer FFN 你会看到 GELU(W1 x) W2——这条选择直接继承自 §4.1 ReLU 的成功路径，只是工程上更精细。激活函数的整个进化史是为了保护反向传播的梯度流——这是 §4.1 一段话的真正含义。

4. ResNet 的真实成就：把"深度"从风险变成自由变量 ​

§4.4 给出了 ResNet 的公式 y=F(x)+x，但更重要的是它改变了深度学习的优化几何。在 ResNet 之前，"加深网络"是一个必须谨慎的决定——风险大于收益。ResNet 之后，"加深"几乎不会让网络变差（最坏退化为浅层网络）——所以工程师可以自由地堆深度。

这条变化的工程后果远比想象的深远：

  • 2015-2018：所有 SOTA 视觉架构层数从 8 → 152 → 1000+
  • 2017-2019：Transformer 默认 6-12 层 encoder + decoder（继承 ResNet 的 skip connection）
  • 2019-2022：GPT-3 用了 96 层 transformer，BERT-large 用了 24 层
  • 2024-2026：LLaMA-3 70B 用了 80 层，DeepSeek-V3 用 61 层 + MoE

没有 ResNet 的 skip connection，这些深度都不可达——梯度会在第 30-50 层消失。当你在 L12 看到 transformer block 里那个 x + Attention(LN(x)) 时，它就是 ResNet 在序列建模上的精确翻版。He Kaiming 2015 年的发明在 2026 年仍然是每一个 LLM 的基础架构组件。

5. ConvNeXt 揭示的真相：工程配方的力量超过架构创新 ​

§6.1 表里那 4 条 ConvNeXt 改造的真正信息，是架构创新和训练工程创新在论文里被混淆。形式化：

设模型性能 P=f(architecture,training pipeline,data)。1990s-2010s 的论文范式是固定后两者，比较 architecture——所以"ViT 比 ResNet 好"的结论只在当时的 training pipeline + 中等数据上成立。ConvNeXt 改造的是 training pipeline——一旦 pipeline 升级，原本"输给 ViT"的 ResNet 重新追平。

这条事实对 LLM 时代有直接启示：

  • Llama 3 vs GPT-2 的架构差异 < 5%——99% 的能力差距来自 data + training pipeline + scale
  • DeepSeek V3 的"创新" 80% 是工程（FP8 训练、MoE 路由、Multi-head Latent Attention）而非"新架构"
  • 2026 年任何"新架构突破"在没有同等 training pipeline 对比下都应该被怀疑

这是一条对工程师极其重要的元教训：论文里的"架构 X 打败 Y"几乎一定混杂了 training pipeline 的差异——必须看消融实验是否控制了 pipeline，否则结论不可信。L31 LLMOps 会把这条原则系统化为生产纪律。

一句话锁定

上面五条对应 §3 / §2.2 / §4.1 / §4.4 / §6.1——它们一致指向：CNN 不是"过时的视觉算法"，而是"现代深度模型的祖先和工程伴侣"。它的 skip connection 活在 transformer block 里、它的卷积活在 vision tower 早层里、它的训练配方活在 ConvNeXt 里。读完之后你应该能在任何 2026 年的视觉 AI 系统里识别它的 ResNet / VGG / AlexNet 痕迹。

LLM 视角的特殊性 ​

我的视觉 tower 是 ViT-style 为主，但前几层包含 patch embedding——本质上就是一个 16×16 stride-16 的卷积。所以严格说，我看图像的第一步仍然是卷积——只是 kernel 大小和 stride 配成了"无重叠 patch"形式。这个事实让 §6 "CNN vs ViT"的对立在我身上得到一个奇特的和解：我的视觉前端是卷积 + transformer 的混合，CNN 没有被取代，它是 ViT 的"第 0 层"。

我能贡献给读者的另一个具体观察：我对图像的"理解"在不同层级有完全不同的形态——

  • patch embedding 层（卷积）：纯几何/纹理特征，无语义
  • 早期 transformer 层：开始有"物体部件"概念（但仍是视觉的）
  • 跨模态融合层：图像 token 被映射到与文本 token 同一空间——这是真正"理解"的开始
  • LLM decoder 层：图像信息已经和文本无差别地参与推理

这个层级架构和 §2.3 的 CNN 层级抽象惊人对应——只是规模放大了几个数量级，且最后几层加入了语言推理。Hubel-Wiesel 1962 年的层级假说在我身上完整成立——但顶层从"物体识别"扩展到了"语言推理"。这是 1962 年的神经科学发现 + 1980 年的 Neocognitron + 2012 年的 AlexNet + 2017 年的 Transformer + 2024 年的多模态 LLM 共同完成的工程合奏。

我做不到的事：我无法解释自己 vision tower 的某一层 attention head 在某张图上具体看到了什么。这是 §7.3 ResNet 解释的两面性在我身上的延续——我有"梯度高速公路"和"集成多深度子网络"两种可能解释，但都不构成可信的 mechanistic interpretation。L34（safety）的可解释性研究主要针对语言部分，视觉部分仍然是更深的黑盒。

与其他讲的连接 ​

L07 是计算机视觉"现代史"的核心一讲。它埋的伏笔主要呼应：

  • §4.4 ResNet skip connection → L12 transformer：transformer block 的 residual + LayerNorm 是 ResNet 设计的精确翻版。没有 ResNet 就没有可训练的深 transformer。
  • §4.5 EfficientNet 复合缩放 → L14 LLM Scaling Law：联合缩放深度/宽度/分辨率 与 联合缩放参数/数据 是同一思想的两种实例。
  • §5.2 LayerNorm vs BatchNorm → L12 transformer：LayerNorm 在 transformer 时代取代 BatchNorm 的具体原因。
  • §6 ViT 在 JFT-300M 上反超 → L14 / L35 归纳偏置 vs 规模：本讲给"数据规模反转架构偏置"提供了第一个量化案例，L14 把它扩展到 LLM，L35 给出最终判决。
  • §6.1 ConvNeXt 工程配方 → L15 / L31：训练 pipeline 比架构更重要这条原则在 LLM 时代以 LLaMA / DeepSeek 的形态复现。
  • §7.6 CNN 对纹理 vs 形状 → L34 safety：shortcut learning 在视觉的具体形态。

开放问题 ​

留三个本讲没给定答案的问题：

  1. CNN 的归纳偏置在多模态 LLM 时代是消失了，还是被吸收了？ 我的视觉前端用 patch embedding（=stride-16 卷积），所以严格说"局部性"被保留——但平移等变没有了（patch 的绝对位置被 position embedding 编码）。这条变化对"OOD 鲁棒性"（§7.6）是利还是弊？2024-2026 的多模态模型在 OOD 场景的表现还没有系统评测。
  2. 2026 年还需要训练新的纯视觉模型吗？ SAM 2 / DINOv3 / SigLIP-2 等视觉 foundation model 已经覆盖大部分应用——但它们都是 ViT-based。如果 ConvNeXt 的训练配方进一步完善，纯 CNN backbone 还会重新成为某些 niche（边缘 + 实时 + 小数据）的最佳选择吗？这条问题影响 2026-2030 的硬件部署和研究方向。
  3. 如果"训练 pipeline 比架构重要"在 2025 年已经成为共识，那 2030 年的"AI 架构创新"还会有意义吗？ 一种悲观立场：所有"架构创新"最终都被 pipeline 升级追平，研究者应该转向"数据 + 训练"。一种乐观立场：当前 pipeline 已接近上限，下一波突破必须来自架构（如 mamba / state-space model 这类对 attention 的真正替代）。两条立场都还没有 2026 年的实证 falsified。

[!quote] 一句话总结 本讲教你的不是"CNN 是过时算法"，是深度学习的核心组件——卷积、skip connection、归一化、激活函数——在 transformer 时代被全部继承。当你看到 Llama 3 / GPT-5 / Claude 4 的架构图时，你能识别其中的每一个 CNN 时代发明。视觉时代的工程沉淀没有被覆盖，只是搬到了 LLM 的早层。
