第 7 讲 · 卷积神经网络 — 把先验编码进结构 ​

如果让机器自己学特征呢？CNN 的答案不是"完全放手"——而是把人类对视觉世界的三条直觉编码进网络结构，让特征从数据中自动涌现。

这是"归纳偏置"路线的巅峰之作。它在 2012 年炸翻了 ImageNet，统治计算机视觉十年；2020 年被 Vision Transformer 挑战；2022 年又用 ConvNeXt 反击；2024 年依然占据60% 以上的工业部署。

这一讲讲 CNN 的每一寸——从 1962 年 Hubel-Wiesel 的猫脑实验，到 2012 年 AlexNet 那两块 GTX 580 GPU，到 2024 年 ConvNeXt v2 的卷土重来。

前置知识核心产出建议用时
L03（梯度优化）、L06（手工特征的天花板）① 理解 CNN 的三大归纳偏置（局部性、平移等变、层级抽象）及其数学表达 ② 走完 LeNet → AlexNet → VGG → GoogLeNet → ResNet → DenseNet → EfficientNet → ConvNeXt 的演进 ③ 看清 BatchNorm / Dropout / 残差 / Inception 这些工程贡献 ④ 理解 ViT 的挑战与 ConvNet 的反击 ⑤ 拿到 L08（CV 应用：检测/分割/SAM）和 L12（Transformer）的伏笔阅读 ~75 分钟 + 动手 ~30 分钟

从上一讲到这一讲 ​

L06 结尾留下问题：谁来选特征？人类还是机器？

本讲给出回答：让机器自己学。但这件事比"完全放手"复杂——你不能把网络当作完全空白。如果你这么做，网络要么不收敛，要么过拟合，要么需要不可承受的算力。

CNN 的真正贡献是「半放手」：把人类对视觉世界的三条最强直觉写进网络的连接结构（不是写进数据、不是写进损失函数）——剩下的让数据填空。这就是我们在 L03 预埋的"归纳偏置"（Inductive Bias）：模型对数据生成过程的先验假设。

核心概念

归纳偏置 = 模型在没有数据的情况下倾向于的解的集合。所有学习算法都有归纳偏置（"完全没有偏置"在数学上等价于"完全无法泛化"，No Free Lunch 定理[1]）。问题不是要不要有偏置，而是有什么偏置。CNN 的胜利在于它的偏置和图像世界的真实结构高度匹配。

1. 前史：从猫脑到 Neocognitron ​

[!quote] 历史 1958 年，哈佛医学院。两位年轻的神经生理学家 David Hubel 和 Torsten Wiesel 给一只麻醉的猫植入电极，监测视觉皮层 V1 区的神经元活动。他们想看：当猫看不同的视觉刺激时，哪些神经元会激活？

实验进行了好几个月，几乎一无所获——他们用各种点、各种圆、各种形状刺激猫，神经元死气沉沉。

一天，他们换玻片时不小心把玻片在投影上滑过一道边缘的影子——某个神经元突然剧烈放电[2]。

他们意识到：那个神经元只对特定方向的边缘有响应。换一个方向，它就沉默了。

1962 年的论文 Receptive Fields, Binocular Interaction and Functional Architecture in the Cat's Visual Cortex[3] 描述了 V1 区的两类神经元：

  • 简单细胞（Simple Cells）：对特定方向、位置的边缘有响应
  • 复杂细胞（Complex Cells）：对边缘有响应但对位置宽容——边缘移动一点点也仍然激活

这两类细胞构成层级——简单细胞 → 复杂细胞 → 更高级特征。这一发现奠定了现代视觉神经科学。Hubel 和 Wiesel 因此获得 1981 年诺贝尔生理或医学奖。

1.1 Neocognitron（1980）：第一个卷积神经网络 ​

[!quote] 历史 1980 年，日本 NHK 放送科学技术研究所。Kunihiko Fukushima（福岛邦彦）发表论文 Neocognitron: A Self-organizing Neural Network Model for a Mechanism of Pattern Recognition[4]。

Neocognitron 是第一个包含卷积、池化、层级结构的神经网络——比 LeNet 早 9 年，比 AlexNet 早 32 年。它的设计完全基于 Hubel-Wiesel 的"简单细胞 + 复杂细胞"层级：

  • S-cell 层（简单细胞）= 卷积层
  • C-cell 层（复杂细胞）= 池化层
  • 多层叠加 = 层级抽象

但 Fukushima 没有反向传播——他用了一个手工设计的无监督学习规则，效果有限。Neocognitron 没引起大轰动。

2021 年福岛获鲍尔奖（Bower Award），同年的 Neural Networks 杂志专门出了一期纪念。Fukushima 在采访中说：「我做这件事比 LeCun 早，但我的运气没他好——我没赶上反向传播的浪潮。」[5]

1.2 LeNet-5（1989-1998）：第一个能用的 CNN ​

[!quote] 历史 1980 年代末，Yann LeCun 在贝尔实验室，他的同事包括 Léon Bottou、Yoshua Bengio 等。他们的目标客户：美国邮政服务——读手写邮政编码。

1989 年，LeCun 等发表 Backpropagation Applied to Handwritten Zip Code Recognition[6]——第一次把反向传播 + 卷积层 + 池化层组合起来。1998 年的最终版本叫 LeNet-5[7]：

Input(32×32)
  → Conv(6@5×5) → Pool → Conv(16@5×5) → Pool
  → FC(120) → FC(84) → Output(10)

6 万参数，在 MNIST 上达到 99.2% 准确率。美国邮政部门实际部署了它——1990s 中期开始，全美邮政编码读取的相当大比例由 LeNet 完成。

但学术界主流不在乎。1990s 主流 ML 是 SVM、Random Forest——它们有漂亮的统计学习理论支撑，CNN 看起来像"炼金术"。LeCun 自己后来说："我从 1989 年到 2010 年，整整 21 年在用 CNN 解决实际问题——但每次申请基金都被拒。"[8]

1.3 为什么 1990s-2000s CNN "卡住"了 ​

缺什么当时状况
数据MNIST 6 万张 28×28 → 太简单；ImageNet 还要等 2009
算力CPU 训 LeNet 一周；同期 SVM 几小时
优化技巧没有 ReLU、没有 BN、没有 Adam、没有 He 初始化——网络越深越难训
GPU 软件CUDA 2007 才发布，深度学习框架（Theano/Caffe/PyTorch）都还没出现
学术自信Vapnik 的 SVM 有 VC 维理论；CNN 没有等价的理论保证

CNN 不是没人做——只是没人能扩大规模。这个状况持续到 2012 年。

2. CNN 的三大归纳偏置 ​

CNN 的成功不在"它有多巧"——在于它的结构假设和图像世界的真实结构高度对齐。三条假设，每一条都对应图像世界的一个真实属性。

2.1 局部性（Locality）：重要的事发生在邻居之间 ​

假设：图像中相关的像素是空间上相邻的。 实现：每个卷积核只看图像的一个小区域（典型 3×3 或 5×5）。

直觉

全连接网络是"每个像素跟所有其他像素都有关系"——在 224×224 RGB 图片上意味着 150,528×150,528≈2.3×1010 个连接。这不仅算力不可承受——它假设了一件错的事：图片左上角的像素和右下角的像素没有直接关系。卷积核 3×3 = 9 个参数，用局部性假设干掉了大部分无用连接。

反例（局部性假设失效的场景）：

  • 长程依赖的文本（"他从北京来" — "他" 和 "北京" 跨越很远）→ L10 RNN / L12 Transformer 解决
  • 图结构数据（社交网络、分子）→ Graph Neural Network 解决
  • 全局上下文重要的图像任务（如理解整张图片的语义）→ ViT 部分受益，但 CNN 也有应对（dilated conv, attention layers）

2.2 平移等变（Translation Equivariance）：同一模式可以出现在任何位置 ​

假设：一只猫在图片左上角和右下角应该被识别为同一只猫。 实现：参数共享——同一个卷积核在每个位置使用相同的参数。

数学上：

Conv(Translate(x))=Translate(Conv(x))

——卷积运算与平移对易（commute）。这就是"等变"（equivariant）。

常见误区

CNN 是平移等变，不是平移不变。卷积层输出会跟着输入一起平移。池化层的作用之一就是把"等变"近似为"不变"——通过 max/avg 池化，特征图的精确位置变得不那么重要。完全的"平移不变"需要 global pooling 或 FC 层。

核心概念

参数共享的最戏剧化效果：参数量爆炸性减少。一个 3×3 卷积核只有 9 个参数（加偏置 10 个），但作用于整张图的每一个位置。等效全连接层需要数百万。这种"在所有位置共享同一组参数"的思想，在 L12 的 Transformer 里以 self-attention 的形式重生——只是 Transformer 的"位置"是 token 位置而非像素位置。

2.3 层级抽象（Hierarchical Composition）：从边缘到眼睛到猫 ​

假设：视觉特征是层级组合的——简单特征组合成复杂特征。 实现：堆叠多层卷积 + 池化，每一层接受野（receptive field）逐级扩大。

经验观察（Zeiler-Fergus 2014 Visualizing and Understanding Convolutional Networks[9]）：

层级学到的特征
第 1 层边缘、角点、颜色块——和 V1 简单细胞惊人地相似
第 2 层弧线、纹理、简单形状（眼睛、鼻子、轮子）
第 3-4 层物体部件（人脸、车轮、动物的腿）
第 5+ 层完整物体（猫、狗、汽车）

[!quote] 历史 Zeiler-Fergus 论文是第一次用反卷积（deconvolution）可视化 CNN 内部学到的特征。他们的发现震惊了视觉社区——CNN 的浅层确实学到了边缘检测器，深层学到了物体部件。这件事和 Hubel-Wiesel 的猫脑发现对应得让人不寒而栗。

但要警惕：这种相似性是粗略类比——CNN 与真实视觉皮层在算法细节上有大量差异（生物视觉有反馈连接、跨皮层投射、注意力调制等机制，CNN 都没有）。

[!example] 动手 在 demo/feature_map_viz.py 里运行特征图可视化，亲眼看到 MNIST 上训练的小 CNN 学到了什么。第 1 层有方向性的笔画检测器，第 2 层开始拼出数字的部件——一切都自动涌现。

3. 卷积运算：数学细节 ​

这一节给出关键运算的精确定义。如果你已经熟，可以跳到 §4。

3.1 二维卷积 ​

输入特征图 X∈RH×W，卷积核 K∈Rk×k：

Y[i,j]=∑m=0k−1∑n=0k−1X[i+m,j+n]⋅K[m,n]

（注：严格意义上这是互相关（cross-correlation）；真正的"数学意义上的卷积"会翻转 K。深度学习里习惯叫"卷积"——因为如果 K 是学习的，翻不翻转都没差别。）

3.2 多通道卷积 ​

输入 X∈RCin×H×W（Cin 个通道），卷积核 K∈RCout×Cin×k×k：

Y[cout,i,j]=∑cin∑m,nX[cin,i+m,j+n]⋅K[cout,cin,m,n]

每个输出通道是所有输入通道的线性组合。

3.3 步长（stride）与填充（padding） ​

  • stride s：滑动步长。s=2 时输出特征图的空间尺寸大约缩小一半。
  • padding p：在输入边缘填充 p 圈零，让输出尺寸可控。

输出尺寸：

Hout=⌊Hin+2p−ks⌋+1

3.4 池化（Pooling） ​

  • Max pooling：在 k×k 窗口内取最大值
  • Average pooling：在窗口内取平均值
  • Global average pooling：对整个特征图取平均（NIN 引入[10]，被广泛用于 ResNet 等）

池化的两个作用：

  1. 降维——减少后续层的计算量
  2. 平移容忍（partial translation invariance）——特征精确位置变得不那么重要

常见误区

"Pooling 是 CNN 的本质"——错。现代架构（ConvNeXt、EfficientNet v2）大量用 stride-conv 替代 max-pool，证明 pooling 不是不可或缺。它的降维功能可以由 stride-conv 替代，平移容忍功能在更深的网络里通过参数学习获得。

4. 三大里程碑：AlexNet → VGG → ResNet ​

4.1 AlexNet（2012）：分水岭 ​

[!quote] 历史 2012 年 9 月 30 日，ImageNet ILSVRC 大赛公布。

Hinton 团队（Alex Krizhevsky 一作，Ilya Sutskever 二作，Hinton 三作）的网络：top-5 错误率 15.3%。 第二名（用传统 SIFT + Fisher Vector + SVM）：26.2%。

这个差距是 ImageNet 历史上前所未有的。论文标题朴素得像作业：ImageNet Classification with Deep Convolutional Neural Networks[11]。

Krizhevsky 当时是 Hinton 的 PhD 学生。他在自家的两块 NVIDIA GTX 580（每块 3GB 显存）上训练，写了上千行手工 CUDA 代码——因为当时还没有 PyTorch、TensorFlow，连 Theano 都还不成熟。整个训练跑了 6 天[12]。

AlexNet 的四个关键工程创新：

创新解决的问题数学/工程后续命运
ReLU 激活sigmoid/tanh 梯度消失，训练慢ReLU(x)=max(0,x)默认激活函数，统治至今
Dropout过拟合（参数 6000 万）训练时随机关闭 50% 神经元标准正则化技术
GPU 训练算力——CPU 训这个网要数月手写 CUDA，2 张 GTX 580开启"用 GPU 训深度学习"的时代
数据增强数据量不够，过拟合翻转 + 裁剪 + PCA 颜色抖动标准技巧

核心概念

ReLU 的简洁性是革命性的。它不是"更聪明"的激活函数——它比 sigmoid 简单 100 倍。但它解决了一个几十年的瓶颈：深层网络的梯度消失。sigmoid 的导数最大值 0.25，10 层网络的梯度被乘 0.2510≈10−6；ReLU 在正区间导数恒为 1，梯度不衰减。简单赢了复杂——这是深度学习里反复出现的主题。

直觉

AlexNet 是"工程的胜利，不是理论的胜利"。它没有任何全新的算法发明——所有组件（卷积、池化、ReLU 概念、Dropout 概念、GPU 训练、数据增强）都已经存在。AlexNet 的功劳是第一次把它们正确地组合在一起、在一个足够大的数据集上。这一点对当代 LLM 同样适用——Transformer 也是工程胜利。

[!abstract] 呼应线 🔗 物理账单（physical-bill）（L03 预埋 → L07 首次实账单 → L12 → L14 → L22 → L31）：AlexNet 的 6 天双 GPU 训练，是深度学习“算力换能力”范式的第一次工业级示范。到了 L12，账单从“天”升级到“显存墙”；到 L14，升级为“幂律 + 数据中心资本开支”。

4.2 VGG（2014）：深度的力量 ​

[!quote] 历史 2014 年 ImageNet：牛津大学 Visual Geometry Group 的 VGG-16 / VGG-19[13] 把网络做到 16-19 层（AlexNet 是 8 层），错误率降到 7.3%。

VGG 的设计哲学：极简。

  • 所有卷积核统一用 3×3——多个 3×3 串联可以达到 5×5、7×7 的等效感受野，但参数更少：
    • 一个 7×7 卷积：49 个参数
    • 三个 3×3 串联：3×9=27 个参数（且引入了更多非线性）
  • 堆叠模块化：Conv-Conv-Pool 反复

VGG 的影响：

  • 至今仍是风格迁移（neural style transfer）和图像感知损失（perceptual loss）的事实标准 backbone
  • "用更深更窄替代更浅更宽"成为通用设计原则

4.3 GoogLeNet / Inception（2014）：宽度的力量 ​

[!quote] 历史 2014 年 ImageNet 冠军实际是 Google 的 GoogLeNet（致敬 LeNet-5）[14]——错误率 6.67%。22 层但参数量只有 VGG-16 的 1/12。

论文一作 Christian Szegedy 后来去了 Google Brain，2015 年又一作了 Batch Normalization[15]——和 ResNet 并列的两大训练神器。

Inception 模块的核心想法：让网络自己选该用 1×1、3×3 还是 5×5 卷积，全部并行。

        ┌─→ 1×1 conv ─→ ┐
input ──┼─→ 1×1 → 3×3 ─→├─→ concat
        ├─→ 1×1 → 5×5 ─→┤
        └─→ pool → 1×1 ─→┘

1×1 卷积的妙处：跨通道线性组合 + 降维。它不改变空间尺寸，但能把 256 通道压成 64 通道。这一思想被后续所有架构继承（ResNet bottleneck、MobileNet 的 pointwise conv、ConvNeXt）。

4.4 ResNet（2015）：深度的逆袭 ​

[!quote] 历史 2014 年之后，"加深网络"似乎是必然方向。但人们尝试时遇到了反直觉现象：56 层的网络在训练集上比 20 层网络更差[16]——不是过拟合（连训练误差也更高），而是优化困难。

2015 年 12 月，He Kaiming（何恺明，时任 MSRA 研究员）等人发表 Deep Residual Learning for Image Recognition[16:1]。ResNet 一举把 ImageNet 错误率拉到 3.57%（已低于人类水平 ~5.1%[17]）。论文获 CVPR 2016 best paper。

ResNet 是深度学习史上被引用最多的论文之一，至今 25 万+ 引用[18]。

残差连接（Skip Connection / Residual Connection）的核心：

y=F(x)+x

让网络学习的是残差 F(x)（"还差多少"），而不是直接学习目标映射 H(x)。如果某一层没什么可学的，F(x) 趋近于零，输出就等于输入——网络退化为恒等映射。

核心概念

残差连接的真正贡献是给优化器一条退路。最坏情况下，网络可以"摆烂"——一直输出输入。这意味着深层网络至少不比浅层差。这件事改变了"加深网络"的风险：以前加深可能让性能下降，现在加深至少不会让性能变差。

这一思想被 Transformer 完整继承——Transformer 的每一层都是 output = LayerNorm(x + Attention(x)) 的形式（或更现代的 PreLN）。L12 会展开。

常见误区

早期解释残差连接为「梯度高速公路」（gradient highway）——梯度可以直接穿越层。但 Veit 等 2016 年的论文 Residual Networks Behave Like Ensembles of Relatively Shallow Networks[19] 给出了另一种解读：ResNet 在功能上等价于多个不同深度子网络的集成。每个 skip 决定了"用还是不用这一层"，N 层 ResNet 实际上是 2N 个子网络的隐式集成。

哪种解释更准确？2024 年综述认为两者都对——梯度流动和集成效应共同作用。教学时可以先讲梯度高速公路（直观），高级读者再补集成视角。

4.5 后续演进：DenseNet → SENet → EfficientNet ​

年份网络关键创新参数量
2017DenseNet[20]每层连接到所有后续层（极致 skip connection）比 ResNet 少
2017SENet[21]Squeeze-and-Excitation——通道注意力接近 ResNet
2017MobileNet[22]Depthwise + Pointwise 卷积——移动端优化极小
2019EfficientNet[23]NAS 搜索 + 复合缩放（depth/width/resolution 联动）同精度下最小
2020EfficientNet v2[24]加入 Fused-MBConv，训练更快同上

EfficientNet 的核心贡献是复合缩放法则：

d=αϕ,w=βϕ,r=γϕ,s.t.α⋅β2⋅γ2≈2

——同时缩放深度 d、宽度 w、分辨率 r，而不是只缩放一个维度。这与 L14 的 LLM Scaling Law（同时缩放参数 N 和数据 D）有异曲同工之妙。

5. 训练技巧的演化 ​

CNN 的成功不仅靠架构创新——同时靠训练技巧的累积。

5.1 Batch Normalization（2015） ​

[!quote] 历史 Ioffe & Szegedy 在 2015 年 ICML 发表 Batch Normalization[15:1]——在每一层激活之前做归一化：

x^=x−μBσB2+ϵ,y=γx^+β

其中 μB,σB 是 mini-batch 的均值和方差，γ,β 是可学习参数。

BatchNorm 的影响：

  • 训练速度提升 ~10×
  • 对学习率不敏感
  • 一定程度上替代 Dropout 的正则化作用

Sergey Ioffe 一作的这篇论文被引用 60,000+ 次，是深度学习训练技巧史上最重要的工作之一。

5.2 LayerNorm vs BatchNorm ​

后续在 Transformer 时代，LayerNorm（沿特征维归一化）取代了 BatchNorm，原因有二：

  1. BatchNorm 对 batch size 敏感，小 batch 时表现差
  2. BatchNorm 在序列长度变化时麻烦（NLP 任务序列长度不固定）

LayerNorm 对单个样本归一化，无 batch 依赖，被 Transformer 默认采用。L12 会回到这件事。

5.3 He 初始化、学习率调度、AdamW ​

技巧提出年份解决的问题
Xavier/Glorot 初始化2010让方差在层间稳定
He 初始化2015适配 ReLU 的"半激活"，方差守恒
Cosine LR Schedule2017后期训练时学习率衰减更优雅
AdamW (Adam + decoupled weight decay)2017让 weight decay 在 Adam 里行为正确
Label Smoothing2016防止模型对 one-hot 标签过度自信
Mixup / CutMix2018-19数据增强：混合两张图片+两个标签

L03 的"训练循环"四要素（模型、数据、损失、优化器）在 CNN 这里被填得满满当当。

6. CNN vs ViT：归纳偏置的拉锯战（2020-2024） ​

[!quote] 历史 2020 年 10 月，Google Brain 的 Dosovitskiy 等发表 An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale[25]——把图像切成 16×16 的 patches，喂给 Transformer。这就是 ViT（Vision Transformer）。

在 ImageNet-1k 上，ViT 不如 CNN。但当用 JFT-300M（Google 的 3 亿张内部数据集）预训练时，ViT 超过了 ResNet。

这戏剧化地证明了 L01 预埋的"归纳偏置 vs 规模"主线：当数据足够多，归纳偏置反而成为束缚。CNN 的局部性 + 平移等变假设在 ImageNet 这种"中等规模"数据集上有用，但在 3 亿样本上反而限制了模型的表达力。

ViT 横空出世后，CNN 看起来要被取代了——但故事没有这么简单。

6.1 ConvNeXt（2022）：CNN 的反击 ​

Liu 等 2022 年 A ConvNet for the 2020s[26] 提出 ConvNeXt：

  • 把 ViT 的训练技巧（AdamW、Mixup、长训练 schedule、label smoothing）搬到 ResNet 上
  • 把卷积核改成 7×7 大核
  • 把激活改成 GELU
  • 减少归一化、把 BN 换成 LN

结果：纯 CNN 在 ImageNet-1k 上超过 Swin Transformer。

这件事真正有价值的不是“CNN 赢了一次榜单”，而是它提供了一个强反例：

  • 2018–2021 的主流叙事是“attention 本身更强”
  • ConvNeXt 证明至少在一部分场景中，真正的提升来源是训练 pipeline 的现代化，而不一定是 attention 这个算子本身
  • 换句话说，很多“架构革命”里，算法创新和训练工程创新是缠在一起的，不能只看论文标题

更细一点看，ConvNeXt 的改造几乎是“向 Transformer 借工程纪律”：

ConvNeXt 改造表面看起来实际作用
7×7 depthwise 卷积只是把核变大扩大感受野，让局部归纳偏置更接近全局建模能力
GELU 替代 ReLU激活函数替换与 AdamW + 长训练更匹配，减小训练震荡
LayerNorm 替代 BatchNorm（部分位置）归一化替换减少 batch-size 依赖，提升跨设备稳定性
AdamW + 强增强 + 长 schedule训练配方升级让同一架构“吃满”数据与算力预算

这也解释了为什么 2022–2026 的工程共识不是“CNN 回来了，所以 ViT 结束了”，而是：视觉模型进入“架构差异缩小、训练配方决定上限”的阶段。这条结论会在 L14（Scaling Law）和 L31（LLMOps）再次出现。

核心概念

ConvNeXt 揭示的真相：ViT 的优势不在 attention 本身——更多在「现代训练 pipeline」。把同样的 pipeline 用在 CNN 上，CNN 也能赢。这一论点至今仍有争议，但它说明"架构对决"远比表面看起来复杂。

6.2 2024 年的 CV 架构格局 ​

到 2024-2026，计算机视觉的架构选择变得复杂：

场景主流选择原因
小数据 / 边缘设备EfficientNet / MobileNet归纳偏置帮忙，参数少
大规模预训练 (JFT-3B 级)ViT / DiT规模大时灵活性赢
检测 / 分割主流Mask R-CNN (CNN backbone)工业稳定，部署成熟
零样本分割SAM (ViT backbone)大规模数据训练
多模态主干ViT（CLIP, SigLIP）对文本/图像统一编码
极致效率ConvNeXt / EfficientNet v2同精度下最小参数
视频生成DiT (Diffusion Transformer)Sora、Veo 都用

结论：2026 年看，CNN 没死——它在工业部署中仍占主导，特别是在小数据和边缘场景。ViT 没赢——它在大规模和多模态场景占优，但需要远超 ImageNet 的数据。两者并存且互相借鉴——这才是真实的现状。

7. 失败模式 / 反例 / 边界 ​

7.1 「CNN 因生物启发所以最优」误解 ​

视觉皮层不是严格的层级卷积——它有大量反馈连接、跨皮层投射、注意力调制。CNN 的归纳偏置（局部性 + 平移等变）是工程选择，不是生物模仿的精确版本。"CNN 像大脑"这种说法只适合做营销，不适合做严格论证。

7.2 Pooling 不是必需的 ​

如 §3.4 所述。现代架构大量用 stride-conv 替代 max-pool。

7.3 ResNet skip connection 解释的复杂性 ​

如 §4.4 警告所述。"梯度高速公路"是一个解释，"集成多深度子网络"是另一个解释。两者都不完整，但都有用。

7.4 ViT 反例与"数据规模反转架构偏置" ​

ViT 在 ImageNet-1k 上不如 CNN，在 JFT-300M 上反超——印证 L14 的"数据规模反转架构偏置"。但这不意味着 CNN 已死——只意味着当数据足够多时，归纳偏置变成束缚。在小数据、边缘设备、工业部署场景里，CNN 仍然占优。

7.5 「越深越好」是误解 ​

直到 ResNet 出现前，深度是双刃剑（优化更难）。即使有了 ResNet，深度的边际收益也递减。EfficientNet 证明：联合缩放深度、宽度、分辨率比"只加深"更有效。

7.6 CNN 在 OOD 上脆弱 ​

CNN 对纹理比对形状更敏感[27]。如果改变图像纹理（比如把猫的纹理换成大象皮肤），CNN 经常分类错误——而人类不会受影响。这是 CNN 的一个深层局限。L08 会展开"对抗样本"问题。

延伸实验：把数据集换成 CIFAR-10 重做。差距会显著放大——这是因为 CIFAR-10 比 MNIST 困难得多，归纳偏置的价值更高。

[!example] 动手 3：感受野计算

计算下面这个网络从输入到输出的感受野：

Input → Conv(3×3, s=1) → Conv(3×3, s=1) → Pool(2×2, s=2)
      → Conv(3×3, s=1) → Conv(3×3, s=1) → Pool(2×2, s=2)
      → FC

公式（一层一层往回推）：

RFl=RFl−1+(kl−1)⋅∏i=1l−1si

答案：14×14。

意义：感受野解释了"网络看到了多大范围"。早期层只看局部，后期层看全局。这件事在 L08 的 detection 任务里至关重要。

这是工业上用 CNN 最常见的方式——很少有人从零训。预训练 + 微调是大模型时代的标准操作。

本讲小结 ​

  1. CNN 的成功来自三大归纳偏置和图像世界结构的对齐——局部性、平移等变、层级抽象。
  2. 从 Hubel-Wiesel 到 Neocognitron 到 LeNet 到 AlexNet——CNN 的诞生是 50 年神经科学 + 工程实验的累积。
  3. AlexNet 的胜利是工程胜利——ReLU + Dropout + GPU + 数据增强。所有组件都已存在；功劳是第一次正确组合。
  4. ResNet 的残差连接改变了"加深"的风险——最坏情况退化为恒等映射，这一思想被 Transformer 全盘继承。
  5. BatchNorm 是训练技巧史上最重要的工作之一——10× 训练加速，对学习率不敏感。
  6. ViT 挑战 + ConvNeXt 反击——2020-2022 的拉锯战说明：架构 vs 训练 pipeline 远比表面看起来复杂。
  7. 2026 年看 CNN 没死——工业 60%+ 部署仍是 CNN，ViT 在大规模 + 多模态占优；两者长期共存。
  8. 归纳偏置是双刃剑——在小数据时帮助极大，在大数据时反成束缚。这是 L01 预埋的"归纳偏置 vs 规模"主线在 CV 上的具体演绎。

下一讲预告 ​

敌意问题：CNN 让机器在 ImageNet 上分类图片——但分类只是 CV 的最浅任务。怎么从图像中找出物体的位置（detection）？怎么把图像像素级标注（segmentation）？怎么让模型在没见过的物体上也能工作？

第 8 讲——「计算机视觉的应用全景」——从 R-CNN 到 YOLO 到 SAM 到 CLIP 到 DINOv2，看 CNN 与 ViT 在真实任务中的演化。还会看到 2024 年的 Segment Anything 2、CLIP-3、视觉基础模型的最新格局。

[!abstract] 呼应线 🔗 归纳偏置 vs 规模（L01 → L06–07 → L07 此处 → L12 → L35）：CNN 是归纳偏置路线的巅峰——把人类关于视觉的三条直觉硬编码进结构。L12 的 Transformer 走向对立面——几乎不编码先验，用规模暴力求解。L35 的最终回答：归纳偏置真的输了吗？还是只是在不同问题上有不同最优？
