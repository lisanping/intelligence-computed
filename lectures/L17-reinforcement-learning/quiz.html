四、动手验证（实操题） ​

Q12（实操 · 表格 Q-Learning）

实现一个简单的 Q-Learning Agent 在网格世界中学习导航：

  • 网格：3×3，起点 (0,0)，目标 (2,2)
  • 动作：上下左右四个方向，边界处无法移动（停留原地）
  • 奖励：进入目标 +1，其他 0，每步 -0.01（鼓励快速到达）
  • 参数：α=0.1,γ=0.9,ϵ=0.1

任务：

  • ① 初始化 Q 表（3×3×4 维）
  • ② 运行 1000 步探索（随机过程），更新 Q 值
  • ③ 绘制最优策略（贪心选择 Q 值最大的动作）
  • ④ 评估：从起点走到目标的最少步数是多少？算法学到的最优路径是否一致？
Q13（实操 · DQN on CartPole）

使用 PyTorch / TensorFlow 实现一个简单的 DQN，在 CartPole-v1 环境训练：

  • 网络：3 层 MLP（state -> hidden 128 -> hidden 64 -> 2 actions）
  • 经验回放：batch 32，buffer size 1000
  • 目标网络：每 100 steps 更新一次
  • 训练 500 episodes

任务：

  • ① 写出 DQN 的伪代码（包括 experience replay 和 target network 更新）
  • ② 在 CartPole 上训练，记录每 50 episode 的平均奖励
  • ③ 绘制学习曲线，观察"何时收敛"
  • ④ 对比：不用 target network 的 DQN 会发生什么？（提示：不稳定振荡）
