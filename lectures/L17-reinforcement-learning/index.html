第 17 讲 · 强化学习与博弈智能 — 从试错到 AlphaGo ​

监督学习是"老师给答案"，强化学习是"自己试错找答案"——这是机器学习的第三种范式。

这一讲是从经典深度学习到 LLM 时代后训练的关键桥梁——RL 不只是 AlphaGo 时代的"游戏 AI"，它是 RLHF (L18)、推理模型 (L20) 和 Agent (L26) 的底层引擎。

没有 RL，ChatGPT 不会"听话"；没有 RL，o1 / DeepSeek-R1 不会"思考"；没有 RL，自动驾驶 / 机器人 / 蛋白质设计都无法学习。这一讲的概念你必须完全内化。

前置知识核心产出建议用时
L02（搜索算法 / MCTS）、L04（ML 基础）① 掌握 MDP / 值函数 / Bellman 方程 ② 掌握 Q-learning + DQN 两大技巧 ③ 掌握 REINFORCE / Actor-Critic / PPO 演进 ④ 深入理解 AlphaGo / AlphaZero / MuZero 架构 ⑤ 理解 Reward Hacking / 稀疏奖励等失败模式 ⑥ 看 RL 在现代 AI 中的位置（RLHF / RLVR / 推理 / Agent） ⑦ 拿到 L18 (RLHF)、L20 (推理)、L33 (具身) 的伏笔阅读 ~75 分钟 + 动手 ~30 分钟

从上一讲到这一讲 ​

到目前为止，所有学习都有一个共同点：有人给了正确答案。

  • L04 经典 ML：监督学习 = 数据 + 标签
  • L13 BERT/GPT：自监督 = 用数据本身做标签
  • L15 预训练：next-token prediction = 下一个词就是标签

但人类学会的很多能力不是靠别人给答案的——小孩学走路没有"正确步态数据集"，只有"摔了疼"的反馈。

[!quote] 历史 强化学习的根源可追溯到 1950s 的 B.F. Skinner 操作性条件反射——动物通过试错学习。

1989 年 Chris Watkins 在剑桥发表 Q-learning 博士论文[1]——给出 RL 的第一个收敛性保证算法。

1998 年 Sutton & Barto 出版《Reinforcement Learning: An Introduction》[2]——RL 的圣经。Sutton 后来因 RL 工作获 2024 年 ACM 图灵奖（与 Hinton 同年）。

这就是强化学习——机器学习的第三种范式。

1. RL 核心框架 ​

1.1 MDP（马尔可夫决策过程） ​

RL 的数学框架——五元组 (S,A,P,R,γ)：

符号含义
S状态空间
A动作空间
P状态转移概率 $P(s'
R奖励函数 R(s,a)
γ折扣因子 γ∈[0,1)

循环：Agent 观察 st → 选择 at → 环境返回 rt+1,st+1 → 重复。

1.2 累积折扣奖励 ​

Agent 的目标——最大化累积折扣奖励：

Gt=rt+1+γrt+2+γ2rt+3+⋯=∑k=0∞γkrt+k+1

γ 控制"短视"还是"远见"：γ=0.99 很有耐心，γ=0.5 很短视。

1.3 值函数与 Bellman 方程 ​

状态值函数：

Vπ(s)=Eπ[Gt|st=s]

动作值函数：

Qπ(s,a)=Eπ[Gt|st=s,at=a]

Bellman 最优方程——值函数的递归定义：

V∗(s)=maxa[R(s,a)+γ∑s′P(s′|s,a)V∗(s′)]Q∗(s,a)=R(s,a)+γ∑s′P(s′|s,a)maxa′Q∗(s′,a′)

核心概念

Bellman 方程说的是：一个状态的价值 = 当前奖励 + 折扣后的下一个状态的最优价值。 有了 Q∗，最优策略就是 π∗(s)=arg⁡maxaQ∗(s,a)——在每个状态选 Q 值最大的动作。

1.4 探索 vs 利用 ​

ε-greedy 策略：

  • 概率 1−ε：选 Q 值最大的动作（利用）
  • 概率 ε：随机选一个动作（探索）
  • 训练中逐渐降低 ε

2. 算法演进 ​

2.1 Q-learning ​

表格型 RL——对每个 (s,a) 维护 Q 值，在线更新：

Q(s,a)←Q(s,a)+α[r+γmaxa′Q(s′,a′)−Q(s,a)]
分量含义
r+γmaxa′Q(s′,a′)TD Target（实际 + 最优未来估计）
Q(s,a)当前估计
两者之差TD Error（估计误差）
α学习率

直觉

Q-learning 和梯度下降精神一样——每次修正一小步，慢慢逼近真实 Q 值。只要探索足够 + 学习率衰减合适，保证收敛到最优。

2.2 DQN（Deep Q-Network） ​

用神经网络近似 Q(s,a;θ)——解决大状态空间（如 Atari 画面 128210×160）。

DQN Loss：

L(θ)=E[(r+γmaxa′Q(s′,a′;θ−)−Q(s,a;θ))2]

两个稳定训练的关键技巧：

技巧解决的问题做法
Experience Replay连续帧的时间相关性存入缓冲区，随机采样 mini-batch
Target Network训练目标不稳定（自己追自己）θ− 每隔 C 步从 θ 复制一次

2.3 REINFORCE（策略梯度） ​

直接优化策略 πθ(a|s)——不通过 Q 值：

∇θJ(θ)=Eπθ[∇θlog⁡πθ(at|st)⋅Gt]

直觉

高奖励的动作 → 增加其概率；低奖励的动作 → 降低其概率。"好的做多，坏的做少"——用梯度的语言说出来。

问题：方差太大——Gt 是整局累积奖励，无法区分哪个动作的贡献。

2.4 PPO（Proximal Policy Optimization） ​

Actor-Critic + Clipped Surrogate Objective：

LCLIP(θ)=E[min(rt(θ)⋅At,clip(rt(θ),1−ϵ,1+ϵ)⋅At)]

其中 rt(θ)=πθ(at|st)πθold(at|st) 是新旧策略的概率比。

概念含义
Actor策略网络 $\pi_\theta(a
Critic价值网络 Vϕ(s)——评估状态
AdvantageAt=Gt−Vϕ(st)——"比平均好多少"
Clipping限制概率比在 [1−ϵ,1+ϵ] 内

核心概念

PPO 的核心直觉：限制每次更新步幅——像保守的投资者，每次只小幅调整。PPO 是当前深度 RL 的默认算法，也是 RLHF（L18）的核心优化器——把游戏分数换成人类偏好，PPO 的框架完全适用。

3. AlphaGo 深讲 ​

3.1 围棋的搜索空间 ​

棋类搜索空间
国际象棋∼10123
围棋∼10360
宇宙原子∼1080

Deep Blue（暴力搜索 + 手工评估函数）在围棋面前完全无用。

3.2 AlphaGo = MCTS + 策略网络 + 价值网络 ​

组件替代 MCTS 中的作用
策略网络 pσ随机 Rollout引导搜索方向，优先探索概率高的走法
价值网络 vθ完整模拟到终局直接评估局面胜率，一次前向传播

MCTS + 网络的结合：

  1. 选择：策略网络引导搜索方向
  2. 扩展：策略网络初始化子节点先验概率
  3. 评估：价值网络评估叶子节点价值
  4. 回传：评估结果沿路径回传更新统计量

MCTS 中的 UCB1 选择公式：

at=arg⁡maxa[Q(s,a)+c⋅P(s,a)⋅N(s)1+N(s,a)]

3.3 AlphaZero (2017)——从零开始 ​

AlphaZero 的三个简化：

  1. 去掉人类棋谱：完全随机初始化 → 纯自我对弈
  2. 合并两个网络：策略 + 价值合为双头网络
  3. 去掉手工特征：只用原始棋盘状态

结果：训练 3 天击败 AlphaGo Lee 100:0；同一个算法学会围棋、国际象棋、将棋。

核心概念

AlphaGo 是第 2 讲"搜索 vs 学习"故事的终极呼应。Deep Blue = 搜索 + 人类手工评估；AlphaGo = 搜索 + 机器自学评估。20 年——从"人类编写智能"到"机器自己学会智能"。

[!abstract] 呼应线 🔗 符号 AI vs 学习 AI（L02 → L17 此处 → L20）：L02 Deep Blue = 搜索 + 人类手工评估函数；AlphaGo = 搜索 + 机器自学评估。20 年——从"人类编写智能"到"机器自己学会智能"。L20 推理模型再进一步——把 AlphaZero 的"自我对弈"思想用在语言模型上：让模型自己生成推理路径，自己学。

3.4 MuZero (2019)：连规则都不需要 ​

[!quote] 历史 DeepMind 2019 发表 MuZero[3]——比 AlphaZero 更彻底——不需要游戏规则。

MuZero 通过学习世界模型（learned world model）+ MCTS 来做决策。在围棋、国际象棋、将棋上达到 AlphaZero 水平，同时在 57 个 Atari 游戏上达到 SOTA——证明了"无模型 + 学到模型 + 搜索"的统一框架。

3.5 AlphaFold：RL 风格的科学突破 ​

[!quote] 历史 2021 年 DeepMind 发表 AlphaFold 2[4]——把 50 年的蛋白质折叠问题从"困难"变成"基本解决"。Demis Hassabis 因此与 John Jumper 共同获得 2024 年诺贝尔化学奖。

AlphaFold 不是纯 RL——但它使用 RL 思想（迭代搜索 + 学到的评估）的精神。这是 AI 改变科学方法论的标志事件。

4. RL 在 LLM 时代的复活 ​

2010s 后期 RL 一度被认为"只能玩游戏"——但 2022 年 ChatGPT 出现让它重回 AI 中心。

4.1 RLHF：把人类偏好当奖励 ​

[!quote] 历史 OpenAI 的 Christiano et al. 2017[5] 在玩 Atari 游戏时实验：让人类在两个 trajectory 间二选一作为奖励信号——Reinforcement Learning from Human Feedback (RLHF) 诞生。

5 年后 InstructGPT (2022-01) + ChatGPT (2022-11) 把 RLHF 用到 GPT-3 上——让模型从"会续写"变成"听人话"。这是 ChatGPT 引爆的根本技术原因。

L18 会全面展开。

4.2 RLVR：把可验证奖励当奖励 ​

[!quote] 历史 2024-2025 年 OpenAI o1 / DeepSeek-R1 / Claude 4 Thinking 引爆推理模型范式——核心技术是 RLVR (Reinforcement Learning with Verifiable Rewards)。

数学题、代码题有可验证奖励（答案对 / 错、代码通过 / 失败）——直接用 PPO / GRPO 训练，不需要 reward model。

L20 会全面展开。

4.3 RL for Agent ​

2025-2026 年 Agent 领域开始使用 RL——让 Agent 通过"完成任务"的反馈学习更好的工具调用、更精确的规划。

核心概念

RL 不是"游戏 AI 的小众技术"——它是 LLM 后训练的核心引擎。

理解 PPO、Reward Hacking、稀疏奖励等概念，是理解 ChatGPT 为什么"听话"、o1 为什么"会思考"的前提。

失败模式 / 反例 ​

本节列出本讲核心结论不适用或易被误用的常见情境。教学的目的不是制造「已学会」的错觉，而是认清边界。

  • 「强化学习 = 万能」反例：在 sparse reward 任务上，pure RL 训练步数比 imitation learning 多 100×——这是 RLHF 实际用 SFT warmup 的原因。
  • Reward Hacking 的经典案例：CoastRunners (OpenAI 2016) 学会绕圈刷分而非完成比赛；这一模式在 RLHF 时代变成「模型学会奉承用户而非诚实」。
  • AlphaGo 神话拆解：AlphaGo Lee 用了 ~3000 万人类对局数据 + 数千 TPU 月；不是「纯 RL」——AlphaGo Zero (2017) 才是，但仍依赖完美仿真器（围棋规则确定）。
  • Q-learning 在连续空间的失效：Q 表无法枚举连续动作空间；DQN 用神经网络逼近也不稳定（需 target net、replay buffer 等大量工程）——RL 比监督学习脆弱得多。

本讲小结 ​

  1. RL = 试错学习——没有正确标签，只有"做了之后好不好"的奖励反馈。
  2. Q-learning 是最简单的 RL 算法——表格存 Q 值，TD Error 在线更新。
  3. DQN 用 CNN 近似 Q 函数——Experience Replay + Target Network 两个工程技巧让深度 RL 成为可能。
  4. 策略梯度到 PPO：REINFORCE（高方差）→ Actor-Critic（Advantage 降方差）→ PPO（Clipping 限制步幅）。PPO 是 RLHF 的引擎。
  5. AlphaGo = MCTS + 策略网络 + 价值网络——搜索与学习的终极合体。AlphaZero 从零自我对弈，一个算法三个棋类。
  6. Bellman 方程 是 RL 的数学核心——当前价值 = 即时奖励 + 折扣的未来价值。

下一讲预告 ​

敌意问题：AlphaGo 的奖励很明确——赢了棋。但如果要训练一个语言模型——什么是"好的回答"？游戏有明确的输赢，对话没有。如果"好不好"只能靠人类判断——怎么把人类偏好变成可以优化的目标？

第 18 讲——「对齐」——RLHF 的完整故事。PPO + 人类偏好 = 让 ChatGPT 变得"好用"的关键技术。
