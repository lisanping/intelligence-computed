第 33 讲 · 具身智能 — 物理世界的重锤 ​

上一讲 AI 征服了数字世界的生成——视频、音频、3D，一切比特皆可生成。

本讲给出一记重锤：物理世界根本不买账。Moravec 悖论告诉我们，让机器人叠衣服比让 AI 写诗难得多——数字世界的"智能"和物理世界的"智能"有本质区别。

2024-2026 年人形机器人赛道炸起：Tesla Optimus / Figure 02 / Apptronik Apollo / Sanctuary Phoenix / 1X NEO / Unitree G1 / 小米 CyberOne / 小鹏 / 智元 / 宇树 / Galbot / Fourier GR-1——众多创始公司获亿美元级别融资。

这是课程倒数第三章——提醒你未来十年 AI 不只在屏幕上。

前置知识核心产出建议用时
L12（Transformer）、L20（推理）、L29（多模态）、L32（生成式）① 理解 Moravec 悖论的深层含义 ② 掌握 Sim-to-Real gap 的技术根源与 Domain Randomization 实证 ③ 了解 Open X-Embodiment / LeRobot / π0 代表的数据路线走向 ④ 掌握三条技术路线（LLM 规划器 / 端到端 / 混合） ⑤ 认识世界模型 (NVIDIA Cosmos / Genie 3) ⑥ 理解物理试错成本不可压缩 ⑦ 看 2026 年人形机器人热潮 ⑧ 拿到 L34 (Safety) 的伏笔阅读 ~80 分钟

从上一讲到这一讲 ​

第 32 讲问：征服了比特的 AI，能征服原子吗？你让 AI 倒一杯水试试。

你刚看完 AI 在数字世界的全面胜利——Sora 生成电影级视频，Suno 一键作曲，Gaussian Splatting 实时渲染三维世界。数字世界的共同特点是：零成本重试。Sora 生成了一段物理不合理的视频？再生成一次就好。Suno 的旋律不好听？换个 seed。错误的代价是几秒钟的等待时间。

物理世界不是这样的。机器人伸手抓杯子，力度大了——杯子碎了。碎了就是碎了，你不能 ctrl+Z。机器人试图叠毛巾，毛巾滑落——你需要重新摆好毛巾、让机器人重置姿态，然后再试一次。每次尝试消耗的是真实的时间、真实的能量、真实的物理磨损。

这就是为什么 AI 在数字世界所向披靡，但在物理世界举步维艰。

1. Moravec 悖论：难的不是你以为的那个 ​

1.1 什么是 Moravec 悖论 ​

1988 年，Hans Moravec 在《Mind Children》中提出了一个反直觉的观察[1]：

核心概念

Moravec 悖论：让计算机在智力测试或下棋中表现出成人水平是相对容易的，但让它拥有一岁小孩的感知和运动能力却极其困难。 高级推理只需要很少的计算，而低级的感觉运动技能却需要巨大的计算资源。

为什么？进化的解释是：感觉运动能力经过了数亿年的进化打磨，高度优化且深度嵌入大脑的底层结构；而抽象推理只有几千年历史，建立在"最新的"且"最薄"的皮层之上。进化花了最久时间打磨的能力，恰恰是我们觉得最"简单"的——因为它们如此自然，以至于我们意识不到它们的复杂性。

[!example] 具体例子

  • 下围棋：AlphaGo 2016 年击败李世石。状态空间虽大，但规则完全确定、环境完全可观测。
  • 倒一杯水：需要估计杯子位置（视觉 + 深度估计）、规划抓握姿态（运动规划）、控制力度（力反馈）、判断水量（液面检测）、处理意外（水洒了怎么办）——而且整个过程在连续空间中实时进行，没有离散的"走一步棋"。

1.2 为什么 GPT-4 不能控制机器人 ​

GPT-4 可以写出完美的机器人控制代码，可以用文字描述如何倒水的每一步。但从"文字描述"到"物理执行"之间隔着一道巨大的鸿沟：

  • 连续控制：语言是离散 token，物理动作是连续关节角度——7 自由度机械臂的每个关节需要毫秒级的实时控制
  • 闭环感知：机器人必须根据实时视觉反馈调整动作——杯子滑了一点？手的轨迹要立刻修正
  • 接触物理：抓握、推拉、倒水涉及复杂的接触力学——神经网络对此没有内建的物理直觉

2. Sim-to-Real Gap：模拟器的许诺与背叛 ​

图：Sim-to-Real Gap 示意——视觉差距、物理差距、动力学差距三管齐下，模拟器中的成功不等于现实中的成功。

2.1 为什么用模拟器 ​

在物理世界训练机器人太慢、太贵、太危险。一个自然的想法是：先在模拟器中训练，然后迁移到真实世界。

模拟器的优势：

  • 无限并行：可以同时运行 1000 个模拟环境（NVIDIA Isaac Sim）
  • 零成本犯错：摔坏了 reset 一下就好
  • 精确标注：物体位置、力、速度——模拟器知道一切
  • 加速训练：模拟中 1 小时 = 真实世界 1 年

2.2 Sim-to-Real Gap 的三个来源 ​

核心概念

Sim-to-Real Gap（模拟到现实的差距）是指模拟器中训练好的策略在真实世界中表现显著下降的现象。 三大来源：视觉差距（渲染不够真实）、物理差距（模拟器的物理引擎不精确）、动力学差距（电机延迟、摩擦、传感器噪声）。

模拟器中:
  ✅ 光照完美均匀 → 真实: 阴影、反光、遮挡
  ✅ 摩擦系数精确 → 真实: 不同材质摩擦不同，且随温度变化
  ✅ 关节响应即时 → 真实: 电机有延迟，齿轮有间隙
  ✅ 物体刚体碰撞 → 真实: 软体变形、液体流动

常见误区

"模拟器越精确，Sim-to-Real Gap 就越小"——不完全对。模拟器精度提升会命中递减回报：从 80% 到 95% 的真实感可能比较容易，但从 95% 到 99% 的成本会指数增长。更有效的策略是Domain Randomization（域随机化）：故意在模拟中引入随机噪声（随机光照、随机摩擦、随机物体位置），让策略学会对不确定性鲁棒。

2.3 Domain Randomization 的实证 + 数据规模才是真正答案 ​

§2.2 提了 Domain Randomization,这一节给出它实际上有多有效 + 它什么时候不够——这是 2024-2026 年具身智能社群最重要的两个实证。

实证 1: OpenAI Dactyl(魔方)的 DR 神话与代价

2019 年 OpenAI 用 Domain Randomization 让单手机器人魔方,sim-to-real 成功——但代价是:

  • 6144 个 CPU 核心 跑 50 天的模拟训练(相当于真实世界 13000 年经验)
  • DR 包含 95 种参数随机化(摩擦 / 质量 / 视觉 / 时延 / 传感器噪声 / 重力扰动)
  • 真机测试成功率 60%,远不如视频显示的"魔方一气呵成"印象

结论:DR 能 跨越 sim-to-real,但代价是算力成本数量级超过监督学习——这条路在 2020-2023 年被绝大多数实验室放弃,因为打不起。

实证 2: 数据规模反超 Domain Randomization (2024-2025)

2024 年开始,具身社群出现路线转向:与其在模拟器里把 DR 做到极致,不如收集真实机器人数据。两个标志事件:

项目时间数据规模关键发现
Open X-Embodiment2023-10 → 202422 个机构,1M+ trajectories,527 种技能,21 种机器人形态跨 embodiment 训练的策略,在新机器人 / 新任务上 zero-shot 成功率比单机器人专训提升 50%
LeRobot (Hugging Face)2024-05 公开30K+ trajectories + 100 余项标准化任务把"机器人数据集"变成 HuggingFace 风格——任何研究者可以一行 load_dataset() 获取
π0 (Physical Intelligence)2024-10私有数据 + Open X第一个"通用机器人基础模型"——一个模型做 50+ 任务,sim-to-real 不再是核心瓶颈

范式转移

2024-2025 年具身 AI 的范式从"在模拟器里做 DR"转移到"训练机器人基础模型"——和 NLP 在 2018 年从"任务专属模型"转向"通用 LM"高度相似。Sim-to-Real Gap 不再被尝试"消除",而是被"绕过"——直接在真实数据上训练,模拟器只用作初始策略 / 数据增强。

实证 3: 数据 + 仿真混合的胜利公式 (2025-2026)

2026 年 SOTA 机器人系统(π0 / OpenVLA / Helix from Figure)的训练配方是:

预训练: VLM (Vision-Language Model)        ← 互联网图文数据 (~10 亿样本)
    +
具身预训练: VLA (Vision-Language-Action)    ← Open X-Embodiment + LeRobot (~100 万 trajectory)
    +
任务微调: 真机 demo (5-50 demonstration)    ← 用户演示 + 模仿学习
    +
在线优化: RL 或 DAgger (可选)               ← 部署后自我改进

注意:Domain Randomization 在这条配方里完全消失 —— 它不是没用,是被**"用数据规模消除 sim-to-real 缺口"** 的新范式压倒。L17 §RLVR 的逻辑在这里复现:先用大规模通用数据预训练,再用少量任务数据微调。

反派视角

数据派的弱点是:1M trajectory 仍远小于 LLM 的 10^13 token 量级,而且采集真实机器人数据的边际成本是 LLM 训练数据的 ~10000 倍(每个 trajectory 需要人在场,LLM 文本免费爬)。如果数据量天花板在 1000 万 trajectory(2030 年估计上限),它可能不足以覆盖物理世界长尾。这是 §6 World Model 路线被 LeCun / DeepMind 押注的根本原因——用合成视频替代真实采集。

3. 三条技术路线 ​

3.1 路线一：LLM 作为规划器 + VLA 模型 ​

代表：RT-2（Robotics Transformer 2）[2]

Google DeepMind 的 RT-2 把视觉-语言模型（VLM）直接用于机器人控制——模型同时接收图像和语言指令，直接输出机器人动作。

图像 + "把苹果放到碗里" → VLA 模型 → 动作序列 (Δx, Δy, Δz, 夹爪)

核心概念

VLA（Vision-Language-Action，视觉-语言-动作）模型是把多模态大模型的知识直接连接到物理动作的尝试。 RT-2 证明了一个惊人的发现：在互联网图文数据上预训练的知识可以迁移到机器人控制——模型看到"可乐罐"就知道它是圆柱形的、可以抓握的，即使从未在机器人数据中见过可乐罐。

局限：RT-2 的动作频率约 3Hz（每秒 3 个动作），而精细操作（如穿针引线）需要 100Hz 以上。LLM 的推理延迟是物理控制的瓶颈。

3.2 路线二：端到端学习 ​

代表：Tesla Optimus

特斯拉的路线是"不要中间抽象，直接从感知到动作"——摄像头像素 → 神经网络 → 关节电机信号，中间没有人类设计的规划模块。

这条路线的信念是：如果给足够多的数据和足够大的模型，端到端学习可以涌现出所有必要的"中间能力"（物体识别、运动规划、力控制……）——不需要人类显式设计。

回顾

这和 L04-L07 的故事惊人地一致——从 CNN（手工特征 → 学习特征）到 Transformer（手工架构 → 通用架构）。端到端路线的信念是：同样的"规模碾压归纳偏置"法则在物理世界也成立。但下一小节会展示为什么这次可能不一样。

3.3 路线三：混合方案 ​

代表：Figure 01 + OpenAI

Figure 的人形机器人整合了 OpenAI 的语言能力 + 自己的运动控制模型。LLM 负责高级规划（"把桌子上的垃圾收拾了"），底层运动控制器负责执行（抓取、移动、放置）。

用户指令 → LLM 规划 (任务分解) → 底层控制器 (动作执行) → 物理世界
              ↑                         ↑
         语言理解 + 常识            运动规划 + 力控制

直觉

混合方案就像"CEO + 工人"——CEO（LLM）负责决策（先拿杯子，再倒水，最后放回去），工人（底层控制器）负责精细执行（怎么抓、用多大力、手腕转几度）。CEO 不需要懂焊接，工人不需要懂战略。

4. 世界模型：物理直觉的可能出路 ​

4.1 什么是世界模型 ​

核心概念

世界模型（World Model）是一个能够预测物理世界未来状态的模型——给定当前状态和一个动作，它预测"接下来会发生什么"。 如果机器人有一个好的世界模型，它可以在"脑子里"模拟多种行动方案，选择最好的那个——然后再在物理世界中执行。这就是"物理直觉"。

4.2 Genie 2：DeepMind 的世界模型 ​

2024 年底，Google DeepMind 发布了 Genie 2[3]——一个可以从单张图像生成可交互 3D 世界的基础世界模型（Foundation World Model）。

Genie 2 的能力：

  • 输入一张图像，生成一个持续、一致的 3D 环境
  • 支持键盘/手柄交互——你可以在生成的世界中"走动"
  • 理解基本物理（重力、碰撞、遮挡）

世界模型与模拟器的区别

传统模拟器（Isaac Sim、MuJoCo）用手写的物理方程（牛顿力学、碰撞检测）模拟世界。世界模型用学习到的物理规律预测世界。前者精确但只能模拟已知的物理现象；后者不精确但可能"理解"未明确建模的复杂交互（布料褶皱、液体流动、柔性物体变形）。

4.3 为什么世界模型对具身智能至关重要 ​

[!abstract] 呼应线 🔗 物理账单线（核心呼应）：从 L20 的训练成本、L11 的量化省钱、L25 的推理经济学——本讲揭示终极账单：物理世界的试错成本不可压缩。机器人摔一次是真钱（硬件维修 + 停机时间）。世界模型的价值正在于此：在"脑子里"低成本试错，只把最好的方案拿到物理世界执行——用比特的廉价模拟替代原子的昂贵试错。

5. 失败是常态：机器人的窘境 ​

让我们看看当前机器人在"简单"任务上的表现：

任务人类完成时间机器人成功率主要失败原因
叠毛巾30 秒~60%柔性物体变形不可预测
开门2 秒~70%把手类型多样，力度难控
倒水5 秒~50%液面估计 + 倾斜角度控制
穿鞋带30 秒~10%精细操作 + 柔性绳索

[!example] 失败视频集锦 推荐搜索："robot fail compilation" 或 "DARPA robotics challenge fails"。2015 年 DARPA 机器人挑战赛的摔倒集锦至今仍是 Moravec 悖论最好的教学素材——这些花费数百万美元、由顶级团队打造的机器人，在"走过碎石地面"这种三岁小孩都能做的事情上摔得人仰马翻。

[!abstract] 呼应线 🔗 归纳偏置 vs 规模（呼应 + 翻转）：在数字世界（L07-L09），规模碾压了归纳偏置——Transformer 不需要 CNN 的局部性假设、不需要 RNN 的序列性假设，靠规模就够了。但在物理世界，没有物理先验（归纳偏置）的纯规模路线举步维艰。机器人不理解牛顿力学、不理解材料弹性、不理解液体的流体力学——没有这些先验知识，再多数据也很难学会"倒水不洒"。归纳偏置的反击。

6. 走向通用具身智能 ​

从三条路线到世界模型，具身智能的未来可能是这样的：

世界模型（物理直觉）
  ↓ 提供"脑内模拟"
LLM 规划器（任务分解）
  ↓ 提供高级策略
VLA 中间层（视觉-语言-动作映射）
  ↓ 提供感知-动作桥接
底层控制器（实时精细控制）
  ↓ 100Hz 级别
物理世界

直觉

这个层级结构和人类的运动控制惊人地相似。你决定"喝水"（大脑皮层 = LLM），你的手自动伸向杯子（小脑 = 中间控制器），你的手指自动调整抓握力度（脊髓反射 = 底层控制器）。你不需要意识参与每个关节的角度计算——不同层级各司其职。

失败模式 / 反例 ​

本节列出本讲核心结论不适用或易被误用的常见情境。教学的目的不是制造「已学会」的错觉，而是认清边界。

  • 「具身智能即将爆发」预测的反复落空：从 2014 Baxter 到 2024 Figure 01，每隔 5 年都有「机器人元年」——但 sim-to-real gap 至今未根本性解决。
  • RT-2 / OpenVLA 的真实表现：在受控演示场景成功率 80%+；家庭实环境下成功率断崖式下跌（漏光、纹理变化、未知物体）。
  • 「LLM 是机器人大脑」过简：LLM 给规划没问题；但精细操作 / 实时控制 / 力反馈仍需专门模型与硬件——纯 LLM 端到端方案至今未成功。
  • 数据规模的硬约束：互联网文本 ~10^13 token；机器人轨迹数据 ~10^7 episodes（4 个数量级差距）——Scaling Law 在具身上失效。

本讲小结 ​

  1. Moravec 悖论揭示了直觉的反面——高级推理（下棋、写诗）对计算机容易，低级感觉运动（抓握、行走）反而极难。数亿年进化打磨的能力，恰恰是最难复制的。
  2. Sim-to-Real Gap 是具身智能的核心瓶颈——视觉差距、物理差距、动力学差距三管齐下，模拟器中训练好的策略在真实世界大幅退化。
  3. 三条技术路线各有优劣——LLM 规划器（RT-2）迁移知识但频率太低，端到端学习（Optimus）简洁但数据饥渴，混合方案（Figure）实用但模块间接口复杂。
  4. 世界模型是物理直觉的可能出路——在"脑子里"低成本试错，只把最优方案拿到物理世界执行，用比特模拟替代原子试错。
  5. 物理世界的试错成本不可压缩——这是具身智能与数字 AI 的根本区别，也是归纳偏置（物理先验）在物理世界反击规模路线的原因。

下一讲预告 ​

敌意问题：好，物理世界给了 AI 一记重锤——叠衣服比写诗难，倒水比生成视频难。但别忘了：AI 在数字世界也是从"做不到"走到"碾压人类"的。当 AI 真的能够操控物理世界的时候，它犯的错误就不再是生成了一张错误的图片，而是撞伤了一个人。我们能确保理解并控制这些系统吗？
