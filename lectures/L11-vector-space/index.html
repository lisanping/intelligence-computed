第 11 讲 · 向量空间 — 所有模态的通用语言 ​

文字、图像、声音看起来毫无共同点——但在向量空间里它们说的是同一种语言。

嵌入（Embedding）是这种翻译的核心技术——它让"意义"变成了"方向和距离"。

这一讲是 L09 (Classical NLP "词 = 符号" 天花板) 与 L12 (Transformer) 之间的关键桥梁。它的概念不只是"更高级的词表示"——它是整个 LLM 时代的世界观：

  • 检索（L23 RAG）：向量近 = 相关
  • 多模态（L29 CLIP）：图像 + 文字共享向量空间
  • 对齐（L18 RLHF）：人类偏好 = 向量分布的微调
  • 内存与状态（L22 / L26 Agent）：记忆 = 向量数据库

没有向量空间，就没有 ChatGPT、没有 GPT-4V、没有 RAG、没有 Agent。这一讲的概念你必须完全内化。

前置知识核心产出建议用时
L03（统一框架）、L09（NLP）、L10（Attention）① 理解"嵌入"概念：把离散符号映射到连续向量空间 ② 掌握 Word2Vec / GloVe 的 Skip-gram / CBOW 训练直觉 ③ 理解 King - Man + Woman ≈ Queen 的奇迹与背后机制 ④ 掌握余弦相似度、点积、欧氏距离的几何意义 ⑤ 理解静态嵌入的局限（"bank" 多义） ⑥ 看清向量空间作为多模态通用语言（文字 / 图像 / 声音 / 代码） ⑦ 拿到 L12 (上下文化嵌入)、L23 (向量数据库)、L29 (CLIP) 的伏笔阅读 ~70 分钟 + 动手 ~25 分钟

从上一讲到这一讲 ​

L10 展示了 Attention 如何通过 "打分 → 归一化 → 加权求和" 在序列中动态检索信息。但 Attention 操作的是向量——每个词、每个位置都被表示为一个向量。

那这些向量从哪来？它们为什么能代表"意义"？

L09 留了根本问题——"King" 和 "Queen" 是完全无关的符号。本讲回答它，同时建立一个将贯穿后续课程的关键概念：向量空间是所有模态的通用语言。

1. 一个改变 NLP 的奇迹：King − Man + Woman = Queen ​

让我们从一个令人惊叹的实验开始。

1.1 Mikolov 的发现 ​

[!quote] 历史 2013 年，Google 的 Tomas Mikolov, Kai Chen, Greg Corrado, Jeffrey Dean 发表 Efficient Estimation of Word Representations in Vector Space[1]。

在训练一个非常简单的"预测上下文"模型时，他们偶然发现了这件事：

King→−Man→+Woman→≈Queen→

把 "King" 的向量减去 "Man"，加上 "Woman"——得到的结果最接近 "Queen"。

向量的算术运算竟然对应了语义关系。

1.2 更多例子 ​

任务例子
首都关系Paris→−France→+Italy→≈Rome→
语法关系bigger→−big→+small→≈smaller→
公司 CEOMicrosoft→−Gates→+Apple→≈Jobs→
货币Japan→−yen→+Russia→≈ruble→

图 11.1：词向量在二维 PCA 投影上的语义算术。来源：demo/word2vec_demo.py 生成。

1.3 为什么这是奇迹？ ​

核心概念

嵌入（Embedding）：把离散的符号（词、像素、类别）映射到连续的向量空间。

在这个空间里：

  1. 相似的东西距离近，不相似的东西距离远 — 几何性质
  2. 方向编码语义关系 — 加减运算有意义
  3. 维度可解释（部分） — 某些方向对应"性别"、"复数"等

这是 NLP 史上最重要的概念发现之一。它比任何具体算法都更深刻——因为它告诉我们："意义"是可以用几何刻画的。

2. 为什么 One-Hot 不够？ ​

在嵌入出现之前，表示一个词的标准方式是 One-Hot 编码：词表有 10,000 个词，每个词是一个 10,000 维向量，只有对应位置是 1，其他全是 0。

例：

"猫" = [0, 0, 1, 0, 0, ..., 0]
"狗" = [0, 1, 0, 0, 0, ..., 0]

2.1 One-Hot 的两个致命问题 ​

2.1.1 维度灾难 ​

词表越大向量越长。GPT-4 的词表有约 10 万个 token —— 每个 token 就是 10 万维。每个 embedding lookup 需要一个 10万 × d 的矩阵。

2.1.2 语义失明 ​

任何两个 One-Hot 向量的距离都完全相同（互相正交）：

cosine(cat→one-hot,dog→one-hot)=0cosine(cat→one-hot,economics→one-hot)=0

"猫" 和 "狗" 的距离 = "猫" 和 "经济学" 的距离。这显然不对。

核心概念

One-Hot 编码不包含任何语义信息——它只是给每个符号一个独立索引。这是 NLP 60 年来的根本困境——直到 Word2Vec 出现。

3. Word2Vec：从上下文学语义 ​

3.1 分布式假说 ​

Word2Vec 的核心思想来自语言学中的分布式假说：

"You shall know a word by the company it keeps."

— J.R. Firth, 1957[2]

一个词的含义由它的上下文决定。

  • "猫" 经常和 "喵"、"宠物"、"爪子" 一起出现
  • "狗" 也经常和 "宠物"、"爪子" 一起出现
  • → "猫" 和 "狗" 应该有相似的表示

[!quote] 历史 这个观察是 1950s 的语言学家 J.R. Firth 和 Zellig Harris 提出的。但一直没有计算实现——直到 Mikolov 2013 用神经网络让它可计算。

3.2 Skip-gram 模型 ​

Word2Vec 有两个变体：CBOW（连续词袋，给上下文预测中心词）和 Skip-gram（给中心词预测上下文）。Skip-gram 在大数据集上效果更好。

Skip-gram 训练样本：

句子 "The cat sat on the mat"，窗口大小 2。中心词 "cat" 的训练样本：

(cat → The)
(cat → sat)
(cat → on)

3.2.1 训练目标 ​

最大化对数似然：

L=1T∑t=1T∑−c≤j≤c,j≠0log⁡P(wt+j|wt)

其中：

P(wO|wI)=exp⁡(vwO′TvwI)∑w=1Vexp⁡(vw′TvwI)

每个词学两个向量：作为中心词的 v，作为上下文词的 v′。最终通常用 v。

3.2.2 Negative Sampling：让训练可行 ​

完整 softmax 的分母要遍历整个词表（10 万次内积）——太慢。

Negative Sampling 把这个改为二分类：

LNS=log⁡σ(vwO′TvwI)+∑i=1kEwi∼Pn(w)log⁡σ(−vwi′TvwI)

意思：让正样本（真实上下文词）相似度大，让 k 个随机负样本相似度小。k 通常 5-20。

3.3 训练过程 ​

  1. 随机初始化所有词的两个向量
  2. 扫描语料，对每个 (中心词, 上下文词) 对
  3. SGD 更新：让中心词向量更接近上下文词向量，远离负样本
  4. 重复几轮 → 收敛

3.4 训练目标 ≠ 模型用途 ​

直觉

Word2Vec 的训练目标是"预测上下文"——但真正的产出不是预测结果，是训练过程中学到的向量表示。

这些向量是"副产品"，却成了最有价值的东西。

这个思想——预训练（pre-training）的目标不是任务本身，而是学到好的表示——会在 L13（BERT vs GPT）、L15（预训练）成为 LLM 时代的核心原则。

[!abstract] 呼应线 🔗 预训练范式（L11 此处 → L13 → L15 → L18）：Word2Vec 是预训练范式的鼻祖——用一个 proxy task（预测上下文）学出有用的表示，然后转移到下游任务。BERT 把这变成 masked language modeling，GPT 把这变成 next-token prediction，Llama 把这放大 1000×。思想没变，规模和复杂度变了。

3.5 GloVe：基于全局共现的替代 ​

[!quote] 历史 Pennington, Socher, Manning (Stanford) 2014 发表 GloVe[3]——基于全局共现矩阵的因式分解。

哲学不同：

  • Word2Vec：局部（窗口）+ 预测目标
  • GloVe：全局（共现矩阵）+ 统计目标

实证：两者效果相当，看任务而定。GloVe 在某些类比任务上更稳定。

GloVe 公式：

J=∑i,j=1Vf(Xij)(wiTwj+bi+bj−log⁡Xij)2

其中 Xij 是词 i 和词 j 在语料中的共现次数。

3.6 FastText：处理子词 ​

FastText[4] (Facebook 2016) 把每个词表示为字符 n-gram 的平均——能处理 OOV 词、能学到形态学结构。多语言场景的标配。

4. 向量空间的几何 ​

4.1 三种距离 / 相似度 ​

度量公式适用
余弦相似度cos⁡(a,b)=a⋅b|a||b|NLP 标配
点积a⋅bTransformer 用
欧氏距离|a−b|2部分聚类

核心概念

余弦相似度只看方向，不看模长——这正是 embedding 想要的（"猫"和"狗"应该相似，无论它们的向量有多长）。

点积 = 余弦 × 模长。Transformer 的 attention 用点积——所以模长会隐式编码"重要性"。

4.2 维度的选择 ​

典型 embedding 维度：

模型维度
Word2Vec100 - 300
GloVe50 / 100 / 300
BERT-base768
BERT-large1024
GPT-312288
Llama-3-70B8192

常见误区

"维度越高 = 越好" 是错的。Word2Vec 300 维 vs 1000 维差距 < 2%，但显存翻 3×。维度收益是次线性的——边际递减很快。

4.3 t-SNE / UMAP：高维可视化 ​

[!quote] 历史 van der Maaten & Hinton 2008 提出 t-SNE[5]——把高维向量映射到 2D/3D 用于可视化。McInnes et al. 2018 提出 UMAP[6]——更快、更好的替代。

t-SNE / UMAP 只用于可视化——不能用作下游任务的输入（不稳定、不可逆）。

图 11.2：词向量在二维 t-SNE 投影中的语义聚类——颜色按预定义类别着色。来源：本课程 demo。

5. 向量空间的统一性：三种模态，同一种语言 ​

向量空间的力量不仅限于文字。

5.1 任何模态都可嵌入 ​

模态嵌入方式结果
文字Word2Vec / GloVe / BERT 等 contextual embedding每词/token 一个向量
图像CNN 最后一层（去分类头）/ ViT 的 [CLS] token每张图一个向量
声音转成频谱图后当"图像"处理，或 wav2vec 直接编码每段音频一个向量
代码CodeBERT / GraphCodeBERT每段代码一个向量
视频帧级 embedding 聚合 / TimeSformer每个视频一个向量
图结构GNN（GCN, GraphSAGE）每个节点一个向量
3D 形状PointNet / DGCNN每个点云一个向量

核心概念

向量空间是多模态的通用语言。无论原始数据是文字、图像、声音——经过嵌入后都变成同一种东西：高维空间中的点。

而在这个空间里，最重要的操作是余弦相似度：

sim(a,b)=a⋅b∥a∥∥b∥

两个向量方向越接近，它们代表的东西越相似——无论它们是文字还是图像还是声音。

5.2 多模态对齐：CLIP ​

[!quote] 历史 2021 年 OpenAI 发表 CLIP[7]——把图像和文字嵌入同一个向量空间。训练目标：让 (图像, 描述) 配对在向量空间中接近，让不配对的远离。

4 亿组 (图像, 文字) 对训练。结果：能用文字搜图像、能 zero-shot 图像分类、能给图像生成 caption。这是 L29（多模态）的核心。

[!abstract] 呼应线 🔗 向量空间 (L11 起点 → L23 → L29 → L34)：本讲建立的"一切皆可嵌入"概念，将在 L23（向量数据库 + ANN 搜索）、L29（CLIP / GPT-4V）、L34（safety/对齐——人类偏好就是向量分布微调）中持续核心。

6. 静态嵌入的局限：「bank」的困境 ​

Word2Vec 给每个词一个固定向量，无论上下文如何。但很多词有多个含义：

  • "I went to the bank to deposit money."（银行）
  • "The river bank was covered in grass."（河岸）

在 Word2Vec 里，"bank" 只有一个向量——它是 "银行" 和 "河岸" 两种含义的某种混合平均。这在很多场景下不够好。

6.1 静态 → 上下文化 ​

理想的解：让每个词的向量根据上下文动态变化：

  • 在 "deposit money in the bank" 中，"bank" 的向量倾向于"银行"
  • 在 "river bank" 中，"bank" 的向量倾向于"河岸"

核心概念

上下文化嵌入（Contextualized Embedding）的需求是 Transformer 出现的直接驱动力。ELMo (2018), BERT (2018), GPT (2018) 都解决了这件事——每个词的向量根据上下文不同而不同。

L12 (Transformer)、L13 (BERT vs GPT) 会展开。

6.2 从静态到动态：Attention 的向量空间解读 ​

L10 的 Attention 机制可以重新理解为向量空间中的操作：

  • 编码器的每个隐藏状态是向量空间中的一个点
  • 打分是计算两个向量的相似度（点积）
  • 加权求和是在向量空间中根据相似度做软性检索

如果让每个词的向量根据上下文动态变化，同时同时看到所有位置（不被 RNN 的逐步处理限制）——那就得到了上下文化嵌入。

这正是 L12 Transformer 要做的事。

7. 向量数据库 / ANN 搜索：工业基础设施 ​

Embedding 不只是"拿来算相似度"——它需要大规模检索基础设施。

7.1 向量数据库 ​

存几亿/几十亿向量，每秒响应几千次查询。主流系统：

系统类型特点
Pinecone云服务易用，初创企业首选
Weaviate开源内置混合搜索
Milvus开源国内首选
Qdrant开源Rust 实现，高性能
pgvectorPostgreSQL 扩展已有 PG 部署直接用
FAISS库Facebook 出品，工业标准
ChromaDB嵌入式轻量级 RAG 项目

L23 / L24 会展开 RAG 实战。

7.2 ANN（Approximate Nearest Neighbor）算法 ​

精确最近邻 = 暴力遍历——10 亿向量不可能。ANN 牺牲一点精度换巨大速度：

算法思路
LSH (Locality-Sensitive Hashing)相似向量哈希到同一桶
KD-Tree / Ball Tree空间划分（低维有效）
HNSW[8]分层小世界图——主流方法
IVF + PQ倒排索引 + 乘积量化（FAISS）
ScaNN[9]Google 出品，超大规模

HNSW + PQ 是 2024 年向量数据库的事实标准。

8. 失败模式 / 反例 / 边界 ​

8.1 「向量近 = 语义近」反例 ​

Word2Vec 中 "good" 和 "bad" 向量距离比 "good" 和 "excellent" 还近——因为它们出现在相同的句法位置。语义 ≠ 分布相似。

这是经典 word embedding 的根本局限。Sentence-BERT、E5、BGE 等现代 embedding 用对比学习专门解决这件事。

8.2 Embedding 偏见的传递 ​

早期 Word2Vec 中：

  • king→−man→+woman→≈queen→ — 美好
  • doctor→−man→+woman→≈nurse→ — 暴露语料偏见[10]
  • programmer→−man→+woman→≈homemaker→ — 同上

这一问题在 LLM 中至今未根除。L34 (Safety) 会回到。

8.3 「higher dim = better」误解 ​

如 §4.2 所述。

8.4 类比测试 (analogy task) 的瓦解 ​

Linzen 2016[11] 证明 Word2Vec 在类比任务上的"成功"很大程度上是评估指标偏向——是教学时常被略过的反例。

8.5 t-SNE / UMAP 可视化的误读 ​

t-SNE 的 cluster 大小、cluster 间距都没有意义——只反映了优化算法的特性，不反映原始空间。Distill 文章[12] 详细讨论了 t-SNE 的陷阱。

8.6 Embedding 不是最终目的 ​

Embedding 只是表示——它要服务于下游任务（分类、检索、生成）。一个 embedding 在 benchmark 上很好，不等于在你的特定任务上好。

8.7 "Embedding 越多越好"误解 ​

RAG 系统中，chunk 太小 → 失去上下文；chunk 太大 → 检索粗糙。Embedding 数量不是越多越好——是匹配你的查询粒度才好。

10. 本讲小结 ​

  1. 嵌入把离散符号映射到连续向量空间——相似的东西距离近，方向编码语义关系。
  2. King - Man + Woman ≈ Queen 是 NLP 史上最重要的概念发现之一。
  3. One-Hot 不够——维度灾难 + 语义失明。
  4. Word2Vec 从上下文学语义——"预测上下文"的训练目标让向量自动获得语义结构。
  5. GloVe / FastText 是 Word2Vec 的同代替代。
  6. 余弦相似度 / 点积 是向量空间中最重要的两种相似度——Transformer attention 用点积。
  7. 向量空间是多模态通用语言——文字、图像、声音、代码都可嵌入。
  8. CLIP 把图像和文字对齐到同一空间——多模态时代的奠基。
  9. 静态嵌入有局限——"bank" 困境驱动了上下文化嵌入（→ L12）。
  10. 向量数据库 + ANN 是工业基础设施——HNSW 是事实标准。
  11. 预训练范式起源于 Word2Vec——"训练目标 ≠ 模型用途" 思想贯穿到 GPT-4。
  12. Embedding 有偏见——LLM 时代仍未根除。

下一讲预告 ​

敌意问题：Word2Vec 给每个词一个固定向量——"bank" 永远是同一个点。如果让每个词的含义根据上下文动态变化，同时能同时看到所有位置（不受 RNN 逐步处理的限制）——这种模型该长什么样？

答案是："Attention is all you need."

第 12 讲——「Transformer」——是这门课的核心讲次。它将彻底颠覆 L06-L10 建立的信念：

  • 特征不需要手工设计（L11 已颠覆）
  • 结构先验不需要硬编码（L12 颠覆）
  • 序列不需要逐步处理（L12 颠覆）

我们从第二幕（归纳偏置路线）进入第三幕（规模路线）。
