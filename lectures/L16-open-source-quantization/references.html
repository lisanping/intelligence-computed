第 16 讲 · 资料收集清单 ​

分级：⭐⭐⭐ 必读（讲师自己准备讲稿前必过）· ⭐⭐ 推荐（学员延伸） · ⭐ 可选（深挖）

Last Verified: 2026-05-04 (links and citations checked; replace this when re-verifying)

📄 论文

  1. ●●●○○
    LLaMA: Open and Efficient Foundation Language Models

    开源革命的起点——用更少资源训出可比肩 GPT-3 的模型，本讲 LLaMA 泄露事件的主角

    作者 / 年份：Touvron et al., Meta, 2023

    链接：arxiv:2302.13971

  2. ●●●○○
    The Llama 3 Herd of Models

    LLaMA 3/3.1 全景——15T tokens 训练 + 405B 参数，开源首次追平 GPT-4 级能力

    作者 / 年份：Grattafiori et al., Meta, 2024

    链接：arxiv:2407.21783

  3. ●●●○○
    GPTQ: Accurate Post-Training Quantization for Generative Pre-trained Transformers

    首个实用的 4-bit 量化方案——逐层量化 + 误差补偿，量化段核心参考

    作者 / 年份：Frantar et al., 2022

    链接：arxiv:2210.17323

  4. ●●●○○
    AWQ: Activation-Aware Weight Quantization for LLM Compression and Acceleration

    "保护重要权重"的量化策略——基于激活值识别 salient weights

    作者 / 年份：Lin et al., MIT, 2023

    链接：arxiv:2306.00978

  5. ●●●○○
    Efficient Memory Management for Large Language Model Serving with PagedAttention

    vLLM 核心论文——PagedAttention 解决 KV Cache 碎片，推理框架段主参考

    作者 / 年份：Kwon et al., UC Berkeley, 2023

    链接：arxiv:2309.06180

  6. ●●○○○
    Mistral 7B

    7B 参数击败 LLaMA 2-13B——Sliding Window Attention + GQA

    作者 / 年份：Jiang et al., Mistral AI, 2023

    链接：arxiv:2310.06825

  7. ●●○○○
    Mixtral of Experts

    开源 MoE 的标志性工作——8×7B，激活 13B，性能接近 LLaMA 2-70B

    作者 / 年份：Jiang et al., Mistral AI, 2024

    链接：arxiv:2401.04088

  8. ●●○○○
    Qwen2 Technical Report

    中文最强开源家族——0.5B-72B 全尺寸 + 中英双语领先

    作者 / 年份：Qwen Team, Alibaba, 2024

    链接：arxiv:2407.10671

  9. ●●○○○
    DeepSeek-V3 Technical Report

    $5.5M 训出追平 GPT-4 的模型——MoE + MLA + FP8

    作者 / 年份：DeepSeek-AI, 2024

    链接：arxiv:2412.19437

  10. ●●○○○
    LLM.int8(): 8-bit Matrix Multiplication for Transformers at Scale

    首个大规模 Transformer INT8 量化方案——发现 outlier 特征维度问题

    作者 / 年份：Dettmers et al., 2022

    链接：arxiv:2208.07339

  11. ●●○○○
    QLoRA: Efficient Finetuning of Quantized LLMs

    量化 + LoRA 结合——4-bit Base Model + LoRA 微调，连接 L25

    作者 / 年份：Dettmers et al., 2023

    链接：arxiv:2305.14314

  12. ●○○○○
    SqueezeLLM: Dense-and-Sparse Quantization

    非均匀量化 + 稀疏处理 outliers

    作者 / 年份：Kim et al., 2023

    链接：arxiv:2306.07629

  13. ●○○○○
    SmoothQuant: Accurate and Efficient Post-Training Quantization for Large Language Models

    激活-权重联合平滑——将量化难度从激活转移到权重

    作者 / 年份：Xiao et al., 2023

    链接：arxiv:2211.10438

  14. ●○○○○
    Alpaca: A Strong, Replicable Instruction-Following Model

    $600 微调 LLaMA-7B → ChatGPT 级能力——开源微调爆发的导火索

    作者 / 年份：Taori et al., Stanford, 2023

    链接：stanford_alpaca
