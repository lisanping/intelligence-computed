第 3 讲 · 学习即优化 — 一个公式统治所有 ​

既然人类智能是"压缩过的统计直觉"，那机器如何"学会"这种直觉？

答案是一个公式——所有机器学习都在做同一件事：在看不见全貌的地形中寻找最低点。

这一讲是这门课的"骨架讲"。所有后续 30+ 讲讲的方法——线性回归、SVM、CNN、Transformer、扩散模型、RLHF、推理模型——都是同一个公式的不同实例。理解这一讲，你就拿到了机器学习的"统一场论"。

前置知识核心产出建议用时
L01（认知偏差与统计直觉）① 掌握 ML 统一框架：模型 + 数据 + 损失 + 优化器 ② 理解"损失曲面上的盲人登山者"几何直觉 ③ 推导梯度下降公式与 SGD 的来源 ④ 理解 momentum / Adam / AdamW 的演化逻辑 ⑤ 区分欠拟合 / 过拟合 / 双下降现象 ⑥ 掌握 bias-variance 分解 ⑦ 写完一个 100 行的训练循环 ⑧ 拿到 L04（经典 ML）/ L12（Transformer）/ L14（Scaling Law）的伏笔阅读 ~70 分钟 + 动手 ~30 分钟

从上一讲到这一讲 ​

L01 留了一个问题：如果人类智能真的只是"统计直觉"，那它能被一个数学公式捕获吗？

能。就是这个：

θ∗=arg⁡minθL(fθ(x),y)

翻译成自然语言：找到一组参数 θ，让模型 f 的预测和真实答案之间的差距 L 最小。

就这么简单。

  • 线性回归在做这件事
  • 决策树在做这件事
  • SVM 在做这件事
  • CNN 在做这件事
  • GPT-4 在做这件事

区别只在于——"模型"有多复杂、"数据"有多大、"差距"怎么衡量、"找"的方法有多聪明。

本讲的任务：把这个公式拆开，逐个理解四个要素，然后亲手用代码体验一次完整的"学习"。

1. 为什么需要统一框架 ​

你可能听说过很多名词——线性回归、决策树、SVM、随机森林、神经网络、深度学习、强化学习、自监督……它们看起来完全不同。

很多人学了三年机器学习，脑子里全是零散算法，像一堆没有目录的工具——知道每把锤子长什么样，但不知道它们为什么都是锤子。

直觉

想象你去一个陌生城市旅行。

方式一：死记每条路——"从酒店左转走 200 米看到红灯右转"。 方式二：先看一张地图——街道网格、地铁线路、主要地标。

方式一记忆量正比于路线数。方式二记忆量正比于地图大小（远小于所有路线之和）。统一框架就是 ML 的地图。

接下来 33 讲中你遇到的每一个模型、每一个技术，都会落在今天画出来的这张地图上。

核心概念

ML 的统一框架，就是把所有学习问题归约为优化问题。所谓"学习"——就是在某个参数空间里搜索一个让某个目标函数最小化的点。这一归约听起来抽象，但它的力量在于：所有为优化发明的数学工具（梯度、二阶方法、随机化、正则化、约束）都可以无差别地用在所有学习算法上。

2. 四大支柱 ​

所有机器学习都由四个要素组成：数据（Data）、模型（Model）、损失函数（Loss）、优化器（Optimizer）。

我们逐一拆解，每一节先讲直觉，再给数学。

2.1 数据：你试图绘制的领土 ​

直觉

想象你是一个制图师，被空投到一片完全陌生的大陆。任务是画出地图，但你不能飞到天上俯瞰——只能站在地面一个点一个点地测量。

  • 测量 10 个点 → 地图很粗糙
  • 测量 10,000 个点 → 开始有模有样
  • 测量 1,000,000 个点 → 相当精确

数据就是这些测量点。每一条数据都是对真实世界的一次采样。

数学语言：数据是一组输入-输出对 {(xi,yi)}i=1N，其中：

  • xi∈Rd 是输入（一张图片、一段文字、一组数值）
  • yi 是标签（"猫"、"正面情感"、"房价 500 万"）

两个关键事实贯穿整门课：

  1. 数据有限——训练数据只是真实世界的一个样本，你永远不可能测量所有点。
  2. 数据有噪声——标注可能有错，数据可能有缺失，采样可能有偏。

常见误区

"更多数据总是更好"是错的。如果数据有系统性偏差（如：只在阳光下拍的猫照片），加更多同样偏差的数据只会让模型更自信地学错。L05 会展开"数据质量 > 数据数量"的具体场景。

2.1.1 i.i.d. 假设 ​

经典 ML 的隐含假设：训练数据是从某个真实分布 D 中独立同分布（i.i.d., independent and identically distributed）采样的。

(xi,yi)∼D,i.i.d.

这个假设是所有泛化保证的基石——但几乎所有真实场景都违反它：

  • 时间漂移：今天的用户行为不等于昨天的（推荐系统）
  • 分布偏移：训练用学术论文测试用 Twitter（NLP）
  • 采样偏差：训练数据来自付费用户测试在免费用户上（B2C）

L05、L34 会回到这个问题。

2.2 模型：一块可以弯曲的橡皮泥 ​

有了数据，下一步是一个模型——一个根据输入做出预测的函数。

2.2.1 从直线到神经网络 ​

最简单的模型是一条直线：

y^=w⋅x+b

w 是斜率，b 是截距。这条直线有两个参数——调 w 改变斜率，调 b 上下平移。"学习"就是找到最好的 w 和 b，让直线尽可能贴合数据。

但一条直线能拟合的东西很有限。如果数据是弯曲的，可以换更灵活的模型：

y^=w3x3+w2x2+w1x+b

多项式有更多参数，曲线能弯得更厉害。再复杂一点？神经网络——一层又一层的线性变换加非线性激活，理论上可以逼近任何连续函数（Universal Approximation Theorem[1]）。

核心概念

模型就是一个带参数的函数 fθ(x)，其中 θ 是所有可调参数的集合。

模型参数量
线性回归（1 维）2
多项式（5 阶）6
LeNet (MNIST)~60K
ResNet-50~25M
GPT-2 small117M
GPT-3175B
GPT-4 (估)~1.8T (MoE 激活更少)
DeepSeek-V3671B (37B 激活)

学习的目标就是找到让预测最准的那组 θ。

直觉

模型是一块橡皮泥：

  • 直线 = 一根细条，只能做简单形状
  • 多项式 = 一块更大的橡皮泥，能捏出复杂形状
  • 神经网络 = 一吨橡皮泥，理论上能捏出任何形状

但橡皮泥越多，越容易捏出"看上去很像训练数据、但完全不对"的形状——这就是过拟合（§4）。

2.2.2 归纳偏置 ​

每个模型有自己的归纳偏置（inductive bias）——它在没有数据时倾向于的解的集合。

模型归纳偏置
线性回归输入与输出是线性关系
决策树决策边界是轴对齐的矩形
CNN局部性 + 平移等变 + 层级抽象（L07）
RNN序列依赖 + 时间方向
Transformer几乎无偏置（任意位置可交互）（L12）

L07 与 L12 会反复回到这个概念。

2.3 损失函数：你到底有多错？ ​

模型做了预测 y^，真实答案是 y。我们需要一种方式量化错误有多大——把"错误"压缩成一个数字。这就是损失函数的工作。

2.3.1 回归任务：MSE ​

最简单的损失函数是均方误差（Mean Squared Error）：

LMSE=1N∑i=1N(y^i−yi)2

直觉

对每一个数据点，算预测值和真实值的差，平方（让大错误被放大），然后取平均。

为什么平方？两个原因：

  1. 正负误差不抵消——预测高了 5 和低了 5 应该一样"错"
  2. 大错误的惩罚远超小错误——差 10 的平方是 100，差 1 的平方只是 1

平方在数学上还有一个好处：导数好算（线性的）。绝对值（L1 损失）不可导（在 0 处），优化更麻烦。

2.3.2 分类任务：交叉熵 ​

二分类的标准损失是二元交叉熵（Binary Cross-Entropy）：

LBCE=−1N∑i[yilog⁡p^i+(1−yi)log⁡(1−p^i)]

多分类用 Softmax + Cross-Entropy：

LCE=−1N∑ilog⁡pi,yi

其中 pi,yi 是模型给样本 i 真实类别的概率。

核心概念

交叉熵的信息论解释：L=−log⁡p 是信息论中的编码长度（self-information）。最小化交叉熵 = 最小化"用模型预测分布编码真实标签所需的比特数"。

这是 L13 "预测 = 压缩 = 理解" 论证的数学起点。

2.3.3 损失函数清单 ​

任务标准损失
回归MSE / MAE / Huber
二分类BCE
多分类Softmax + CE
排序Pairwise hinge / Ranknet / LambdaRank
生成NLL（负对数似然）

LLM 对齐DPO / PPO with reward (L18)

核心概念

损失函数就是一个自动评判者（Evaluator）。它自动告诉模型"你做得好不好"。这个看似简单的想法会贯穿整门课：

  • L18（对齐）：人类当 Evaluator，通过 RLHF 告诉模型"这个回答比那个好"
  • L20（推理模型）：模型内置 Evaluator，学会自我检查
  • L26（Agent）：显式的 Evaluator 决定计划要不要修改
  • L31（LLMOps）：用 LLM 当评判者（LLM-as-Judge）
  • L34（Safety）：Evaluator 被 hack 是核心威胁

从损失函数到 LLM-as-Judge，"如何评判好坏"这条线贯穿整门课。今天先记住起点。

[!abstract] 呼应线 🔗 Evaluator（L03 起点 → L18 → L20 → L26 → L31 → L34）：损失函数是自动 Evaluator 的最简形态。后续讲次会看到这个概念从数学公式进化为人类偏好、自我检查、乃至 LLM-as-Judge。

🔗 Physical Bill（L03 预埋 → L07 → L12 → L14 → L22 → L31）：同一个 loss 曲线，背后是不同量级的算力账单。L03 先建立“每一次优化都要付计算成本”的概念，L07 会给出 AlexNet 的第一代 GPU 账单，L12-L14 再升级到大模型时代的万卡账单。

2.4 优化器：看不见全貌的登山者 ​

我们有了模型、数据、损失函数。损失函数给了一个数字——"你有多错"。现在问题变成：怎么调参数，让这个数字变小？

2.4.1 梯度下降的直觉 ​

直觉

想象你是一个蒙着眼睛的登山者，被丢在一片山脉中间。任务是找到最低的山谷。但你看不见周围的地形——唯一的感觉是脚下的坡度。

你会怎么做？一直朝下坡方向走。这就是梯度下降。

2.4.2 公式与解读 ​

梯度下降（Gradient Descent）的更新公式：

θt+1=θt−η⋅∇θL

逐项解读：

  • θt：你现在站的位置（当前参数值）
  • ∇θL：脚下的坡度——数学上叫梯度——指向损失增大最快的方向
  • η：步长，也叫学习率——你每步迈多大
  • θt+1：新位置（更新后的参数）

就这样，一步一步走。每走一步，损失就小一点。走够多步，就到了谷底。

没有魔法，只是反复问自己："从这里，哪个方向最陡？然后走一步。"

2.4.3 为什么是负号？ ​

梯度 ∇L 指向损失增大最快的方向。我们要减小损失，所以朝反方向走——即 −∇L。

这是初学者最常错的地方。记住：梯度指向上山，我们要下山。

[!abstract] 呼应线 🔗 物理账单（L03 预埋 → L14 → L15 → L31）：每走一步都要算一次梯度，算梯度要花计算资源。GPT-3 训练用了 3.14×1023 次浮点运算，耗资约 460 万美元；GPT-4 估算耗资 ≥ $1 亿；GPT-5 训练算力是 GPT-4 的 ~10×。智能不是免费的——L14（Scaling Law）会正式展开。

2.5 四大支柱汇总 ​

回到开场公式：

θ∗=arg⁡minθL(fθ(x),y)
符号含义对应支柱
fθ带参数的函数模型
x,y输入和标签数据
L衡量错误的方式损失函数
arg⁡min找到让损失最小的参数优化器的目标

从今天开始到课程结束，每当遇到一个新方法，都用四个问题拆解它：

  1. Model：什么结构？什么归纳偏置？
  2. Data：什么数据？多少？什么质量？
  3. Loss：怎么定义"好"和"不好"？
  4. Optimizer：怎么找到最优参数？

这四个问题就是 ML 指南针。

3. 在看不见的山脉中行走：可视化直觉 ​

理解了四大支柱的概念后，需要建立几何直觉——理解"学习"这个过程在空间中长什么样。

3.1 损失曲面：你脚下的地形 ​

把所有可能的参数组合画在平面上（两个参数分别对应 x 轴和 y 轴），对每一组参数算出损失，画成高度——就得到一个损失曲面（Loss Landscape）。

图 3.1：线性回归的 3D 损失曲面。x/y 轴分别为参数 w 和 b，z 轴为 MSE 损失。碗形曲面意味着只有一个全局最优。来源：demo/loss_landscape_viz.py 生成。

高处（红色）= 损失大的参数组合（模型预测很差） 低处（蓝色）= 损失小的参数组合（模型预测接近正确） 最低点 = 最优参数 θ∗

曲面的形状完全取决于模型 + 数据 + 损失函数的组合：

  • 简单问题（线性回归 + MSE）：曲面是光滑的碗——只有一个最低点（凸优化），梯度下降保证找到它。
  • 复杂问题（深度神经网络）：曲面像崎岖山脉——到处是山谷、山脊、鞍点（saddle point）。

3.2 梯度下降轨迹 ​

在等高线图上观察梯度下降在做什么：

图 3.2：梯度下降在等高线图上的轨迹。从随机初始点出发，沿梯度反方向逐步逼近最低点。注意一开始坡陡步长大，越接近谷底步长越小。

3.3 局部最优的陷阱 ​

如果损失曲面是凸的（一个碗），梯度下降保证找到全局最优。但真实曲面不是碗——它是崎岖山脉。

假设曲面有山谷 A 和更深的山谷 B：

  • 从左边出发 → 梯度下降带你到 A 然后停下——A 底部坡度为 0，登山者觉得到了最低点。
  • 但 B 更低。这就是局部最小值（Local Minimum）的陷阱。

3.3.1 鞍点：高维空间中真正的敌人 ​

在高维空间中还有鞍点——在一个方向上是谷底，在另一个方向上是山顶。

[!quote] 历史 Goodfellow et al. 2015 的研究表明[2]：在高维网络中，鞍点比局部最小值更常见、更难处理。直观原因：在 d 维空间中，一个临界点是"局部最小"需要所有 d 个 Hessian 特征值都为正——概率随 d 指数衰减。

好消息：高维网络的局部最小值大多接近全局最小值——梯度下降找到的"局部最优"通常足够好。这部分解释了为什么深度学习"work"。

3.4 SGD 的噪声：有用的"地震" ​

怎么逃离局部最优？答案之一：随机梯度下降（SGD）。

Batch Gradient Descent：每步用全部数据算梯度——路径光滑，但容易卡在局部最优。 Stochastic Gradient Descent：每次只用一小批数据（mini-batch）算梯度——路径会抖动。

直觉

想象你卡在一个浅山谷里。如果你走路很稳（批梯度下降），你永远出不来。但如果时不时有随机地震把你颠一下，你有可能被颠出浅谷，滚进更深的谷底。

SGD 的噪声就是这种"地震"——它帮助你逃离局部最优。

更深的研究[3] 表明：SGD 倾向于找到平坦最小值（flat minima）——损失曲面在该点附近变化平缓。这种最小值泛化更好——这是 SGD 比"完美"优化器在实践中更优秀的部分原因。

3.5 学习率：最重要的超参数 ​

学习率 η 决定每步迈多大——可能是 ML 中最重要的超参数。

学习率效果比喻
太大（η=10）每步跨过整个山谷，来回弹跳，不仅不收敛——损失反而上升巨人在山谷里蹦迪
太小（η=0.0001）每步像蚂蚁爬行，3000 步了还在半山腰蚂蚁登珠峰
刚好（η=0.01）稳步下降，在合理步数内到达谷底正常登山者

3.5.1 学习率调度 ​

学习率不应该是常数。常见调度：

  • Step decay：每 N 步把学习率乘一个常数（如 0.1）
  • Cosine annealing：按余弦曲线从 η0 降到 0
  • Warmup + Cosine：前 K 步线性升到 η0，再 Cosine 降——Transformer 训练事实标准
  • One-Cycle：先升再降——Smith 2017[4] 在 CIFAR 等任务上 SOTA

L15（Pretraining）会展开 LLM 训练的学习率调度细节。

3.6 优化器进化：从盲人到有惯性的盲人 ​

3.6.1 SGD + Momentum ​

原始 SGD 在窄长谷底里锯齿形振荡，进展缓慢。

Momentum[5] 记住前几步的方向：

vt=βvt−1+∇θL,θt+1=θt−ηvt

效果：在正确方向上加速，在振荡方向上抵消——像一颗滚下山坡的球，越滚越快。β 通常取 0.9。

3.6.2 Adam 与 AdamW ​

[!quote] 历史 Kingma & Ba 2014 的 Adam 论文[6] 是 ML 史上被引用最多的论文之一（180,000+ 次）。它的核心想法：给每个参数自适应步长——震荡多的参数步子小，变化平稳的参数步子大。

更新公式：

mt=β1mt−1+(1−β1)gt（一阶矩估计）vt=β2vt−1+(1−β2)gt2（二阶矩估计）m^t=mt1−β1t,v^t=vt1−β2t（偏差修正）θt+1=θt−ηv^t+ϵm^t

通常 β1=0.9,β2=0.999,ϵ=10−8。

3.6.3 AdamW ​

Loshchilov & Hutter 2019[7] 发现：Adam 加 weight decay 时，传统实现把 weight decay 当作 L2 正则项加到梯度——这在 Adam 里不是真的 weight decay。AdamW 把 weight decay 解耦：

θt+1=θt−η(m^tv^t+ϵ+λθt)

AdamW 在大多数现代深度学习训练中取代了 Adam 成为默认。GPT-3、Llama、Stable Diffusion 都用 AdamW。

3.6.4 优化器对比 ​

优化器特点适用场景
SGD锯齿形，慢，泛化有时更好大规模训练、某些精调
SGD + Momentum圆滑加速经典深度学习训练
Adam快速、自适应大部分深度学习
AdamWAdam + 解耦 weight decay2024 默认——LLM、扩散、vision
Lion[8]仅 sign(gradient)，省显存大模型训练（部分场景）
Sophia[9]二阶方法，对 LLM 训练加速实验阶段
Shampoo / DistShampoo[10]块对角 K-FAC 近似大规模分布式训练

深入阅读

关于优化器的更完整比较，推荐 Sebastian Ruder 的经典博客 An Overview of Gradient Descent Optimization Algorithms[11]，系统梳理从 SGD 到 Adam 的全部变体。Distill.pub 上的 Why Momentum Really Works[12] 用交互式可视化解释动量的几何直觉。

4. 过拟合与欠拟合：橡皮泥的两难 ​

直线能学，那曲线呢？

假设真实关系是 y=0.5x3−2x+1。用不同复杂度的模型去拟合：

模型参数量在训练集上在新数据上诊断
直线（degree=1）2误差大误差大欠拟合（Underfitting）
三次多项式（=数据真实复杂度）4误差小误差小刚好
20 次多项式21误差极小误差极大过拟合（Overfitting）

4.1 经典 Bias-Variance 权衡 ​

把测试误差分解：

E[(y^−y)2]=(Bias)2⏟模型本身的偏见+Variance⏟对训练集的敏感度+Irreducible noise⏟数据本身的噪声
  • Bias 高 = 欠拟合：模型太简单，不能表达真实关系。
  • Variance 高 = 过拟合：模型对训练数据细节过度敏感，换一份数据完全不同。

经典 ML 教材教导：增加模型复杂度 → bias 下降、variance 上升 → 最优点在中间。

4.2 过拟合的真实视觉 ​

20 次多项式在每个训练点都精确穿过——但点之间剧烈震荡。新数据来时它自信地给出离谱的答案。

4.3 双下降（Double Descent）：经典教材被推翻 ​

[!quote] 历史 2019 年，Belkin, Hsu, Ma, Mandal 在 PNAS 发表 Reconciling modern machine learning practice and the classical bias-variance tradeoff[13]——证明 bias-variance 经典曲线在深度学习里被破坏了。

他们发现：当模型容量超过"插值阈值"（恰好能拟合训练集的那个点），测试误差不是单调上升——而是先升后降，最终低于经典最优点。这就是 Double Descent（双下降）。

测试误差
    │
    │     ╱╲
    │    ╱  ╲      经典区域 + 现代区域
    │   ╱    ╲    /
    │  ╱      ╲  /
    │ ╱        ╲/
    │╱          (双下降)
    ╰────────────────→ 模型容量
     欠拟合 | 经典最优 | 插值阈值 | 现代过参数化区域

这一现象至今没有完整的理论解释，但它颠覆了 ML 教材几十年的"复杂模型一定过拟合"的教条。LLM 时代的"越大越好"在理论上有了部分依据。L14 会展开。

4.4 防止过拟合的工具箱 ​

经典方法：

方法思路
更多数据数据多了模型就过拟合不动了
数据增强翻转、裁剪、加噪——人工"造"数据
L2 正则（Ridge）L+λ|θ|2 ——惩罚大权重
L1 正则（Lasso）L+λ|θ|1 ——产生稀疏权重
Dropout[14]训练时随机关闭神经元
Early Stopping监控验证集 loss，loss 上升时停止训练
集成多个模型投票（Random Forest 思想）
Weight Decay等价于 L2 正则（在 SGD 中）

LLM 时代的特殊方法：

  • Pretrain on diverse data → 隐式正则化
  • 不显式 early stopping——LLM 训练通常不到一个 epoch（数据足够大）
  • Cosine schedule + 大模型——足够过参数化时反而帮助
  • Mixup / CutMix（视觉特有）

5. 从概念到代码：100 行训练循环 ​

任何机器学习训练，本质上都是这 5 步循环。

python
# 1. 准备数据
X_train, y_train = load_data()
dataloader = DataLoader(X_train, y_train, batch_size=32, shuffle=True)

# 2. 定义模型
model = nn.Sequential(
    nn.Linear(d_input, 128),
    nn.ReLU(),
    nn.Linear(128, d_output),
)

# 3. 定义损失函数
loss_fn = nn.MSELoss()  # 或 nn.CrossEntropyLoss() for 分类

# 4. 定义优化器
optimizer = torch.optim.AdamW(model.parameters(), lr=1e-3)

# 5. 训练循环
for epoch in range(num_epochs):
    for x_batch, y_batch in dataloader:
        # Forward
        y_pred = model(x_batch)

        # Compute loss
        loss = loss_fn(y_pred, y_batch)

        # Backward
        optimizer.zero_grad()
        loss.backward()  # ← 自动微分计算梯度
        optimizer.step()  # ← 一步参数更新

核心概念

这 5 步是所有现代机器学习训练的骨架。从训练 LeNet 到训练 GPT-4，步骤完全一样——区别只在每一步的具体内容。

  • 训练 GPT-3：步骤一样，但"模型"是 175B 参数 Transformer，"数据"是 300B token，"损失"是 next-token cross-entropy，"优化器"是 AdamW + 余弦调度
  • 训练 ResNet-50：步骤一样，模型是 25M 参数 CNN，数据是 ImageNet 1.2M 图，损失是分类 CE，优化器是 SGD + Momentum

6. 自动微分：让我们能轻松算梯度的魔法 ​

如果你需要手动算每个网络的梯度，深度学习不可能成为现实。

自动微分（Automatic Differentiation, autodiff）解决了这件事——你只需要写前向传播代码，框架自动算出梯度。

6.1 反向传播的本质 ​

反向传播（Backpropagation）本质是链式求导沿计算图反向传递。

例：y=f(g(h(x)))

∂y∂x=∂y∂f⋅∂f∂g⋅∂g∂h⋅∂h∂x

计算量：和前向传播相同（O(n)）。这就是反向传播伟大之处——给定计算图，反向算所有参数的梯度只需要一次反向遍历。

6.2 PyTorch / JAX / TensorFlow 的实现 ​

PyTorch：动态图。每次前向传播构建计算图，调用 .backward() 时反向传播。 JAX：函数式 + JIT。jax.grad(f) 直接返回梯度函数。 TensorFlow：静态图（早期）和 eager（后来）混合。

[!quote] 历史 2024 年的工业事实是 PyTorch 一统江湖——HuggingFace、Llama、Mistral、ChatGPT、Sora、AlphaFold、几乎所有研究论文都用 PyTorch。TensorFlow 在 Google 内部仍然使用，JAX 在 Google DeepMind 内部主流。但社区已经站队 PyTorch。

7. 现代训练的额外工具 ​

这一节是预告——L14、L15、L31 会详细展开。

7.1 混合精度训练 ​

用 FP16 / BF16 而不是 FP32 训练，显存减半、速度翻倍。需要 loss scaling 防止梯度下溢。所有现代 LLM 训练标配。

7.2 梯度累积 ​

显存不够装大 batch？把多个小 batch 的梯度累加再做一次更新——等效大 batch 训练。

7.3 梯度裁剪（Gradient Clipping） ​

防止梯度爆炸——把梯度的范数限制在某个阈值（通常 1.0）。LLM 训练标配。

7.4 分布式训练 ​

  • Data Parallel：多 GPU 各处理一份 batch
  • Tensor Parallel：单层切到多 GPU
  • Pipeline Parallel：不同层放不同 GPU
  • FSDP / ZeRO：参数 / 梯度 / optimizer state 分片
  • DeepSpeed / Megatron-LM：工业级分布式训练框架

8. 失败模式 / 反例 / 边界 ​

8.1 损失没下降——5 大常见原因 ​

  1. 学习率太大：loss 震荡或 NaN
  2. 学习率太小：loss 几乎不动
  3. 数据没归一化：某些维度数值过大主导梯度
  4. 梯度消失/爆炸：loss 是 NaN 或一直不动
  5. Bug：模型 forward 计算错了，梯度算不出有意义的方向

调试顺序：① 学习率扫一遍 → ② 检查数据 → ③ 看梯度 norm → ④ 单步 overfit 一个 batch（小数据集） → ⑤ 跟人比

8.2 训练 loss 下降但验证 loss 上升 ​

→ 过拟合。增加正则、dropout、early stopping，或减小模型/加数据。

8.3 双下降的反直觉 ​

如 §4.3 所述。经典教材的"复杂模型一定过拟合"在 deep learning 时代不再成立。

8.4 「优化器找到的就是全局最优」误解 ​

99% 的 deep learning 是非凸优化——SGD/Adam 找到的是某个局部最优。它"够好"是经验事实，不是数学保证。

8.5 「损失低 = 模型好」误解 ​

低 loss 不意味着 ① 在测试集上低 ② 对人类有用 ③ 没有偏见。L18（对齐）和 L34（安全）会反复回到这件事。

8.6 「梯度下降是唯一选择」误解 ​

强化学习有些场景用 evolution strategies；离散参数空间（如神经架构搜索）用 GA / SA / PSO（L02 §5）。深度学习内部也在尝试 zero-order optimization 等替代方案。

10. 本讲小结 ​

  1. 所有机器学习都是优化问题：找参数让损失最小。一个公式 θ∗=arg⁡minθL(fθ(x),y) 统治一切。
  2. 四大支柱：数据、模型、损失、优化器——每个新方法都可以用这四个问题拆解。
  3. 梯度下降的几何直觉：损失曲面 + 蒙眼登山者。SGD 噪声有用——帮助逃离局部最优。
  4. 学习率是最重要的超参数——太大发散，太小不动。Warmup + Cosine 是 LLM 标配。
  5. 优化器演化：SGD → SGD+Momentum → Adam → AdamW（2024 默认）→ Lion / Sophia（实验中）。
  6. 过拟合 vs 欠拟合：经典 bias-variance 权衡。L2 / Dropout / Early stopping 是经典工具。
  7. 双下降颠覆经典教科书——deep learning 时代"越大越好"在理论上有了部分依据。
  8. 自动微分让深度学习成为现实——你只写前向，框架自动算梯度。PyTorch 一统江湖。
  9. 训练循环 5 步——从 LeNet 到 GPT-4，本质相同，区别只在每一步的具体内容。
