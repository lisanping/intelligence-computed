第 8 讲 · 视觉应用全景 — 从人脸检测到万物分割 ​

CNN 的真正价值不在论文里的 accuracy，而在于改变了整个产业。

2012 年 AlexNet 之后发生的不只是"继续刷分"——而是整个产业被引爆：

  • 人脸识别 → 安防、支付、解锁
  • 目标检测 → 自动驾驶、机器人、零售
  • 语义分割 → 医疗影像、卫星遥感、AR
  • 姿态估计 → 健身、动捕、康复
  • 光流 / SLAM → AR/VR、扫地机器人、无人机

本讲从最底层的 Canny 边缘检测到最前沿的 SAM 万物分割，是 CNN 从实验室走向产业的故事。

前置知识核心产出建议用时
L06（手工特征）、L07（CNN）① 掌握 Canny / Hough / Viola-Jones 等经典 CV 操作 ② 理解 R-CNN → Fast → Faster → YOLO 检测演进的工程逻辑 ③ 区分语义 / 实例 / 全景分割 ④ 理解 U-Net 在医学影像的统治地位 ⑤ 看清 SAM 如何让分割进入"基础模型"时代 ⑥ 掌握光流约束方程与 RAFT ⑦ 拿到 L29（Multimodal）的伏笔 ⑧ 看清 CV 在自动驾驶 / 机器人 / 医疗的真实部署阅读 ~75 分钟 + 动手 ~25 分钟

从上一讲到这一讲 ​

L07 拆解了 CNN 的内部结构——卷积核、参数共享、层级抽象、ResNet / VGG / EfficientNet 演进。你知道了 CNN 怎么学到特征。

但学到特征之后呢？2012 年 AlexNet 之后发生的不是"继续刷分"——是整个产业被引爆。这一讲把视野从单张图片的分类（"这是什么"）扩展到完整的视觉系统（"在哪里"、"什么形状"、"在动吗"）。

核心概念

视觉理解不只是分类。一个完整的视觉系统需要回答：

问题任务
"是什么"分类
"在哪里"检测
"什么形状"分割
"什么姿势"姿态估计
"在动吗"光流 / 跟踪
"在哪里 (3D)"深度估计 / SLAM

1. 经典 CV 基础操作（仍在生产） ​

不要以为 1980s 的算法都过时了。Canny + Hough 至今仍是工业视觉的主力——快、稳定、可解释。

1.1 Canny 边缘检测 ​

[!quote] 历史 1986 年，John Canny 在 MIT 博士期间发表 A Computational Approach to Edge Detection[1]——把边缘检测建模为一个最优化问题，用三条标准（检测率、定位、单响应）推导出最优滤波器。

论文被引用 40,000+ 次——CV 史上最高引用论文之一。OpenCV 至今 cv2.Canny() 是默认边缘检测。

算法五步（CPU 上几毫秒）：

步骤操作作用
1高斯滤波去噪
2梯度计算（Sobel）求每个像素的梯度幅值和方向：G=Gx2+Gy2
3非极大值抑制（NMS）在梯度方向上只保留极大值——边缘细化为一像素宽
4双阈值高阈值以上 = 强边缘，低阈值以下 = 非边缘
5滞后连接（Hysteresis）中间的须连接到强边缘才保留

直觉

Canny 的每一步都有明确的物理/工程意义。2024 年富士康质检产线上仍在跑 Canny——不是因为没有更好的方法，而是因为在确定性场景下它更快、更稳定、更可解释——而且不需要 GPU。

1.2 Hough 变换 ​

将"图像空间中找几何形状"转化为"参数空间中找交点"——经典的对偶变换思想。

1.2.1 直线检测 ​

图像空间中一个点 (x0,y0) 在参数空间 (ρ,θ) 中对应一条正弦曲线：

ρ=x0cos⁡θ+y0sin⁡θ

多个共线点的正弦曲线交于一点 → 该点即为直线参数。

1.2.2 圆检测 ​

三参数 (xc,yc,r)。每个边缘点在参数空间中投票，票数最多的位置即为圆心和半径。

核心概念

Hough 变换的核心是投票机制——每个边缘点对"它可能属于哪条线/圆"投一票，得票最多的参数组合胜出。

应用：

  • 工业质检：电路板走线对齐、PCB 缺陷
  • 文档扫描：纸张边界、表格识别
  • 车道检测：自动驾驶早期方案
  • 硬币计数：圆检测的经典任务

1.3 形态学操作 ​

膨胀（Dilation）、腐蚀（Erosion）、开运算、闭运算——基于结构元素的二值图像操作。至今是 OCR / 文档分析 / 工业视觉预处理标配。

2. 目标检测的 25 年演进 ​

"在哪里" 是比 "是什么" 更难的问题——你需要同时定位 + 分类。

2.1 Viola-Jones (2001)：实时人脸检测的奇迹 ​

[!quote] 历史 2001 年，Paul Viola (Microsoft Research) 和 Michael Jones 发表 Rapid Object Detection using a Boosted Cascade of Simple Features[2]。这是第一次人脸检测能在 CPU 上实时运行（30 FPS）。

这个算法被装进了 2000s 中后期所有数码相机的"自动对焦人脸" 功能——直到深度学习出现前，Viola-Jones 是消费电子市场上最广泛部署的视觉算法。

三个关键创新：

创新技术效果
Haar 特征用黑白矩形块检测明暗对比如：眼眶比鼻梁暗——一个 Haar 特征即可
积分图O(1) 计算任意矩形和几万特征实时计算
AdaBoost 选择从 16 万个特征中选最有区分度的 2k自动特征工程
级联淘汰先用简单特征排除非目标区域90% 区域在第一步就被淘汰 → 实时

2.2 R-CNN 家族 (2014-2017) ​

2.2.1 R-CNN (2014) ​

[!quote] 历史 2014 年，Ross Girshick (Berkeley) 发表 Rich Feature Hierarchies for Accurate Object Detection and Semantic Segmentation[3]——第一个用 CNN 做目标检测的工作。

流程：

  1. Selective Search[4] 生成 ~2000 个候选框
  2. 每个框 resize 到 227×227，单独送 CNN 提特征
  3. 每个特征送 SVM 分类
  4. 边界框回归微调

问题：每张图跑 2000 次 CNN → 47 秒/张。完全不能实用。

2.2.2 Fast R-CNN (2015) ​

关键洞察：CNN 计算应该全图共享——只跑一次！

  1. 全图过一遍 CNN 得 feature map
  2. 把 2000 个候选框投影到 feature map 上
  3. RoI Pooling 把变长候选框变成定长向量
  4. 一个网络同时预测分类 + 边界框

速度：0.3 秒/张——比 R-CNN 快 150 倍。

2.2.3 Faster R-CNN (2015) ​

最后一个外部依赖：Selective Search 慢且不可学习。

Region Proposal Network (RPN) 用 CNN 学怎么生成候选框——端到端训练。

速度：0.2 秒/张——5 FPS，开始接近实时。

2.3 YOLO 家族 (2016-2024)：单阶段革命 ​

[!quote] 历史 2016 年，Joseph Redmon 发表 You Only Look Once: Unified, Real-Time Object Detection[5]。45 FPS——比 Faster R-CNN 快 9 倍。

Redmon 的论文风格独特——用 ASCII art 画架构图、写诗当致谢、把模型权重命名为有趣的名字。他在 2020 年宣布退出 CV 研究，理由是"我的研究被用于军事监控用途，我无法继续"。

YOLO 的设计：

把图像分成 S×S 网格，每个 Grid Cell 预测：

  • B 个边界框 (x,y,w,h,confidence)
  • C 个类别概率

一次前向传播输出所有检测结果——这是"单阶段检测"的精髓。

2.3.1 IoU：检测质量度量 ​

Intersection over Union：

IoU=|A∩B||A∪B|

通常 IoU > 0.5 为正确检测。COCO 等更严格 benchmark 用 0.5:0.95 平均。

2.3.2 NMS：去重 ​

按置信度排序，逐个保留最高，删除与它 IoU > 阈值的所有框。几乎所有检测器都需要。

2.3.3 YOLO 演进 ​

版本年份关键特性速度 / 精度
v12016单阶段开创45 FPS / mAP 63
v22017Anchor box + Batch Norm67 FPS / mAP 76
v32018多尺度 + Darknet-5330 FPS / mAP 57
v42020CSPNet + Mosaic 增强(Bochkovskiy 团队)
v52020PyTorch 重写（Ultralytics）工业广泛采用
v82023Anchor-free + 任务统一mAP 53.9 (COCO)
v112024进一步优化mAP 54.7

核心概念

YOLO 的核心贡献不是精度（v1 时不如 Faster R-CNN），而是速度——45 FPS 意味着可以装在车上、工厂里、手机里。从 v1 到 v11 的演进是工程驱动的，不是算法革命。

2024 年的工业事实：YOLO（特别是 Ultralytics 的 YOLOv8/v11）是部署最广的检测模型。

2.4 DETR (2020)：Transformer 进入检测 ​

Carion et al. (Facebook AI) 提出 DETR[6]——Transformer 端到端检测：

  • 没有 anchor box
  • 没有 NMS
  • 直接输出 N 个 (class, box) 元组
  • 用匈牙利匹配计算损失

DETR 让检测领域开始 Transformer 化。后续 Deformable DETR、DINO 等改进让 DETR 系列在 COCO 上超过 YOLO。

2.5 现代检测器对比 ​

检测器速度 (FPS)mAP (COCO)特点
YOLOv11100+54.7工业默认

核心概念

2024 年检测的两大新趋势：

  1. 开放词汇检测——用文本描述检测任意物体（"红色帽子的人"），不再受限于固定类别
  2. 检测 + 分割融合——SAM2 / Grounded-SAM 把检测、分割、跟踪统一

3. 图像分割：从轮廓到万物 ​

3.1 三种分割 ​

类型做什么区分个体
语义（Semantic）每个像素标一个类别❌
实例（Instance）标类别 + 区分同类不同个体✅
全景（Panoptic）stuff（语义）+ things（实例）统一✅

例：3 个人在草地上踢球

  • 语义：所有人 = 一个 class，所有草 = 一个 class
  • 实例：人 1 / 人 2 / 人 3 分别标识
  • 全景：草地（stuff，无个体）+ 3 个独立人（things）

3.2 FCN (2015)：第一个端到端分割网络 ​

Long et al. 提出 Fully Convolutional Network[9]——把分类网络的全连接层换成 1×1 卷积，输出热图而非类别。这是把 CNN 从"分类"扩展到"密集预测"的关键工作。

3.3 U-Net (2015)：医学影像的统治者 ​

[!quote] 历史 2015 年，Freiburg 大学的 Olaf Ronneberger 团队发表 U-Net: Convolutional Networks for Biomedical Image Segmentation[10]——为生物显微图像设计。

没人想到这个网络会成为整个医学影像领域 10 年的事实标准——80% 的医学分割系统是 U-Net 或其变体。

架构：编码器-解码器 + 跳跃连接：

   编码器（下采样）              解码器（上采样）
   conv → conv → pool ──────────── upsample ← conv ← conv
       │                              │
       conv → conv → pool ─────── upsample ← conv ← conv
            │                          │
            conv → conv → pool ── upsample ← conv ← conv
                 │                       │
                 ─────── bottleneck ─────
  • 编码器：特征越来越抽象，分辨率越来越低
  • 解码器：从抽象特征恢复到原始分辨率
  • 跳跃连接：编码器的高分辨率细节直接传给解码器对应层

核心概念

U-Net 改变了医学影像 AI。在标注数据极少（几十张）的情况下就能做出医生水平的分割——因为编码器-解码器结构是很强的归纳偏置。

应用：

  • 肿瘤分割（CT / MRI）
  • 器官轮廓
  • 细胞计数
  • 视网膜血管
  • 卫星遥感

3.4 Mask R-CNN：实例分割的标准 ​

He et al. 2017[11] 在 Faster R-CNN 上加一个 mask head——检测 + 分割同时。

RoIAlign 替代 RoI Pooling 解决量化误差。Mask R-CNN 直到 2023 年仍是实例分割的事实基线。

3.5 SAM (2023)：分割进入基础模型时代 ​

[!quote] 历史 2023 年 4 月，Meta AI 发布 Segment Anything Model (SAM)[12]：

  • 在 11 亿掩膜（SA-1B）数据集上训练
  • 训练用了 256 块 A100 GPU，5 天
  • 零样本——能分割训练集没见过的物体
  • 可提示——点击 / 框 / 文本即可指定要分割的对象

架构：

组件作用
图像编码器ViT-H，将图像编码为 patch embedding
提示编码器将点击点 / 边界框 / 文本编码为提示 embedding
掩膜解码器图像 + 提示 → 掩膜

三种提示：

  1. 点提示：点击一个点 → 分割该点所在物体
  2. 框提示：画一个框 → 框内精确分割
  3. 全自动：无提示 → 分割图像中所有物体

3.5.1 SAM2 (2024)：加入视频 ​

SAM2 (2024-07)[13] 把 SAM 扩展到视频——点击一帧的物体，自动跟踪整个视频。

常见误区

SAM 的突破不在 accuracy——在确定类别的分割任务上，专用模型可能更好。SAM 的突破在于范式转变：从"为每个任务训练一个模型"到"一个模型 + 提示处理所有分割任务"。类似 GPT-3 对 NLP 的意义。

[!abstract] 呼应线 🔗 基础模型化（L13 → L08 此处 → L29 → L33）：先是 NLP（BERT/GPT），然后是视觉（SAM/CLIP），然后是多模态（GPT-4V）——所有领域都在被"基础模型 + 提示"范式重塑。L29（多模态）会展开。

4. 姿态估计与光流 ​

4.1 OpenPose：多人姿态估计 ​

[!quote] 历史 2016 年 CMU 的 Cao et al. 发表 Realtime Multi-Person 2D Pose Estimation using Part Affinity Fields[14]。OpenPose 是第一个开源的实时多人姿态估计系统——直接催生了健身 app 动作识别、康复评估、动作捕捉等产业。

核心技术——Part Affinity Fields (PAF)：

不是先检测人再找关节，而是先找所有关节，再用向量场把关节组装成完整骨骼。解决了遮挡场景下的多人姿态估计。

现代替代：MediaPipe Pose (Google)、MMPose 等。

4.2 光流约束方程 ​

光流的基本假设——亮度恒常：同一像素在相邻帧间亮度不变。

I(x,y,t)=I(x+u,y+v,t+1)

一阶 Taylor 展开 → 光流约束方程：

Ixu+Iyv+It=0

其中 (u,v) 是像素的运动向量，Ix,Iy,It 是图像的空间和时间偏导。

一个方程两个未知数——需要额外约束：

方法约束输出
Lucas-Kanade[15]局部邻域运动一致稀疏光流
Horn-Schunck[16]全局光流场平滑稠密光流
FlowNet (2015)神经网络直接学习稠密光流
RAFT (2020)[17]迭代细化 + 4D cost volume当前 SOTA

4.3 SLAM：实时 3D 重建 + 定位 ​

SLAM (Simultaneous Localization and Mapping) — 同时定位 + 建图。

主流系统：

  • ORB-SLAM3[18] (2021) — 仍用 ORB 手工特征 (L06 §8)
  • NeRF-SLAM[19] (2023) — 神经辐射场 + SLAM
  • Apple Vision Pro 内核 — 完整商业 SLAM 系统

应用：AR/VR、扫地机器人、无人机、自动驾驶。

5. 视觉系统的工业部署 ​

把单个模型组合成完整系统是另一门学问。

5.1 自动驾驶视觉栈（典型） ​

摄像头输入
    ↓
1. 图像增强 (HDR / 去噪)
    ↓
2. 对象检测 (YOLO / DETR)
    ↓
3. 语义分割 (车道线 / 道路 / 障碍)
    ↓
4. 深度估计 (单目 / 多目)
    ↓
5. 3D 物体跟踪 (跨帧)
    ↓
6. 轨迹预测 (其他车 / 行人 5s 内行为)
    ↓
7. 运动规划 (车自己怎么走)

每一阶段都是一个完整模型。Tesla FSD、Waymo Driver、华为 ADS 都遵循类似架构——但具体模型和融合策略各异。

5.2 医疗影像 AI 栈 ​

DICOM 影像
    ↓
1. 预处理 (窗位调整 / 重采样)
    ↓
2. 器官分割 (U-Net 变体)
    ↓
3. 病灶检测 (Faster R-CNN / nnDetection)
    ↓
4. 病灶分类 (ResNet / EfficientNet)
    ↓
5. 报告生成 (LLM——2024 新趋势)

5.3 工业质检栈 ​

通常仍是经典 CV 主导——快、可解释、零样本通用：

相机
    ↓
1. 标定 / 畸变校正 (经典 CV)
    ↓
2. ROI 提取 (Hough / Canny)
    ↓
3. 缺陷检测 (经典 CV 80% / DL 20%)
    ↓
4. 缺陷分类 (DL)
    ↓
5. 决策 (规则)

6. 失败模式 / 反例 / 边界 ​

6.1 目标检测 mAP 的欺骗性 ​

COCO mAP 提升 1 个点常需 100×算力。但下游任务（如自动驾驶）真正在意的是 rare class recall——与 mAP 几乎不相关。

6.2 「YOLO 实时」的隐藏成本 ​

YOLO 的"实时"建立在 GPU 推理上。CPU/边缘设备上 YOLOv8 也跑不到 30 FPS——常被误读。真实嵌入式部署还是首选量化版本（YOLOv8n.int8）。

6.3 人脸识别的伦理反例 ​

Buolamwini & Gebru 2018[20] 在 Gender Shades 中证明：商业人脸 API（IBM、Microsoft、Face++）对深肤色女性错误率比浅肤色男性高 35×。技术指标不是全部——L34 会展开。

6.4 分割 Dice score 的盲点 ​

Dice 对小目标极不友好。医疗影像上"模型 Dice 0.85"可能漏检 50% 的早期肿瘤——因为早期肿瘤是小区域，对总 Dice 贡献小。

6.5 SAM 的局限 ​

  • 无类别——SAM 给你 mask 但不告诉你"这是什么"
  • 零样本不等于完美——医疗影像、卫星遥感等 OOD 场景仍需 fine-tune
  • 细粒度物体——很小的物体或极薄的物体（如电线）SAM 表现差
  • 训练成本不可承受——SA-1B 数据集 11 亿 mask 是 Meta 量级才能做的事

6.6 深度学习 ≠ 全部用神经网络 ​

真实生产视觉系统通常是 70% 经典 CV + 30% DL——经典 CV 处理标定、畸变、ROI、几何变换，DL 处理感知。

6.7 数据偏差是最大风险 ​

  • 自动驾驶模型在白天 / 晴天数据上训练，夜晚 / 雨雪场景失效
  • 医疗模型在某医院数据上训练，换医院影像 3-5% 准确率下降
  • 工业质检模型在某产线训练，换产线全部重来

数据多样性 > 模型复杂度——这是 CV 工业部署最重要的工程教训。

6.8 视频理解 ≠ 帧级理解 × N ​

视频不是独立帧——存在时间相关性、动作连续性。但很多"视频理解"系统仅仅在每帧上跑图像模型 + 聚合——忽略时间信息。Video Transformer / SlowFast / X3D 等才是真正的视频架构。

8. 本讲小结 ​

  1. Canny + Hough 是 1980 年代的技术，至今仍是工业视觉主力。
  2. 检测演进：R-CNN (47s) → Fast (0.3s) → Faster (0.2s) → YOLO (实时 45+ FPS)。
  3. YOLO 的核心贡献是速度——单阶段检测让 CV 装上了车、工厂、手机。
  4. DETR 让 Transformer 进入检测——开放词汇检测是 2024 新趋势。
  5. 三种分割：语义（不区分个体）、实例（区分）、全景（统一）。
  6. U-Net 改变了医学影像——80% 医疗分割系统是它的变体。
  7. SAM 是分割的范式转变——基础模型 + 提示，类似 GPT 对 NLP。
  8. OpenPose / MediaPipe 是姿态估计标准。
  9. 光流 + SLAM 是 AR/VR / 机器人的核心 perception。
  10. 真实部署 = 70% 经典 CV + 30% DL——单纯神经网络不够。
  11. 数据偏差是最大风险——多样性 > 模型复杂度。
