第 10 讲 · 从 RNN 到 Attention — 序列与记忆 ​

CNN 给了视觉以结构，但语言是序列——词的顺序和远距离依赖是核心。

RNN 尝试用"逐步记忆"解决序列问题，LSTM 给了它一个笔记本，而 Attention 机制带来了颠覆性的洞见——不要记住一切，需要时回头查。

这一讲是从经典深度学习走向 Transformer 的关键转折讲。理解 RNN 失败的原因，理解 Attention 出现的必然，是理解 L12（Transformer）"为什么必须革命"的前提。

前置知识核心产出建议用时
L03（统一框架）、L07（CNN 与归纳偏置）、L09（经典 NLP）① 理解 RNN 的序列归纳偏置与梯度消失困境 ② 掌握 LSTM / GRU 门控机制的直觉 ③ 理解 Seq2Seq 的信息瓶颈 ④ 掌握 Attention 三步：打分 → 归一化 → 加权求和 ⑤ 理解 Bahdanau vs Luong attention ⑥ 看清 Attention 是 Transformer 的 prequel ⑦ 理解 RNN 与 LSTM 在 2024 年的真实位置（仍然在跑！） ⑧ 拿到 L12 (Transformer) / L23 (Retrieval) 的伏笔阅读 ~70 分钟 + 动手 ~25 分钟

从上一讲到这一讲 ​

L09 留了敌意问题：TF-IDF 把词当符号，无法捕捉语义。如果让每个词成为连续空间中的一个点呢？

但在讲这件事之前，我们需要先理解一个更根本的问题：如果数据是一句话呢？CNN 的卷积核只看 3×3 的窗口——它看不到远处。

核心概念

语言的依赖关系不是局部的。例：

  • "The cat that sat on the mat was fat"——"was" 要跟远处的"cat"保持单复数一致，中间隔着一个从句
  • "He read the book. It changed his life."——"It" 要指代上一句的 "book"

CNN 的局部感受野处理不了远距离依赖。我们需要一种能处理序列的架构——一种把"时间顺序"编码进结构的归纳偏置。

这一讲的主线是 3 次架构演化：

  1. RNN：朴素的"逐步记忆"——梯度消失
  2. LSTM/GRU：用门控机制给 RNN 一个"笔记本"
  3. Attention：放弃"记住一切"，改为"需要时回头查"——为 Transformer 铺路

1. RNN：逐步处理，逐步记忆 ​

1.1 直觉与公式 ​

[!quote] 历史 1986 年 Rumelhart, Hinton, Williams 在 Learning representations by back-propagating errors[1] 中提出了反向传播——同时也描述了 RNN 的雏形。1989 年 Elman 提出 Simple Recurrent Network[2]——现代 RNN 的标准形式。

循环神经网络（Recurrent Neural Network, RNN）的核心思想：逐个处理序列中的元素，同时维护一个隐藏状态（hidden state）ht 来"记住"之前看到的内容：

ht=tanh⁡(Whhht−1+Wxhxt+b)

输出（如果需要）：

yt=Whyht

直觉

想象你在读一本小说。每读一页，你不会记住所有文字——你在脑中维护一个"摘要"：主角在哪里、发生了什么事、情绪氛围。每读新的一页，你用新内容更新这个摘要。

ht 就是这个摘要——它是对"到目前为止所有输入"的压缩表示。

1.2 RNN 的归纳偏置 ​

RNN 编码两条核心先验：

  1. 时间顺序很重要——"我吃了苹果" vs "苹果吃了我" 词完全相同但顺序不同
  2. 同样的处理函数适用于每个时间步（参数共享）——和 CNN 的 translation equivariance 类似

这对语言来说是合理的归纳偏置。

1.3 RNN 的致命弱点：梯度消失 ​

理论上 ht 可以记住任意远的历史。实际上不行。

1.3.1 BPTT：沿时间的反向传播 ​

训练 RNN 用的是 Backpropagation Through Time (BPTT)——梯度需要从最后一步一路回传到第一步。

每经过一个时间步，梯度要乘以一次权重矩阵 Whh。如果 Whh 的特征值小于 1，连乘的结果指数衰减：

∂L∂h1≈(WhhT)T−1∂L∂hT

[!quote] 历史 Bengio, Simard, Frasconi 1994[3] 严格证明了 RNN 训练长程依赖的根本困难——梯度消失/爆炸。这篇论文标记了 RNN 第一次寒冬的开始。

直觉

传话游戏。第一个人说了一句话，传了 30 个人之后，最后一个人听到的完全变样了。

RNN 的梯度传播就是这个传话链——每传一步就"失真"一次，传得越远，信号越弱。

实践含义：RNN 只能记住大约 10-20 步的信息。对于短句够了，对于长文档——远远不够。

1.4 梯度爆炸：另一极端 ​

如果 Whh 特征值 > 1，连乘指数增长 → 梯度爆炸 → loss 变 NaN。

解法：梯度裁剪（gradient clipping）——把梯度的范数限制在某个阈值（通常 1.0）。这是 LLM 训练标配。

2. LSTM：给网络一个笔记本 ​

2.1 历史 ​

[!quote] 历史 1997 年，Sepp Hochreiter & Jürgen Schmidhuber 提出 LSTM[4]——通过引入门控机制解决梯度消失问题。

论文最初被 NeurIPS 拒收，发表在《Neural Computation》上。直到 2014-2015 年才被广泛采用。Hochreiter 当时是 Schmidhuber 的硕士生——LSTM 是他的硕士论文工作。

Schmidhuber 多年来公开抱怨"LSTM 没得到应有的承认"。LSTM 累计被引用 100,000+ 次。

2.2 Cell State：信息高速公路 ​

LSTM 的核心创新是一条记忆通道（Cell State）ct——它像一条传送带，信息可以不被修改地通过整条序列。

三个门控制信息的流入和流出：

门公式直觉
遗忘门 ftft=σ(Wf[ht−1,xt]+bf)"这段回忆不再重要了，删掉"
输入门 itit=σ(Wi[ht−1,xt]+bi)"这个新信息值得记住"
输出门 otot=σ(Wo[ht−1,xt]+bo)"现在需要用到哪部分记忆"
候选记忆 c~tc~t=tanh⁡(Wc[ht−1,xt]+bc)"新的备选记忆"
Cell State 更新ct=ft⊙ct−1+it⊙c~t加法更新——梯度高速公路的来源
Hidden State 更新ht=ot⊙tanh⁡(ct)

2.3 为什么 LSTM 解决了梯度消失？ ​

关键在 Cell State 的加法更新：

ct=ft⊙ct−1+it⊙c~t
  • RNN 的更新是乘法 → 连乘衰减
  • LSTM 的 Cell State 更新是加法 → 梯度可以直接通过

直觉

如果 RNN 是一个人在脑子里默默记东西（容量有限、容易忘），LSTM 是一个人带着笔记本——可以选择性地写入、删除、查阅。笔记本上的信息不会随时间衰减。

深入阅读

LSTM 的 Cell State 通过加法传递这一特性，在数学上与 ResNet 的残差连接 F(x)+x 异曲同工——都是为梯度提供一条不受连乘衰减影响的"高速公路"。

LSTM 比 ResNet 早了 18 年提出这个想法。但 ResNet 的影响更大，因为它出现在深度学习爆发之后。

2.4 GRU：LSTM 的简化版 ​

[!quote] 历史 Cho et al. 2014[5] 在做 NMT 时提出 Gated Recurrent Unit (GRU)——把 LSTM 的三个门合并为两个（更新门、重置门），参数更少，训练更快。

实证：GRU 与 LSTM 效果通常相当——但参数少 25%。在小数据/小模型场景 GRU 略优。

2.5 BiLSTM：双向上下文 ​

序列标注任务（如 NER）需要看前后上下文。BiLSTM 用两个 LSTM——一个正向、一个反向——concatenate 它们的 hidden state：

ht=[ht→;ht←]

BiLSTM + CRF[6] 是 2015-2018 年序列标注的事实标准——L09 §3.3 提及的"BERT + CRF"是它的后继。

3. Seq2Seq：编码器-解码器与信息瓶颈 ​

3.1 架构 ​

[!quote] 历史 2014 年 Sutskever, Vinyals, Le (Google Brain) 提出 Seq2Seq[7]——把翻译建模为"编码源句子 → 解码目标句子"。

同一年 Cho et al.[5:1] 独立提出类似思路（在统计机器翻译流水线中作为辅助）。Sutskever 后来成为 OpenAI 联合创始人 + 首席科学家——直到 2024 年离开。

Seq2Seq 用两个 RNN：

  1. 编码器（Encoder）：逐词读入源语言句子，把整句话压缩成一个固定长度的向量 c
  2. 解码器（Decoder）：从 c 出发，逐词生成目标语言句子

3.2 信息瓶颈 ​

问题：一个固定长度的向量能装下多少信息？

  • 短句（5-10 词）→ 没问题
  • 中句（20 词）→ 开始吃力
  • 长句（50 词）→ 信息严重丢失

常见误区

Seq2Seq 的瓶颈不是模型不够大——而是结构设计决定了所有信息必须经过一个固定维度的瓶颈。这是架构层面的限制，不是靠增加参数能解决的。

实验证实：Seq2Seq 在短句上翻译出色，但句子越长，BLEU 分数下降越快[8]。

3.3 为什么人不会有信息瓶颈？ ​

人类做翻译时不会"先读完整句话再翻译"——而是边读边对照。看到 "The European Economic Area"，立即对应到 "L'Espace Économique Européen"——注意力在不同段落间切换。

这个观察启发了 Attention 机制。

4. Attention：不要记住一切，需要时回头查 ​

4.1 历史 ​

[!quote] 历史 2014 年 9 月 Dzmitry Bahdanau, KyungHyun Cho, Yoshua Bengio (蒙特利尔大学) 在 arxiv:1409.0473 发表 Neural Machine Translation by Jointly Learning to Align and Translate[9]——第一次把 Attention 机制引入神经机器翻译。

这篇论文累计被引用 40,000+ 次。Bahdanau 当时是 Bengio 的博士生。

2017 年 Attention is All You Need[10] 把这个机制推到极致——抛弃 RNN，只用 Attention——开启了 Transformer 时代（L12）。

4.2 核心想法 ​

核心概念

不把所有信息压缩成一个向量，而是让解码器在生成每个词时，"回头看"编码器的所有隐藏状态，动态决定关注哪些部分。

4.3 Attention 三步公式 ​

第一步：打分（Score）——当前解码器状态 si−1 与每个编码器状态 hj 的"相关程度"：

eij=score(si−1,hj)

第二步：归一化（Normalize）——把分数变成概率分布（softmax）：

αij=exp⁡(eij)∑kexp⁡(eik)

第三步：加权求和（Weighted Sum）——用注意力权重组合所有编码器状态：

ci=∑jαijhj

然后用 ci 与 si−1 一起预测下一个输出词。

4.4 Bahdanau vs Luong Attention ​

两种打分函数：

类型公式特点
Bahdanau (additive)score(s,h)=vTtanh⁡(Wss+Whh)一个小 MLP 学出来
Luong (multiplicative)[11]score(s,h)=sTWh 或 sTh简单矩阵乘——Transformer 用这种

核心概念

Attention 的本质是软性信息检索（Soft Information Retrieval）——给定一个查询（"我现在需要什么信息？"），在一组候选中按相关性加权提取。

这个想法——打分 → 归一化 → 加权求和——是所有后续 Attention 变体的共同祖先，包括 L12 Transformer 的 Self-Attention。

形式化：Query, Key, Value——Q 是查询，K 是被查询的"索引"，V 是返回的"内容"。

Attention(Q,K,V)=softmax(QKTdk)V

L12 会展开。

4.5 直觉对照 ​

传统 Seq2Seq+ Attention
读完一整本书后凭记忆答题答每道题时可以翻书回去找相关段落
所有信息压缩成一个向量每一步动态聚焦于最相关的部分
长序列急剧退化长序列也能保持高质量

4.6 Attention 可视化 ​

Bahdanau 论文中的对齐矩阵（Alignment Matrix）可视化是 AI 领域第一批"模型在看什么"的图——你可以看到翻译 "European Economic Area" 时，解码器在生成每个法语词时精确地注意到了对应的英语词。

图 10.1：解码器在生成每个输出 token 时对输入序列各位置的注意力分布。来源：demo/rnn_vs_attention.py 生成。

常见误区

Attention 权重 ≠ 模型解释。Jain & Wallace 2019 Attention is not Explanation[12] 证明权重和模型决策弱相关。漂亮的注意力图未必意味着模型真的"在看那里"。

[!abstract] 呼应线 🔗 归纳偏置 vs 规模（L06-07 → L10 → L12 → L29）：CNN 编码空间先验，RNN 编码时序先验——都是人类把领域知识硬编码进结构。Attention 的出现暗示了一种可能：也许不需要逐步处理，也许可以同时看所有位置。这个暗示在 L12 会成为现实。

5. RNN 与 LSTM 在 2026 年的真实位置 ​

不要以为 RNN/LSTM 都"过时了"——某些场景它们仍然是最好的选择。

5.1 仍在生产的 RNN/LSTM 场景 ​

场景为什么仍用
嵌入式语音识别内存复杂度 O(n)，比 Transformer 的 O(n2) 友好
极小 IoT 模型树莓派、Arduino——LSTM 能跑，Transformer 跑不动
在线流式处理RNN 天然 streaming，Transformer 需 KV cache
时序预测（小规模）配合 GBDT 仍工业首选
Mamba / SSM 复活2024 年 RNN 风格架构卷土重来（§5.3）

5.2 RNN 训练慢的真实原因 ​

不是模型本身慢，是反向传播无法并行——BPTT 串行依赖。

Transformer 取代 RNN 的根本工程原因不是"更准"，而是"能并行训练" → 能用更多 GPU → 能用更多数据 → Scaling Law 起飞。

L12 / L14 会展开。

5.3 RNN 的复活：Mamba / Selective State Space Models ​

[!quote] 历史 2023 年 Albert Gu, Tri Dao (CMU/Princeton) 发表 Mamba[13]——结构化状态空间模型（SSM）的重大突破。Mamba 在长序列任务上超过 Transformer，且线性时间复杂度。

Mamba 本质上是改良版 RNN——但用了选择机制（selective）+ 硬件友好的并行扫描算法。

2024 年 Mamba-2、Jamba 等混合架构出现。RNN 的火重新点起来了——但和经典 LSTM 相比，新一代 SSM 更接近"可并行训练的 RNN"。

5.4 注意力可视化的过度解读 ​

如 §4.6 所述。Jain & Wallace 2019[12:1] 警告——别把 attention map 当模型解释。

6. 失败模式 / 反例 / 边界 ​

6.1 「LSTM 已死」误解 ​

如 §5.1 所述。嵌入式、流式、IoT 场景仍然首选。

6.2 「Attention 是 RNN 的自然演化」错觉 ​

Bahdanau 2014 attention 是为了翻译对齐临时加的辅助机制，原意不是替代 RNN——但它无意中开启了 Transformer 时代。

6.3 注意力可视化的过度解读 ​

如 §4.6 所述。

6.4 「梯度消失只在 RNN 出现」误解 ​

很深的 MLP / CNN 也会梯度消失/爆炸——ResNet 的残差连接、BatchNorm、合理初始化、Adam 都是为了缓解这件事。

6.5 「Seq2Seq 模式被淘汰」误解 ​

Encoder-Decoder 模式至今活跃：T5、BART、Flan-T5、CodeT5、所有翻译模型……都是 Seq2Seq。L13 会展开 BERT (encoder-only) / GPT (decoder-only) / T5 (encoder-decoder) 的对比。

6.6 「LSTM 一定优于 RNN」误解 ​

LSTM 参数比 RNN 多 4 倍——在小数据 + 短序列场景，简单 RNN 可能更好（不容易过拟合）。

6.7 「Attention 解决一切」误解 ​

Attention 只是工具——它不能弥补数据不足、目标设计不当、过拟合等根本问题。

8. 本讲小结 ​

  1. RNN 编码"时间顺序 + 参数共享"两个先验——逐步处理、逐步记忆。
  2. 梯度消失让 RNN 只能记住 10-20 步——长序列任务上失败。
  3. LSTM 的 Cell State 是"信息高速公路"——加法更新避开连乘衰减。三个门控制写入、删除、读取。
  4. GRU 是 LSTM 的简化版——参数少 25%，效果相当。
  5. Seq2Seq 的信息瓶颈是架构性的——不是模型不够大的问题。
  6. Attention 的本质是软性信息检索——打分 → 归一化 → 加权求和。
  7. Attention 是 Transformer 的 prequel——Bahdanau 2014 为 Vaswani 2017 铺路。
  8. Attention 权重 ≠ 模型解释——别过度解读。
  9. RNN/LSTM 没死——嵌入式、流式、IoT、Mamba 卷土重来。
  10. Transformer 取代 RNN 的根本工程原因是"能并行"——不是"更准"。

下一讲预告 ​

敌意问题：Attention 解决了记忆问题。但我们仍然在逐词处理——RNN 的瓶颈不只是记忆，还有速度。如果干脆扔掉 RNN，只用 Attention——让每个位置同时看到所有其他位置——会怎样？这甚至合理吗？

在回答这个问题之前，第 11 讲先建立一个关键基础：向量空间——所有模态（文字、图像、声音）的通用语言。因为 Attention 的本质就是在向量空间中做检索——理解了向量空间，才能理解 Transformer 在做什么。
