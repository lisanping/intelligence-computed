1. 学术论文

AI 代码生成与评测

  1. ●●●●●
    P1Evaluating Large Language Models Trained on Code (Codex / HumanEval)
    Chen, M., Tworek, J., et al. (OpenAI) · 2021 · arxiv preprint

    AI 代码生成的奠基评测。 HumanEval benchmark 的来源。Codex 模型（GPT-3 代码微调版）定义了"AI 写代码"这个领域。讲稿开场背景参考。

  2. ●●●●●
    P2SWE-bench: Can Language Models Resolve Real-World GitHub Issues?
    Jimenez, C.E., Yang, J., et al. (Princeton) · 2024 · ICLR 2024

    Agentic Coding 最重要的 benchmark。 真实 GitHub Issue → 自动修复 → 测试验证。讲稿 V8 时间线 + Devin/Codex 评估的核心数据来源。

  3. ●●●●●
    P3SWE-bench Verified
    OpenAI / Anthropic / Princeton · 2024 · Technical Note

    SWE-bench 的人工验证子集（500 题），消除噪声。Agentic Coding 刷榜排行榜的权威基准。横评段的数据参考。

  4. ●●●●○
    P4Competition-Level Code Generation with AlphaCode
    Li, Y., Choi, D., et al. (DeepMind) · 2022 · Science

    AlphaCode 在 Codeforces 上达到人类中位水平。"生成 + 筛选"策略 = PGE 中 Generator + Evaluator 的变体。

  5. ●●●○○
    P5RepoBench: Benchmarking Repository-Level Code Auto-Completion Systems
    Liu, T., Xu, C., et al. · 2023 · arxiv preprint

    仓库级代码补全 benchmark——超越单文件的上下文检索评测。与 Cursor 的 codebase indexing 技术直接相关。

  6. ●●●●○
    P6Reflexion: Language Agents with Verbal Reinforcement Learning
    Shinn, N., Cassano, F., et al. · 2023 · NeurIPS 2023

    L26 已引用。Reflexion 在 HumanEval 上从 80%→91%——“反思循环”在代码生成中的直接验证。讲稿 [18:00–22:00] “为什么编程是 PGE 最好的落地场景”。

  7. ●●●○○
    P7CodeAgent: Enhancing Code Generation with Tool-Integrated Agent Systems
    Zhang, K., Li, G., et al. · 2024 · ACL 2024

    Agent + 工具在代码生成中的系统性研究。与本讲 Agentic Coding Agent Loop 直接对应。

  8. ●●●○○
    P8Design2Code: How Far Are We From Automating Front-End Engineering?
    Si, C., et al. (Stanford) · 2024 · arxiv preprint

    前端代码生成 benchmark。动手环节（Web 应用）的学术参考。

人机协同编程

  1. ●●●●●
    P9The Impact of AI on Developer Productivity: Evidence from GitHub Copilot
    Peng, S., Kalliamvakou, E., et al. (GitHub/MIT) · 2023 · arxiv preprint

    Copilot 效率提升的实证研究。 55% 速度提升的数据来源。讲稿 [05:00–08:00] 第一代效率数据的核心引用。

  2. ●●●●○
    P10Expectation vs. Experience: Evaluating the Usability of Code Generation Tools
    Vaithilingam, P., Zhang, T., Glassman, E. · 2022 · CHI 2022

    AI 代码工具可用性研究——"接受建议 ≠ 正确使用"。协作模式讨论的学术基础。

  3. ●●●●○
    P11Grounding Copilots: How Programmers Interact with Code-Generating Models
    Barke, S., James, M.B., Polikarpova, N. (UCSD) · 2023 · OOPSLA 2023

    程序员如何与 AI 代码工具交互的实证分析。"加速模式"vs"探索模式"——与本讲 System 1/2 类比直接呼应。

  4. ●●●●○
    P12SWE-bench Multimodal: Do AI Systems Generalize to Visual Software Domains?
    Yang, J. et al. (Princeton) · 2024 · arxiv preprint

    SWE-bench 多模态版——2025 年 Agentic Coding 下一个关键 benchmark。

  5. ●●●○○
    P13CodeEditorBench: Evaluating Code Editing Capability of Large Language Models
    Guo, J. et al. · 2024 · arxiv preprint

    代码编辑 benchmark——评估 AI 能否限制修改现有代码而非重写。

  6. ●●●●○
    P14AgentLess: Demystifying LLM-based Software Engineering Agents
    Xia, C. S. et al. · 2024 · arxiv preprint

    逆忝论文——证明「简单管道 + 严谨 prompt」在 SWE-bench 上可与 Agent 不相上下。

  7. ●●●●○
    P15OpenHands (formerly OpenDevin): An Open Platform for AI Software Developers as Generalist Agents
    Wang, X. et al. · 2024 · arxiv preprint

    OpenHands 原论文——开源 Devin 趋于设计，以到近 SWE-bench Verified 剩付。
